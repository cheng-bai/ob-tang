一个困扰数学家的问题

x² + 1 = 0

• 实系数一元二次方程 并不总有实数解

• 在实数范围内，负数不能开平方

• 16世纪，数学家引入 "虚数" 解决此困境

• 实数与虚数合称为 复数

虚数单位 i

i² = -1

• i 是 -1 的一个平方根

• 任意 b∈R 与 i 的乘积记为 bi

• (bi)² = -b²，负数开平方得以解决

复数的定义

z = a + bi    (a, b ∈ R)

• 形如 a + bi 的数称为复数

• a 是实部，b 是虚部系数

• 全体复数构成集合 C

• a + bi = 0 ⇔ a=0 且 b=0

复数的加减法

(a + bi) ± (c + di) = (a±c) + (b±d)i

• 按多项式相加减

• 实部与实部相加减

• 虚部与虚部相加减

复数的乘法

(a + bi)(c + di)
= ac + bci + adi + bdi²
= (ac - bd) + (bc + ad)i

关键步骤：i² = -1

复数的除法

c + di

= (a + bi)(c - di)

  (c + di)(c - di)

= ac+bd + bc-adi

实部、虚部与共轭复数

复数的结构

z = a + bi
  • Re z = a（实部）
  • Im z = b（虚部）
  • b=0 时，z 是实数
  • b≠0 时，z 是虚数
  • a=0,b≠0 时，z 是纯虚数

共轭复数

z̄ = a - bi
  • 实部相同
  • 虚部互为相反数
  • z · z̄ = a² + b²（实数）

共轭复数的性质

z̄̄ = z
双重共轭等于自身

• 取共轭与四则运算可交换：

z₁ ± z₂ 的共轭 = z₁的共轭 ± z₂的共轭

z₁ · z₂ 的共轭 = z₁的共轭 · z₂的共轭

(z₁/z₂) 的共轭 = z₁的共轭 / z₂的共轭
