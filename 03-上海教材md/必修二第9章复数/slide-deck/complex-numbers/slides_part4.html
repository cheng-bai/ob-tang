9.2 复数的几何意义

z = a + bi

复数由两个实数确定：实部 a 和虚部系数 b

这让我们联想到平面直角坐标系中的点 (a, b)

复数与平面上的点或向量之间存在一一对应关系

代数视角

  • 代数形式：a + bi
  • 四则运算规则
  • 共轭复数性质

几何视角

  • 复平面上的点
  • 平面向量表示
  • 向量运算法则

复平面（高斯平面）

坐标系定义

  • 横轴（x轴） → 实轴
  • 纵轴（y轴） → 虚轴
  • 原点 O 对应复数 0
  • 点 Z(a,b) ↔ 复数 z = a + bi

|z| = √(a² + b²)
复数的模（到原点的距离）

复数的向量表示与加法

向量表示

  • 复数 z = a + bi
  • 对应向量 OZ→ = (a, b)
  • 零向量对应复数 0

平行四边形法则
复数加法 = 向量加法

例题 3：几何应用

【例题】 已知复数 z₁ = 1 + 2i，z₂ = 3 - i，求 |z₁ - z₂| 并说明其几何意义。

代数解法

z₁ - z₂ = (1 + 2i) - (3 - i)

        = 1 + 2i - 3 + i

        = -2 + 3i

|z₁ - z₂| = √((-2)² + 3²)

        = √(4 + 9)

        = √13

几何意义

|z₁ - z₂| 表示复平面上两点 Z₁ 与 Z₂ 之间的距离
