例题1：复数计算示范

【题目】 已知 z₁ = 3 + 2i，z₂ = 1 - 4i，求：
(1) z₁ + z₂    (2) z₁ - z₂    (3) z₁ · z₂    (4) z₁ ÷ z₂

加减法运算

(1) 加法：

z₁ + z₂ = (3+1) + (2-4)i

        = 4 - 2i


(2) 减法：

z₁ - z₂ = (3-1) + (2+4)i

        = 2 + 6i

乘除法运算

(3) 乘法：

z₁ · z₂ = 3·1 + 3·(-4i) + 2i·1 + 2i·(-4i)

        = 3 - 12i + 2i + 8

        = 11 - 10i


(4) 除法： 分子分母同乘 z₂ 的共轭

z₁/z₂ = (3+2i)(1+4i) / [(1-4i)(1+4i)] = (-5+14i) / 17

实部、虚部与共轭复数

复数的结构

z = a + bi
  • Re(z) = a —— 实部（Real part）
  • Im(z) = b —— 虚部系数（Imaginary part）
  • 当 b = 0 时，z 是实数
  • 当 b ≠ 0 时，z 是虚数
  • 当 a=0 且 b≠0 时，z 是纯虚数

共轭复数

z̄ = a - bi
  • 实部相同，虚部互为相反数
  • z + z̄ = 2a（实数）
  • z - z̄ = 2bi（纯虚数）
  • z · z̄ = a² + b²（实数，≥0）
  • 用于分母实数化
重要关系： z 是实数 ⟺ z = z̄   |   z 是纯虚数 ⟺ z + z̄ = 0 且 z ≠ 0

共轭复数的性质

z̄̄ = z
双重共轭等于自身（对合性质）
z₁ + z₂ 的共轭 = z₁̄ + z₂̄
加法与共轭可交换
z₁ - z₂ 的共轭 = z₁̄ - z₂̄
减法与共轭可交换
z₁ · z₂ 的共轭 = z₁̄ · z₂̄
乘法与共轭可交换
(z₁/z₂) 的共轭 = z₁̄ / z₂̄   (z₂ ≠ 0)
除法与共轭可交换
核心结论：取共轭运算与四则运算可交换，即运算后再取共轭 = 先取共轭再运算

例题2：复数分类讨论

【题目】 设复数 z = (m² - 5m + 6) + (m² - 3m)i，求实数 m 的值，使得：
(1) z 是实数    (2) z 是虚数    (3) z 是纯虚数
情况 (1)：z 是实数
虚部 = 0：m² - 3m = 0
m(m - 3) = 0
∴ m = 0 或 m = 3
情况 (2)：z 是虚数
虚部 ≠ 0：m² - 3m ≠ 0
∴ m ≠ 0 且 m ≠ 3
情况 (3)：z 是纯虚数
需同时满足：
① 实部 = 0：m² - 5m + 6 = 0
   (m-2)(m-3) = 0 → m = 2 或 3

② 虚部 ≠ 0：m ≠ 0 且 m ≠ 3

综合①②：∴ m = 2
解题关键：纯虚数需要同时满足：① 实部为零 ② 虚部不为零
