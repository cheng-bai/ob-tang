虚数单位 i 的定义

i² = -1

• i 是 -1 的一个平方根

• 即 i = √-1（在复数范围内）

• 任意实数 b∈R 与 i 的乘积记为 bi

• (bi)² = b² · i² = -b²，负数开平方得以解决

复数的定义

z = a + bi    (a, b ∈ R)

基本要素

• 形如 a + bi 的数称为复数

• a 是实部（Real part）

• b 是虚部系数（Imaginary part）

• 全体复数构成集合 C

特殊情形

• b = 0 时，z 是实数

• b ≠ 0 时，z 是虚数

• a = 0 且 b ≠ 0 时，z 是纯虚数

• a + bi = 0 ⇔ a=0 且 b=0

复数的加减法

(a + bi) ± (c + di) = (a±c) + (b±d)i

• 按多项式相加减的法则进行

• 实部与实部相加减

• 虚部与虚部相加减

• 结果仍为复数

示例
(3 + 2i) + (1 + 4i) = (3+1) + (2+4)i = 4 + 6i
(5 + 3i) - (2 + i) = (5-2) + (3-1)i = 3 + 2i

复数的乘法

(a + bi)(c + di) = (ac - bd) + (ad + bc)i

推导过程

(a + bi)(c + di)
= ac + adi + bci + bdi² → 展开（分配律）
= ac + adi + bci + bd(-1) → 关键：i² = -1
= (ac - bd) + (ad + bc)i → 合并实部与虚部
示例
(2 + 3i)(1 + 2i) = 2 + 4i + 3i + 6i² = 2 + 7i - 6 = -4 + 7i

复数的除法 — 分母实数化

a + bi
c + di = (a + bi)(c - di)
(c + di)(c - di)
= ac + bd
c² + d² + bc - ad
c² + d² i

关键步骤

• 分子分母同乘分母的共轭复数 (c - di)

• 分母变为：c² + d²（实数，因 i² = -1）

• 实现了分母实数化

示例
1/(1 + i) = 1·(1 - i)/[(1 + i)(1 - i)] = (1 - i)/(1 + 1) = 1/2 - 1/2i
