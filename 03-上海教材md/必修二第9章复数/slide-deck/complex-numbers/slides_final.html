💡 核心问题
负数可以开平方吗？如果能，结果是什么形式的数？

历史上，数学家们为了解决这类问题，引入了虚数单位 i，定义为：
i² = -1 或 i = √(-1)
3 / 3

虚数单位 i 的定义

i² = -1

• i 是 -1 的一个平方根

• 即 i = √-1（在复数范围内）

• 任意实数 b∈R 与 i 的乘积记为 bi

• (bi)² = b² · i² = -b²，负数开平方得以解决

4 / 8

复数的定义

z = a + bi    (a, b ∈ R)

基本要素

• 形如 a + bi 的数称为复数

• a 是实部（Real part）

• b 是虚部系数（Imaginary part）

• 全体复数构成集合 C

特殊情形

• b = 0 时，z 是实数

• b ≠ 0 时，z 是虚数

• a = 0 且 b ≠ 0 时，z 是纯虚数

• a + bi = 0 ⇔ a=0 且 b=0

5 / 8

复数的加减法

(a + bi) ± (c + di) = (a±c) + (b±d)i

• 按多项式相加减的法则进行

• 实部与实部相加减

• 虚部与虚部相加减

• 结果仍为复数

示例
(3 + 2i) + (1 + 4i) = (3+1) + (2+4)i = 4 + 6i
(5 + 3i) - (2 + i) = (5-2) + (3-1)i = 3 + 2i
6 / 8

复数的乘法

(a + bi)(c + di) = (ac - bd) + (ad + bc)i

推导过程

(a + bi)(c + di)
= ac + adi + bci + bdi² → 展开（分配律）
= ac + adi + bci + bd(-1) → 关键：i² = -1
= (ac - bd) + (ad + bc)i → 合并实部与虚部
示例
(2 + 3i)(1 + 2i) = 2 + 4i + 3i + 6i² = 2 + 7i - 6 = -4 + 7i
7 / 8

复数的除法 — 分母实数化

a + bi
c + di = (a + bi)(c - di)
(c + di)(c - di)
= ac + bd
c² + d² + bc - ad
c² + d² i

关键步骤

• 分子分母同乘分母的共轭复数 (c - di)

• 分母变为：c² + d²（实数，因 i² = -1）

• 实现了分母实数化

示例
1/(1 + i) = 1·(1 - i)/[(1 + i)(1 - i)] = (1 - i)/(1 + 1) = 1/2 - 1/2i
8 / 8

例题1：复数计算示范

【题目】 已知 z₁ = 3 + 2i，z₂ = 1 - 4i，求：
(1) z₁ + z₂    (2) z₁ - z₂    (3) z₁ · z₂    (4) z₁ ÷ z₂

加减法运算

(1) 加法：

z₁ + z₂ = (3+1) + (2-4)i

        = 4 - 2i


(2) 减法：

z₁ - z₂ = (3-1) + (2+4)i

        = 2 + 6i

乘除法运算

(3) 乘法：

z₁ · z₂ = 3·1 + 3·(-4i) + 2i·1 + 2i·(-4i)

        = 3 - 12i + 2i + 8

        = 11 - 10i


(4) 除法： 分子分母同乘 z₂ 的共轭

z₁/z₂ = (3+2i)(1+4i) / [(1-4i)(1+4i)] = (-5+14i) / 17

实部、虚部与共轭复数

复数的结构

z = a + bi
  • Re(z) = a —— 实部（Real part）
  • Im(z) = b —— 虚部系数（Imaginary part）
  • 当 b = 0 时，z 是实数
  • 当 b ≠ 0 时，z 是虚数
  • 当 a=0 且 b≠0 时，z 是纯虚数

共轭复数

z̄ = a - bi
  • 实部相同，虚部互为相反数
  • z + z̄ = 2a（实数）
  • z - z̄ = 2bi（纯虚数）
  • z · z̄ = a² + b²（实数，≥0）
  • 用于分母实数化
重要关系： z 是实数 ⟺ z = z̄   |   z 是纯虚数 ⟺ z + z̄ = 0 且 z ≠ 0

共轭复数的性质

z̄̄ = z
双重共轭等于自身（对合性质）
z₁ + z₂ 的共轭 = z₁̄ + z₂̄
加法与共轭可交换
z₁ - z₂ 的共轭 = z₁̄ - z₂̄
减法与共轭可交换
z₁ · z₂ 的共轭 = z₁̄ · z₂̄
乘法与共轭可交换
(z₁/z₂) 的共轭 = z₁̄ / z₂̄   (z₂ ≠ 0)
除法与共轭可交换
核心结论：取共轭运算与四则运算可交换，即运算后再取共轭 = 先取共轭再运算

例题2：复数分类讨论

【题目】 设复数 z = (m² - 5m + 6) + (m² - 3m)i，求实数 m 的值，使得：
(1) z 是实数    (2) z 是虚数    (3) z 是纯虚数
情况 (1)：z 是实数
虚部 = 0：m² - 3m = 0
m(m - 3) = 0
∴ m = 0 或 m = 3
情况 (2)：z 是虚数
虚部 ≠ 0：m² - 3m ≠ 0
∴ m ≠ 0 且 m ≠ 3
情况 (3)：z 是纯虚数
需同时满足：
① 实部 = 0：m² - 5m + 6 = 0
   (m-2)(m-3) = 0 → m = 2 或 3

② 虚部 ≠ 0：m ≠ 0 且 m ≠ 3

综合①②：∴ m = 2
解题关键：纯虚数需要同时满足：① 实部为零 ② 虚部不为零

9.2 复数的几何意义

z = a + bi

复数由两个实数确定：实部 a 和虚部系数 b

这让我们联想到平面直角坐标系中的点 (a, b)

复数与平面上的点或向量之间存在一一对应关系

代数视角

  • 代数形式：a + bi
  • 四则运算规则
  • 共轭复数性质

几何视角

  • 复平面上的点
  • 平面向量表示
  • 向量运算法则

复平面（高斯平面）

坐标系定义

  • 横轴（x轴） → 实轴
  • 纵轴（y轴） → 虚轴
  • 原点 O 对应复数 0
  • 点 Z(a,b) ↔ 复数 z = a + bi

|z| = √(a² + b²)
复数的模（到原点的距离）

复数的向量表示与加法

向量表示

  • 复数 z = a + bi
  • 对应向量 OZ→ = (a, b)
  • 零向量对应复数 0

平行四边形法则
复数加法 = 向量加法

例题 3：几何应用

【例题】 已知复数 z₁ = 1 + 2i，z₂ = 3 - i，求 |z₁ - z₂| 并说明其几何意义。

代数解法

z₁ - z₂ = (1 + 2i) - (3 - i)

        = 1 + 2i - 3 + i

        = -2 + 3i

|z₁ - z₂| = √((-2)² + 3²)

        = √(4 + 9)

        = √13

几何意义

|z₁ - z₂| 表示复平面上两点 Z₁ 与 Z₂ 之间的距离
