### 查找"函数单调性"相关资料
```python
import json
with open('00-索引与配置/扩展标签索引.json') as f:
    index = json.load(f)
# 查找标签
files = index['tags_by_parent']['函数']
for tag in files:
    if tag['tag'] == '函数单调性':
        print(tag['files'])
```
