# 定理卡：等角定理

## 内容

如果一个角的两边和另一个角的两边分别平行，并且方向相同，那么这两个角相等。

## 符号表达

已知：$AA' \parallel BB'$，$CC' \parallel DD'$，且方向相同

则：$\angle AOC = \angle BOD$

## 图示

```
    A' ←—— A
   /        \
  /          \
 O            O'
  \          /
   \        /
    C' ←—— C
```

## 推论

| 推论 | 内容 |
|------|------|
| 推论1 | 如果两组相交直线分别平行，那么它们所成的锐角（或直角）相等 |
| 推论2 | 两边分别平行 → 两角相等或互补 |

## 证明思路

1. 构造辅助线，使两角的顶点重合
2. 利用平行四边形的性质
3. 证明对应边相等，从而角相等

## 应用

- 定义异面直线所成的角（平移后角的大小唯一确定）
- 证明角相等时，找平行线代替

## 注意

**方向相同才相等！** 方向相反则互补。
