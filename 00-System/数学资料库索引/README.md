# mini-数学资料库

上海高中数学资料生产库，当前同时包含教材原文、专题讲义、试卷资源、教学切片、索引配置和自动化脚本。

这次整理后的原则是：

- 根目录只保留主要资料目录和正式入口
- `pipeline/` 作为优先使用的脚本入口
- 历史脚本、零散样稿、单次编译产物统一归入 `99-归档备份/`

## 当前推荐入口

### 资料内容

- `01-教材原文-只有文本 没有图片/`：教材纯文本
- `02-讲义输出/`：讲义输出目录
- `03-上海教材md/`：教材 Markdown 主库
- `04-专题资料/`：专题讲义素材
- `0-一模-二模-模考试卷-md版本/`：模考试卷与转换结果
- `切片库-ai/`：按主题组织的教学切片
- `沪教版必修第三册2026-切片卡片版/`：卡片化切片产物

### 索引与文档

- `00-索引与配置/`：索引、数据库、配置说明
- `docs/`：使用文档、演示资料、工作记录
- `Makefile`：常用命令入口

### 脚本与模板

- `pipeline/`：当前优先维护的工作流脚本
- `preamble/`：LaTeX 预设
- `scripts/`：补充脚本
- `10-工具脚本/`：保留少量实验工具，历史版本已迁走，详见目录内 `README.md`

### 归档与临时产物

- `99-归档备份/`：历史脚本、零散样稿、旧版本产物
- `build/`：临时构建目录，可反复清理
- `outputs/`：已生成输出

## 建议工作流

### 备课

1. 先查 `00-索引与配置/` 里的索引文件或数据库
2. 到 `03-上海教材md/` 找教材原文
3. 到 `04-专题资料/` 和 `切片库-ai/` 选素材
4. 需要临时拼装内容时，输出到 `build/`

### 组卷

1. 优先从 `0-一模-二模-模考试卷-md版本/` 和相关索引取题
2. 生成过程优先走 `pipeline/`
3. 最终可发布的结果放 `outputs/`，中间过程放 `build/`

## 常用命令

```bash
make index
make search keyword=导数
make lesson book=必修第一册 chapter=第2章 output=build/备课-等式与不等式
make exam topic=导数 count=5 output=build/组卷素材-导数.md
```

## 当前维护约定

- 根目录不再新增一次性脚本
- 新脚本优先放进 `pipeline/` 或 `scripts/`
- 实验脚本放 `10-工具脚本/`，确认稳定后再迁入正式入口
- 历史文件不直接散落根目录，统一进 `99-归档备份/`
- `build/` 只放临时文件
