# 高中数学教材知识图谱设计文档

## 1. 概述

本文档定义了高中数学教材知识图谱的数据结构和设计规范，用于构建7册教材（必修1-3册、选择性必修1-3册、选修）的完整知识体系。

## 2. 知识节点Schema

### 2.1 节点属性

| 属性名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | string | 是 | 唯一标识符，格式：教材册-章节-知识点名称 |
| name | string | 是 | 知识点名称 |
| type | enum | 是 | 节点类型：概念/定理/公式/方法/例题/习题/拓展 |
| chapter | string | 是 | 所属章节 |
| textbook | enum | 是 | 教材册：必修第一册/必修第二册/... |
| tags | array | 否 | 标签列表，用于分类和检索 |
| prerequisites | array | 否 | 前置知识节点ID列表 |
| related | array | 否 | 相关知识点节点ID列表 |
| content_summary | string | 否 | 内容摘要 |
| difficulty | integer | 否 | 难度等级：1-5 |
| importance | integer | 否 | 重要程度：1-5 |

### 2.2 节点类型说明

- **概念**：数学定义和基本概念
- **定理**：数学定理和性质
- **公式**：数学公式和运算法则
- **方法**：解题方法和技巧
- **例题**：典型例题
- **习题**：练习题
- **拓展**：延伸拓展内容

### 2.3 ID命名规范

格式：`教材册-章节-知识点名称`

示例：
- `必修一-1.1-集合`：必修第一册第1章第1节-集合的概念
- `必修一-1.4-交集`：必修第一册第1章第4节-交集
- `选择性必修一-2.3-等差数列`：选择性必修第一册第2章第3节-等差数列

## 3. 关系类型定义

### 3.1 核心关系

| 关系名 | 方向 | 说明 |
|--------|------|------|
| prerequisite | 单向 | 前置知识，学习当前知识前需要掌握的知识 |
| related | 双向 | 相关知识点，知识点之间的横向关联 |
| extends | 单向 | 延伸拓展，知识点的深化和扩展 |
| example | 单向 | 例题关系，概念与例题之间的关联 |
| application | 单向 | 应用关系，知识在实际问题中的应用 |

### 3.2 辅助关系

| 关系名 | 方向 | 说明 |
|--------|------|------|
| prerequisite_of | 单向 | 被依赖关系，prerequisite的反向 |
| parent | 单向 | 父节点，层级包含关系 |
| child | 单向 | 子节点，parent的反向 |

### 3.3 关系权重

weight属性表示关系强度，取值范围0-1：
- 0.9-1.0：核心依赖/强关联
- 0.7-0.8：重要关联
- 0.5-0.6：一般关联
- 0.1-0.4：弱关联

## 5. 使用示例

### 5.1 创建节点

```json
{
  "id": "必修一-1.1-集合",
  "name": "集合的概念",
  "type": "概念",
  "chapter": "第1章 集合与逻辑",
  "textbook": "必修第一册",
  "tags": ["集合", "基础概念"],
  "prerequisites": [],
  "related": ["必修一-1.2-集合的表示法"],
  "content_summary": "集合是数学中的基本概念...",
  "difficulty": 1,
  "importance": 5
}
```

### 5.2 创建关系

```json
{
  "source": "必修一-1.1-集合",
  "target": "必修一-1.1-集合的表示法",
  "relation": "extends",
  "weight": 0.8,
  "description": "集合表示法是集合概念的延伸"
}
```

## 6. 扩展说明

### 6.1 跨册关联

知识点可以跨教材册建立关联，例如：
- 必修一的"函数概念" → prerequisite → 必修二的"指数函数"
- 必修一的"集合" → related → 选择性必修一的"集合与简易逻辑"

### 6.2 难度与重要度评估

- **difficulty（难度）**：
  - 1：基础概念，容易理解
  - 2：需要一定思考
  - 3：中等难度，需要练习
  - 4：较难，需要深入理解
  - 5：高难度，综合性强

- **importance（重要度）**：
  - 1-2：了解即可
  - 3：一般重要
  - 4：重要
  - 5：核心知识，必须掌握
