## 🔧 子 Agent 任务分配

### Agent 1: 目录整理专员
**任务**: 重组文件目录结构
**输入**: 当前混乱的目录
**输出**: 按新结构组织的文件
**命令**: 
```bash
# 创建新目录结构
mkdir -p 01-教材原文/{必修第{一,二,三,四}册,选择性必修第{一,二,三}册}
# 移动和重命名文件
```

### Agent 2: MD 文件处理器
**任务**: 标准化 MD 文件格式
**输入**: `03-上海教材md/` 中的原始 MD
**输出**: 清理后的标准格式 MD
**处理内容**:
- 统一标题层级
- 标准化数学公式标记
- 提取习题到单独文件

### Agent 3: LaTeX 讲义生成器
**任务**: 批量生成讲义
**输入**: 标准化后的 MD 文件
**输出**: `.tex` 文件
**并行度**: 每章一个任务

### Agent 4: 真题整理专员
**任务**: 整理真题和试卷
**输入**: `0-一模-二模/` 和 `17-25上海真题试卷/`
**输出**: 按年份和类型组织的试卷库

### Agent 5: 资源去重专员
**任务**: 检测和清理重复文件
**输入**: 全库扫描
**输出**: 去重后的文件列表

## 📋 执行计划

1. **Phase 1**: Agent 1 创建新目录结构
2. **Phase 2**: Agent 2 + Agent 3 并行处理教材
3. **Phase 3**: Agent 4 整理真题
4. **Phase 4**: Agent 5 清理和归档

## ⚠️ 注意事项

- 先备份再移动文件
- 保留原始文件直到确认新结构可用
- 生成文件清单便于回滚
