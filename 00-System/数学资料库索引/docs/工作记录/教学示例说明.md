## 设计亮点

### 1. 教学流程闭环

```
概念引入 → 学生探索 → 解答示范 → 教师总结 → 变式训练 → 错误警示 → 知识卡片
```

### 2. 认知负荷管理

- **学生思路**：降低焦虑，让学生看到"原来我也这么想"
- **教师点睛**：及时纠偏，防止形成错误定势
- **步骤拆解**：复杂问题分步处理
- **对比分析**：正反对比强化理解

### 3. 知识迁移设计

- **变式1**：改变区间（横向变化）
- **变式2**：引入参数（纵向深化）
- 形成"基础→变化→综合"的梯度

### 4. 视觉层次清晰

| 颜色 | 含义 | 使用场景 |
|:-----|:-----|:---------|
| 🟣 紫罗兰 | 学生视角 | 思考过程 |
| 🔴 深红 | 教师权威 | 关键提醒 |
| 🔵 青色 | 拓展训练 | 变式题目 |
| 🟠 橙色 | 轻量提示 | 解题技巧 |
| 🟤 砖红 | 警示错误 | 常见错误 |

## 使用建议

### 在现有章节中插入

1. **找到合适的例题**
2. **在解答前添加学生思路**：
   ```latex
   \begin{studentthinking}[初见此题]
   学生看到题目时的第一反应......
   \end{studentthinking}
   ```

3. **在关键步骤后添加教师点睛**：
   ```latex
   \begin{teacherinsight}[关键提醒]
   这里最容易出错的是......
   \end{teacherinsight}
   ```

4. **例题后添加变式训练**：
   ```latex
   \begin{variation}[改变条件]
   变式题目......
   \end{variation}
   ```

### 完整教学流程模板

```latex
\begin{example}[题目]
......
\end{example}

\begin{studentthinking}
......
\end{studentthinking}

\begin{solution}
......
\begin{teacherinsight}
......
\end{teacherinsight}
\end{solution}

\begin{variation}
......
\end{variation}

\begin{commonerror}
......
\end{commonerror}
```
