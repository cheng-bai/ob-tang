## 追加记录：浦东加工版公式与图片修正复盘

### 问题

用户指出：

```text
outputs/试卷MD加工/2026届浦东新区高三下二模数学试卷-加工版.md
```

中的数学公式没有正常保留，图片也没有做到可靠校验。

### 直接原因

前一版加工脚本使用了：

```text
0-一模-二模-模考试卷-md版本/md输出/2026届浦东新区高三下二模数学试卷（解析版）/2026届浦东新区高三下二模数学试卷（解析版）.md
```

这个文件已经在转换过程中损失了大量 LaTeX 结构，出现了 ``、``、`` 等乱码符号。脚本只是做结构重排，因此把坏公式原样带进了加工版。

更合适的源文件是：

```text
0-一模-二模-模考试卷-md版本/2026届浦东新区高三下二模数学试卷（解析版）/2026届浦东新区高三下二模数学试卷（解析版）-dollar.md
```

该文件保留了 `$...$`、`$$...$$`、`\frac`、`\left`、`\right` 等 LaTeX 数学表达，并包含正确的图片引用。

### 更深层原因

1. 只验证了“能切出题目”，没有验证“数学公式质量”。
2. 没有比较同一试卷目录下多个 Markdown 版本的质量。
3. 图片只保留了原始相对路径，没有复制到加工版输出目录旁边。
4. `pipeline/utils/更新索引.py` 当时只支持 `## 1．` 题号格式，不能解析 `-dollar.md` 中的 `1. 题干` 格式。

### 修正动作

1. 修改 `pipeline/utils/更新索引.py`
   - 支持 `1. 题干` 与 `## 1．题干` 两种题号格式。
   - `exam_questions` 优先从 2026 二模的 `*-dollar.md` 抽题。
   - 图片引用写入 `images_json`。

2. 修改 `pipeline/build/润色试卷MD.py`
   - 使用 `-dollar.md` 重新生成加工版。
   - 自动复制题目图片到加工版旁边的 `*-images/` 目录。
   - 自动改写图片相对路径，保证加工版移动后仍可渲染图片。
   - 日志记录 `copied_images` 和 `missing_images`。

3. 清理 `00-索引与配置/加工日志.jsonl`
   - 移除旧的 `md输出/...md` 加工记录。
   - 保留当前 `-dollar.md` 的有效记录。

### 背景

### 关键设计

- 教师版：题目、知识点总览、教学标签、答案、解析、题干图与解析图。
- 学生版：仅保留题目、知识点总览、题干图与作答空间；源码层面不写入答案、解析、教学标签。
- 知识点总览保留按上海高中数学板块分组，并通过 `hyperref` 跳转到题号。
- 图片复制到 LaTeX 输出目录的 `images/`，编译时使用相对路径。
- 对 Markdown 残留 HTML 表格做简单 LaTeX 表格转换。
- 对 OCR 残留符号做专项修复：弧线符号改为 `\overset{\frown}{...}`，第 12 题异常箭头式改为 `underbrace`。

### 子任务审阅与迭代

已派子任务做成品审阅。根据审阅意见完成两轮迭代：

- 学生版从“条件隐藏答案”改为“生成时净化源码”。
- 教师版从“题目框包住整段答案解析”改为“题目框、标签框、答案框、解析框分离”，降低长题爆版风险。
- 清理缺字、未定义引用、横向溢出和 tcolorbox 大框溢出。
