## 依赖关系设计原则

### 1. 基础切片（无前置知识）
以下切片作为学习起点，不依赖其他切片：
- 集合的运算与常用逻辑用语 (ID: 4)
- 不等式的性质与求解 (ID: 9)
- 柱体、锥体与球的表面积和体积 (ID: 21)

### 2. 核心知识路径

#### 函数主线
```
集合/不等式 → 函数概念 → 幂指对函数 → 指数对数方程/导数概念
```

#### 三角函数主线
```
函数概念 → 任意角与三角比 → 三角恒等变换 → 解三角形/三角函数图像
```

#### 解析几何主线
```
平面向量 → 直线 → 圆 → 椭圆 → 双曲线 → 抛物线
```

#### 立体几何主线
```
几何体基础 → 空间直线与平面 → 空间向量 → 空间向量应用
```

#### 概率统计主线
```
集合 → 古典概率 → 条件概率 → 随机变量 → 统计分析
```

### 3. 跨模块依赖

- **三角函数** 依赖 **函数概念**
- **平面向量** 依赖 **函数概念**
- **空间向量** 依赖 **平面向量** + **空间几何**
- **导数** 依赖 **幂指对函数** + **三角函数**
- **数列** 依赖 **函数概念**
- **解析几何** 依赖 **平面向量**

## 智能学习路径推荐功能

### 功能特性

1. **完整课程路径**: 基于拓扑排序生成43个切片的完整学习顺序
2. **分类路径**: 生成特定分类（如解析几何）的学习路径
3. **目标导向路径**: 为特定切片生成完整的前置知识学习路径
4. **智能推荐**: 基于已学内容推荐下一步学习
5. **缺失知识检测**: 识别学习某切片前缺失的前置知识

### 推荐算法

- 使用**拓扑排序**确保前置知识先于后续内容学习
- 基于**难度**、**依赖数量**、**前置完成度**计算推荐分数
- 支持**个性化学习路径**生成
