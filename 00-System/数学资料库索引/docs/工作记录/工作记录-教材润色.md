# 教材润色工作记录

## 工作概述
使用 Claude Code 润色沪教版高中数学教材 Markdown 文件，修复标题层级结构，清理无意义文本，规范格式。

## 润色内容

### 1. 标题层级修复

| 层级 | Markdown 标记 | 内容类型 |
|------|---------------|----------|
| 一级 | `#` | 前言、目录、第X章、附录 |
| 二级 | `##` | 10.1/6.1等小节、内容提要、复习题 |
| 三级 | `###` | 1/2/3等子节 |
| 四级 | `####` | 练习、习题 |
| 五级 | `#####` | A组、B组 |

### 2. 清理内容

- **删除无意义文本**："细目标题第二题 MONE SHE TAND BART 牛肉鸡" 等乱码
- **删除多余空行**：合并连续4个以上空行为3个
- **删除孤立副标题**：单独的"空间直线"、"空间直线与平面"等文本
- **规范数学公式标记**：`$ $` 格式统一

### 3. 目录处理

- 原文件目录中的章标题 → 转换为列表项（`- 第X章 标题`）
- 正文中的章标题 → 转换为一级标题（`# 第X章 标题`）
- 自动检测目录结束位置（遇到小节标题如 `### 6.1` 或带 `#` 的章标题）

## 使用的 Skill

- **Skill 名称**: polish-textbook
- **Skill 路径**: `~/.claude/skills/polish-textbook/`
- **主脚本**: `polish_textbook.py`
- **功能**: Markdown 教材润色，修复标题层级，清理格式

### 使用方法

```bash
# 润色单个文件
python3 polish_textbook.py input.md

# 指定输出文件名
python3 polish_textbook.py input.md output.md
```
