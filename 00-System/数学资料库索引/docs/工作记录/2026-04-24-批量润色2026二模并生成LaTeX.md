# 2026-04-24 批量润色 2026 二模并生成 LaTeX PDF

## 背景

用户要求继续处理 `0-一模-二模-模考试卷-md版本/` 下 2026 年二模试卷 Markdown：

1. 先复制并润色 Markdown，做好加工署名。
2. 再输出为 LaTeX。
3. 最终全部编译成教师版/学生版 PDF。
4. 完成后由独立子 agent 做评价。

## 本次新增脚本

```text
pipeline/build/批量处理2026二模试卷.py
```

该脚本执行完整批处理：

- 只扫描原始 `*-dollar.md`。
- 排除 `md输出/` 和“一模/分类汇编”等非本次目标文件。
- 输出 AI 润色版 Markdown 到 `outputs/试卷MD加工/2026二模批量润色/`。
- 调用 `pipeline/build/试卷MD转LaTeX讲义.py` 生成教师版/学生版 `.tex`。
- 使用 `latexmk -xelatex` 编译 PDF。
- 编译前清理中间文件，避免旧的 `latexmk` 失败状态污染结果。
- 输出机器报告 `outputs/试卷LaTeX讲义/2026二模批量输出/batch-report.json`。
