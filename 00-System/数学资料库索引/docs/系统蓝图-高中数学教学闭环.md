# 高中数学教学闭环系统蓝图

## 目标

把这个库建设成一套服务高中数学教师日常工作的资料系统，而不是单纯的文件堆。

最终要支持的闭环是：

1. 从教材定位本节核心知识
2. 从切片和专题中抽取讲授素材
3. 从试卷库里匹配训练素材
4. 生成讲义、练习、课堂方案
5. 上课与作业后回写易错点、替换题、讲法优化
6. 下次备课直接复用和迭代

## 系统分层

### 1. 原始内容层

- `01-教材原文-只有文本 没有图片/`
- `03-上海教材md/`
- `0-一模-二模-模考试卷-md版本/`
- `上海高考真题汇编及变式详解版——下册/`

要求：

- 尽量保留原始来源
- 不在原始目录里混放测试文件和中间产物

### 2. 教学加工层

- `04-专题资料/`
- `切片库-ai/`
- `沪教版必修第三册2026-切片卡片版/`
- `02-讲义输出/`

要求：

- 每份内容都要服务于教学动作
- 同一知识点尽量形成“概念 - 定理 - 方法 - 例题 - 练习”链条

### 3. 系统治理层

- `00-索引与配置/`
- `pipeline/`
- `docs/`

职责：

- 建索引
- 做质量审计
- 管理内容准入和归档规则
- 固定教师使用流程

### 4. 生成与临时层

- `build/`
- `outputs/`

要求：

- `build/` 只放临时结果
- `outputs/` 只放可复用产物
- 预览图、测试 tex、调试 pdf 不进入正式内容层

### 5. 归档层

- `99-归档备份/`

用途：

- 保存历史脚本
- 保存旧样稿
- 保存低质量但暂不删除的材料

## 核心资源类型

### 教材资源

作用：

- 作为备课锚点
- 确保所有讲授都能回到教材章节

### 专题讲义

作用：

- 做跨教材知识点归纳
- 支撑二轮复习和专题突破

### 切片

作用：

- 把数学内容拆成可组合、可复用的最小教学单元
- 服务微课、正课、复习课、讲评课

### 试卷素材

作用：

- 提供课堂练习、作业、讲评和阶段检测素材
- 未来要逐步从“试卷文件索引”升级成“单题索引”

### 讲义产物

作用：

- 对外输出给学生或教师
- 是教学动作的最终承载体

## 教师日常工作流

### 备课

1. 先查教材章节
2. 再查知识点对应切片
3. 再补专题讲义
4. 再抽取试卷素材
5. 生成本节备课清单

### 讲课

1. 课堂主线来自教材
2. 讲法来自切片和专题
3. 训练来自试卷素材

### 讲后回写

每节课结束后至少回写三类信息：

- 学生最常见错误
- 本节最有效讲法
- 下次要替换或补充的题目

## 系统当前短板

- 试卷层目前仍以文件级索引为主
- 部分教材转换结果含噪音残留
- 切片元数据还不够统一
- 讲后反馈回写机制还没有独立目录和表结构

## 未来建设方向

1. 完成试卷到题目的结构化拆分
2. 给切片、专题、讲义统一补元数据
3. 增加“易错点 / 课堂反馈 / 替换题”回写目录
4. 逐步把这个库变成个人教学知识库与产出系统
