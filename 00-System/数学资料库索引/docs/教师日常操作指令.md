# 教师日常操作指令

## 一、先更新索引

```bash
make index
```

等价命令：

```bash
python3 pipeline/utils/更新索引.py --verbose
```

用途：

- 重建数据库
- 更新教材 / 切片 / 试卷索引
- 生成质量审计报告

## 二、检索内容

```bash
make search keyword=函数单调性
```

等价命令：

```bash
python3 pipeline/utils/检索.py 函数单调性
```

## 三、生成备课清单

```bash
make lesson book=必修第一册 chapter=第2章 output=build/备课-等式与不等式
```

等价命令：

```bash
python3 pipeline/build/备课.py \
  --book 必修第一册 \
  --chapter 第2章 \
  --output build/备课-等式与不等式
```

## 四、润色试卷 Markdown

```bash
make polish-md input=0-一模-二模-模考试卷-md版本/md输出/某试卷/某试卷.md output=outputs/试卷MD加工/某试卷-加工版.md
```

等价命令：

```bash
python3 pipeline/build/润色试卷MD.py \
  --input 0-一模-二模-模考试卷-md版本/md输出/某试卷/某试卷.md \
  --output outputs/试卷MD加工/某试卷-加工版.md
```

用途：

- 保留原始转换稿
- 生成统一排版的加工版
- 补充题目知识点和学生易卡点
- 记录到 `00-索引与配置/加工日志.jsonl`

## 五、生成组卷素材清单

```bash
make exam topic=导数 count=8 output=build/组卷素材-导数.md
```

等价命令：

```bash
python3 pipeline/build/组卷.py \
  --知识点 导数 \
  --数量 8 \
  --输出 build/组卷素材-导数.md
```

## 六、你每天最该做的动作

### 备课前

1. 更新索引
2. 检索知识点
3. 生成备课清单

### 上课后

1. 把临时测试稿、预览稿归回 `build/` 或归档
2. 把真正保留下来的内容回写到正式目录
3. 再跑一次索引

## 七、不要做的事

- 不要把一次性脚本放根目录
- 不要把 `test_*` 和 `preview*` 放在正式内容目录
- 不要继续制造 `final-v2-ultimate` 一类命名
- 不要把中间文件当成正式成果
