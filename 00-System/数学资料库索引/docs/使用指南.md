## 推荐使用方式

### 1. 检索资料

```bash
make search keyword=基本不等式
python3 pipeline/utils/检索.py 基本不等式
python3 pipeline/utils/检索.py 三角函数
```

适合先确认教材、切片、真题是否已经入库。

### 2. 生成备课清单

```bash
make lesson book=必修第一册 chapter=第2章 output=build/备课-等式与不等式

python3 pipeline/build/备课.py \
  --book 必修第一册 \
  --chapter 第2章 \
  --output build/备课-等式与不等式 \
  --no-slices
```

说明：

- `build/` 放中间结果
- 需要复制切片时，去掉 `--no-slices`

### 3. 尝试组卷

```bash
make exam topic=导数 count=5 output=build/练习-导数.md

python3 pipeline/build/组卷.py \
  --知识点 导数 \
  --数量 5 \
  --输出 build/练习-导数.md
```

注意：当前题库索引仍偏“文件级”，不是稳定“单题级”，所以组卷结果只能作为辅助草稿，不能直接视为最终成卷。

## 当前目录规则

### 应继续往里放内容的目录

- 教材原文放 `01-教材原文-只有文本 没有图片/` 或 `03-上海教材md/`
- 专题讲义放 `04-专题资料/`
- 切片放 `切片库-ai/` 或卡片化目录
- 索引和配置放 `00-索引与配置/`

### 不建议再继续堆东西的目录

- 根目录：不再放一次性脚本和零散 tex/pdf
- `10-工具脚本/`：只保留少量实验工具，新脚本不优先放这里

### 一次性文件应该去哪里

- 临时测试输出：`build/`
- 正式产物：`outputs/`
- 历史样稿与旧脚本：`99-归档备份/`

## 这次整理后新增的约定

1. 根目录不再新增 `*_v2.py`、`*_final.py` 这类脚本
2. 需要长期维护的脚本统一收进 `pipeline/` 或 `scripts/`
3. LaTeX 的 `.aux/.log/.toc/.out` 等中间文件不再保留在根目录
4. 零散样稿统一进 `99-归档备份/零散样稿与编译产物/`
5. 根目录历史脚本统一进 `99-归档备份/legacy-root-scripts/`
6. `10-工具脚本/` 里的历史版本和调试脚本统一进 `99-归档备份/10-工具脚本-历史版本/`
