# 内容治理规范

## 一、总原则

这个库的核心目标不是“尽可能多存文件”，而是“让老师能更快找到高质量内容并稳定复用”。

因此，任何内容进入正式层，都要满足两个条件：

1. 与高中数学教学直接相关
2. 质量达到可复用标准

## 二、资源生命周期

每份内容都应该落在以下状态之一：

- `raw`
  原始来源，未经充分清洗
- `curated`
  已清洗，可用于教学参考
- `indexed`
  已进入系统索引，可被检索
- `published`
  可直接用于课堂或发给学生
- `archived`
  历史版本、低质量版本或非核心内容

## 三、什么内容允许进入正式层

### 允许保留

- 教材原文
- 清洗后的教材 Markdown
- 结构清楚的专题讲义
- 可复用的切片和卡片
- 可追溯来源的试卷与解析
- 正式讲义产物
- 服务教学系统本身的文档与脚本

### 必须归档或清理

- `test_*`、`debug_*`、`preview*`、`sample*`
- `v1 / v2 / v3 / final / perfect / ultimate` 这类历史试错版本
- 模板实验产物，如 `maki原版`
- 预览图片、临时编译文件、局部调试 pdf/tex
- 与高中数学教学无直接关系的展示型材料

## 四、质量判定标准

### A 级：正式可复用

满足以下大部分条件：

- 标题清晰
- 路径规范
- 可直接定位知识点
- 内容无明显占位符
- 无明显转换噪音
- 能明确判断用途

### B 级：可保留待完善

- 内容相关
- 基本可读
- 但元数据不完整或有少量噪音

处理方式：

- 保留在正式层
- 标记后续补元数据或修订

### C 级：应归档

符合以下任一情况：

- 只用于调试
- 只是预览或中间产物
- 已有更高质量替代版本
- 明显残缺
- 含大量占位内容或转换噪音

## 五、命名与目录要求

### 根目录

- 不新增一次性脚本
- 不新增零散 tex/pdf/png

### 正式脚本

- 一律优先进入 `pipeline/`
- 兼容脚本放 `scripts/`
- 实验脚本才允许进入 `10-工具脚本/`

### 内容命名

- 优先用“主题 + 类型”的命名方式
- 避免 `new`、`final2`、`最新版最终版`
- 避免路径前后空格

## 六、元数据最低要求

### Markdown 内容

建议统一使用 frontmatter，至少包含：

- `title`
- `content_type`
- `book` 或 `topic`
- `tags`
- `status`
- `source`

### LaTeX 内容

建议在文件头部注释中补：

- 标题
- 类型
- 对应知识点
- 来源
- 状态

## 七、质量审计规则

当前系统重点关注以下问题：

- `<!-- Meanless -->` 一类转换残留
- `待补充` 一类占位内容
- `示例定义 / 示例题目 / 解答过程...` 一类模板占位内容
- `test_* / preview* / sample* / maki原版` 一类低质量或非正式产物

## 八、教师维护要求

每次新增内容后，至少做两件事：

1. 执行 `python3 pipeline/utils/更新索引.py`
2. 看 `00-索引与配置/质量审计报告.md`

如果新增内容被标成清理候选，必须决定：

- 修
- 归档
- 删除
