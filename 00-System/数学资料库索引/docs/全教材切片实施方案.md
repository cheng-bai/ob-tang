  - `03-上海教材md/上海数学教参 word 版本/`

已经确认覆盖：

但还没有一个“面向全教材批量切片”的正式总控入口。

## 应该怎么用这些素材

### 源数据优先级

建议按以下顺序使用：

1. `03-上海教材md/`
2. `03-上海教材md/2026教材高清精校版 最新版本上海教材 /`
3. `01-教材原文-只有文本 没有图片/`
4. 教参与课程标准作为补充参考，不直接当切片正文

原因：

- `03-上海教材md/` 目录已经包含 `images/`、`result.json`、`*-dollar.md`，适合直接切片。
- `01-教材原文-只有文本 没有图片/` 更像兜底文本源，适合缺图或结构缺失时回填。
- 教参适合生成“教学提示、易错点、讲法建议”，不适合直接替代教材正文。

### 产物应该分成三层

#### A. 原子卡片层

最小教学单元，类型固定：

- `章首卡`
- `节首卡`
- `概念卡`
- `公式卡`
- `公理卡`
- `定理卡`
- `推论卡`
- `方法卡`
- `例题卡`
- `练习卡`
- `误区卡`

#### B. 系统骨架层

把原子卡片重排成可学路径：

- `导航层`
- `知识层映射`
- `方法层脚手架`
- `训练层闭环`
- `一周学习路径`

#### C. 教学增强层

基于教材和教参补充：

- `易错点`
- `讲法提示`
- `替换题入口`
- `与真题切片的链接`

## 全教材批量切片的推荐做法

### 阶段 1：先统一格式，不急着做漂亮

目标：

- 所有册别先切出结构一致的卡片库
- 每张卡片先有稳定命名、frontmatter 和链接

不追求：

- 一开始就把每张卡都写得很漂亮
- 一开始就补全全部例题和练习

### 阶段 2：按册批量跑，再按章修

建议顺序：

1. `必修第一册`
2. `必修第二册`
3. `必修第三册`
4. `选择性必修第一册`
5. `选择性必修第二册`
6. `选择性必修第三册`
7. `必修第四册`

理由：

- 前三册是教材主干，最先产生复用价值。
- `必修第三册` 已有样板，可作为卡片规范基线。
- 选择性必修与数学建模可以在主流程稳定后接入。

### 阶段 3：建立正式总控入口

建议新增正式脚本：

- `pipeline/build/批量教材切片.py`

它负责：

1. 扫描 `03-上海教材md/`
2. 识别册别、章节、主 Markdown、图片目录、result.json
3. 调用统一切片规则
4. 输出到标准目录
5. 生成总索引与进度报告

## 子 Agent 分工建议

### Agent A：教材覆盖审计

职责：

- 核对每册每章是否齐全
- 标出缺图、缺 `result.json`、缺 `*-dollar.md` 的目录

### Agent B：切片规则统一

职责：

- 定义从教材标题到卡片类型的映射规则
- 固定命名和 frontmatter

### Agent C：批量执行器

职责：

- 编写 `pipeline/build/批量教材切片.py`
- 输出批量运行日志和失败清单

### Agent D：质量复核

职责：

- 抽样检查每册 1-2 章
- 专查定义错误、条件缺失、误切片、空卡片

## 我建议的近期执行顺序

1. 先写正式总控脚本，不再继续堆 `convert_v5.py`
2. 用总控脚本先跑 `必修第一册`
3. 复核命名、frontmatter、卡片类型是否稳定
4. 再批量跑其余册别
5. 最后逐册补系统骨架和训练题包

## 需要你拍板的 4 个决策

### 决策 1：正式产物放哪里

我建议放：

- `06-教材切片库/`

而不是继续分散到多个“单册实验目录”。

### 决策 2：优先切什么版本

我建议以 `03-上海教材md/` 为主源，而不是 `01-教材原文-只有文本 没有图片/`。

### 决策 3：切片目标是“教材忠实切分”还是“教学重组切分”

两者区别：

- 教材忠实切分：更接近原书结构，方便溯源。
- 教学重组切分：更适合课堂，但更依赖人工/规则重排。

我建议：

- 第 1 轮先做“教材忠实切分”
- 第 2 轮再叠加“教学重组骨架”

### 决策 4：是否把教参并入第一轮

我建议第一轮不要直接并正文，只做：

- `teaching_tips`
- `common_mistakes`
- `teacher_notes`

## 当前最合理的下一步

如果不再改方向，下一步就直接做两件事：

1. 新建 `pipeline/build/批量教材切片.py`
2. 先跑 `必修第一册` 的全章切片

这样能最快验证“全教材切片”是不是已经进入可规模化状态。
