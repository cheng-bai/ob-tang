## 核心成果展示

### 1. 试卷分类编汇系统

```json
{
  "exams": [
    {
      "id": "2026-chongming-二模",
      "year": 2026,
      "region": "崇明区",
      "type": "二模",
      "files": [...],
      "knowledge_distribution": {...}
    }
  ]
}
```

**使用方式**：
```python
# 智能组卷示例
python 10-工具脚本/smart_exam_generator.py \
    --knowledge "函数单调性,导数应用" \
    --difficulty 3 \
    --count 10
```

### 2. 卡片模板系统

**Frontmatter标准**：
```yaml
---
card_type: 例题卡
id: 10.1.7
title: 例1 三角形重心
chapter: 空间直线与平面
knowledge_points: ["重心", "三线共点"]
difficulty: 2
---
```

**使用方式**：
```bash
# 将卡片转换为PPT
npx openskills read baoyu-slide-deck
# 然后按技能说明生成
```

### 3. 知识图谱系统

**节点结构**：
```json
{
  "id": "必修一-1.1-集合的概念",
  "name": "集合的概念",
  "type": "概念",
  "tags": ["集合", "基础概念"],
  "prerequisites": [],
  "related": ["必修一-1.1-元素与集合的关系"],
  "difficulty": 1,
  "importance": 5
}
```

**使用方式**：
- 查询前置知识：`prerequisites` 字段
- 查找相关知识点：`related` 字段
- 按标签筛选：`tags` 字段
