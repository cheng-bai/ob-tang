# 讲义转PPT卡片模板规范

> 版本：v1.0
> 适用范围：沪教版高中数学切片卡片制作
> 用途：标准化卡片格式，便于自动转换为PPT

---

## 一、文件命名规范

### 1.1 命名格式

```
{章节编号}-{卡片类型}-{内容简述}.md
```

### 1.2 示例

| 文件名 | 说明 |
|--------|------|
| `10.1.1-概念卡-空间的点直线与平面.md` | 第10章第1节第1张，概念卡 |
| `10.1.2-公理卡-公理1.md` | 第10章第1节第2张，公理卡 |
| `10.1.7-例题卡-例1三角形重心.md` | 第10章第1节第7张，例题卡 |
| `10.2.4-方法卡-异面直线所成的角.md` | 第10章第2节第4张，方法卡 |
| `10.1.9-练习卡-练习10.1(1).md` | 第10章第1节第9张，练习卡 |

### 1.3 编号规则

- 章首：`{章号}.0`（如 `10.0`）
- 节首：`{章号}.{节号}.0`（如 `10.2.0`）
- 卡片：`{章号}.{节号}.{序号}`（如 `10.1.1`）

---

## 二、通用Frontmatter规范

所有卡片必须包含YAML frontmatter，位于文件开头：

```yaml
---
source: 沪教版必修第三册2026
section: "10.1"
slice_type: 概念卡
title: 空间的点、直线与平面
tags: [空间几何, 基础概念]
difficulty: 基础
---
```

### 2.1 通用字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source` | string | 是 | 教材来源 |
| `section` | string | 是 | 章节编号（如"10.1"） |
| `slice_type` | string | 是 | 卡片类型（见下文） |
| `title` | string | 建议 | 卡片标题 |
| `tags` | array | 否 | 标签数组 |
| `difficulty` | string | 否 | 难度：基础/中等/困难 |

## 三、五种标准卡片模板

### 3.1 概念卡

用于定义、性质、说明类内容。

#### Frontmatter

```yaml
---
source: 沪教版必修第三册2026
section: "10.1"
slice_type: 概念卡
concept: 空间的点直线与平面
category: 基础概念
difficulty: 基础
---
```

#### 专属字段

| 字段 | 说明 |
|------|------|
| `concept` | 概念名称 |
| `category` | 概念分类 |

#### 内容结构模板

```markdown
# 概念卡：{概念名称}

## 定义

[简明扼要的定义描述]

## 性质/特性

| 对象 | 特性 | 表示 |
|------|------|------|
| 点 | 无大小 | 大写字母 $A, B, C$ |
| 直线 | 无粗细，无限延伸 | 小写字母 $a, b, c$ |

## 说明/要点

- 要点1
- 要点2

## 易错点

- 常见错误1 ❌
- 常见错误2 ❌
```

#### 示例

```markdown
---
source: 沪教版必修第三册2026
section: "10.1"
slice_type: 概念卡
concept: 空间的点直线与平面
---

# 概念卡：空间的点、直线与平面

## 基本规定

| 对象 | 特性 | 表示 |
|-----|------|------|
| 点 | 无大小 | 大写字母 $A, B, C$ |
| 直线 | 无粗细，无限延伸 | 小写字母 $a, b, c$ 或两点 $AB$ |
| 平面 | 无厚薄，无限延展 | 希腊字母 $\alpha, \beta, \gamma$ |

## 平面画法

- 用**平行四边形**示意
- 水平放置：锐角约 $45°$，横边 ≈ 邻边2倍
- 被遮挡部分画**虚线**

## 易错点

- 平行四边形的边 ≠ 平面边界
```

### 3.2 定理卡

用于定理内容、证明思路。

#### Frontmatter

```yaml
---
source: 沪教版必修第三册2026
section: "10.3"
slice_type: 定理卡
theorem: 线面平行判定
type: 判定定理
difficulty: 中等
---
```

#### 专属字段

| 字段 | 说明 |
|------|------|
| `theorem` | 定理名称 |
| `type` | 定理类型：判定定理/性质定理/等角定理 |

#### 内容结构模板

```markdown
# 定理卡：{定理名称}

## 内容

[定理的文字描述]

## 符号表达

$$[数学公式表达]$$

## 条件/要素

1. 条件1
2. 条件2
3. 条件3

## 证明思路

[简要说明证明的关键步骤]

## 推论/应用

- 推论1
- 推论2

## 注意/易错

- 注意事项
```

#### 示例

```markdown
---
source: 沪教版必修第三册2026
section: "10.3"
theorem: 线面平行判定
slice_type: 定理卡
---

# 定理卡：线面平行判定定理

## 内容

平面外一条直线与此平面内的一条直线平行 → 该直线与此平面平行

## 符号表达

$$\begin{cases} a \not\subset \alpha \\ b \subset \alpha \\ a \parallel b \end{cases} \Rightarrow a \parallel \alpha$$

## 三要素（缺一不可）

1. $a$ 在 $\alpha$ 外（$a \not\subset \alpha$）
2. $b$ 在 $\alpha$ 内（$b \subset \alpha$）
3. $a \parallel b$

## 使用场景

证"线面平行"时，优先在平面内找一条与已知直线平行的线

## 注意

三要素缺一不可，缺少任一个条件都不能得出结论
```

### 3.3 例题卡

用于例题展示、解析、答案。

#### Frontmatter

```yaml
---
source: 沪教版必修第三册2026
section: "10.1"
slice_type: 例题卡
example: 1
topic: 三角形重心
difficulty: 中等
---
```

#### 专属字段

| 字段 | 说明 |
|------|------|
| `example` | 例题编号 |
| `topic` | 题目主题 |

#### 内容结构模板

```markdown
# 例题卡：例{编号}（{主题}）

## 题目

[完整的题目描述]

## 思路分析

[解题思路的文字描述]

## 标准步骤

1. 步骤1
2. 步骤2
3. 步骤3

## 关键入口

[总结解题的关键突破口]

## 变式/拓展

[可选：相关变式题]
```

#### 示例

```markdown
---
source: 沪教版必修第三册2026
section: "10.1"
example: 1
slice_type: 例题卡
---

# 例题卡：例1（三角形重心）

## 题目

$\triangle ABC$ 三顶点 $A, B, C$ 都在平面 $\alpha$ 上，求证：重心 $G$ 也在 $\alpha$ 上。

## 思路

证 $G \in \alpha$ → 证 $G$ 在某条在 $\alpha$ 内的直线上

## 标准步骤

1. $AB \subset \alpha$（公理1：$A, B \in \alpha$）
2. $M \in \alpha$（$M$ 为 $AB$ 中点，$M \in AB$）
3. $CM \subset \alpha$（公理1：$C, M \in \alpha$）
4. $G \in \alpha$（$G$ 在 $CM$ 上，重心分中线 $2:1$）

## 关键入口

**先证线在面内，再证点在线上**
```

### 3.4 方法卡

用于解题方法、步骤总结。

#### Frontmatter

```yaml
---
source: 沪教版必修第三册2026
section: "10.1"
slice_type: 方法卡
method: 斜二测画法
category: 作图方法
difficulty: 基础
---
```

#### 专属字段

| 字段 | 说明 |
|------|------|
| `method` | 方法名称 |
| `category` | 方法分类 |

#### 内容结构模板

```markdown
# 方法卡：{方法名称}

## 适用场景

[说明此方法适用于什么类型的问题]

## 核心规则

| 原图形 | 直观图 |
|-------|--------|
| $x$ 轴方向 | 长度**不变** |
| $y$ 轴方向 | 长度变为**一半** |

## 步骤

1. 步骤1
2. 步骤2
3. 步骤3

## 示例

[具体示例说明]

## 易错点

- 错误1 ❌
- 错误2 ❌
```

#### 示例

```markdown
---
source: 沪教版必修第三册2026
section: "10.1"
slice_type: 方法卡
---

# 方法卡：斜二测画法

## 核心规则（水平放置图形）

| 原图形 | 直观图 |
|-------|--------|
| $x$ 轴方向 | 长度**不变** |
| $y$ 轴方向 | 长度变为**一半** |
| 夹角 $90°$ | 变为 **$45°$（或 $135°$）** |

## 步骤

1. 取坐标轴 → 画 $x', y'$ 轴，夹角 $45°$
2. 横不变，纵减半
3. 顺次连接，擦辅助线
4. 被遮挡部分画**虚线**

## 示例：正六边形

- 原：$AD$ 水平，$MN$ 垂直
- 直观：$A'D'$ 不变，$M'O' = \frac{1}{2}MO$，夹角 $45°$

## 易错

- 纵坐标忘记减半 ❌
- 角度画成 $90°$ ❌
- 被遮挡部分未画虚线 ❌
```

| 字段 | 说明 |
|------|------|
| `exercise` | 练习编号 |

#### 内容结构模板

```markdown
# 练习卡：{练习编号}

## 第1题：{题型}

[题目内容]

### 提示

[解题提示]

### 参考答案

[简要答案或思路]

## 第2题：{题型}

...

## 要点总结

[本组练习的核心要点]
```

#### 示例

```markdown
---
source: 沪教版必修第三册2026
section: "10.1"
exercise: "10.1(1)"
slice_type: 练习卡
---

# 练习卡：10.1(1)

## 第1题：集合语言描述

用符号表示：$A \in l$，$B \notin l$，$A \in \alpha$，$B \notin \alpha$

## 第2题：四边形共面证明

**题**：四边形有三边在平面 $\alpha$ 上，证第四边也在 $\alpha$ 上。

**证**：
1. 设三边为 $AB, BC, CD \subset \alpha$
2. $B, C \in \alpha$（在边上）
3. $BC$ 在 $\alpha$ 内
4. 同理可证...

**要点**：用公理1，证两点在面内 → 连线在面内
```

## 五、Markdown格式规范

### 5.1 标题层级

- 一级标题 `#`：卡片主标题
- 二级标题 `##`：内容分区（如"定义"、"步骤"）
- 三级标题 `###`：子分区（如"提示"、"参考答案"）

### 5.2 数学公式

- 行内公式：使用 `$...$`
- 块级公式：使用 `$$...$$`

### 5.3 表格

- 使用标准Markdown表格语法
- 表头必须完整

### 5.4 列表

- 无序列表：使用 `-` 或 `*`
- 有序列表：使用 `1.` `2.` `3.`

### 5.5 强调

- 粗体：`**文字**`
- 斜体：`*文字*`
