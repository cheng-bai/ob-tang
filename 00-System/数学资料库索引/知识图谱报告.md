## 1. 概述

本报告记录高中数学知识体系（上海版）的知识图谱构建情况。知识图谱以 **有向图** 形式描述知识点之间的依赖与关联关系，为教学路径规划、智能推荐和学习诊断提供数据基础。

---

## 2. 表结构

```sql
CREATE TABLE knowledge_graph (
    from_point TEXT,       -- 起点知识点
    to_point   TEXT,       -- 终点知识点
    relation   TEXT,       -- 关系类型：prerequisite(前置)/related(关联)/extension(拓展)
    PRIMARY KEY (from_point, to_point)
);
```

## 7. 查询工具

已创建查询脚本：`pipeline/utils/知识路径.py`

### 用法

```bash
# 查询单个知识点的前置链和关联
python pipeline/utils/知识路径.py "导数及其应用"

# 列出所有知识点
python pipeline/utils/知识路径.py
```

### 输出内容

1. **前置知识链（学习路径）** — 树形展示所有递归前置
2. **关联知识** — 直接关联/拓展知识点
3. **被依赖情况** — 哪些知识点依赖当前知识点
4. **建议学习顺序** — 拓扑排序后的学习路径

### 示例输出

```
============================================================
📚 知识点：导数及其应用
============================================================

🔽 前置知识链（学习路径）
----------------------------------------
└── 导数及其应用
      └── 函数的概念、性质及应用
            └── 幂函数、指数函数与对数函数
                  └── 幂、指数与对数
                        └── 等式与不等式
                              └── 集合与逻辑

🔗 关联知识
----------------------------------------
  🔄 [related] 数列

📋 建议学习顺序
----------------------------------------
     1. 集合与逻辑
     2. 等式与不等式
     3. 幂、指数与对数
     4. 幂函数、指数函数与对数函数
     5. 函数的概念、性质及应用
  👉 6. 导数及其应用
```

## 8. 后续扩展建议

1. **细化知识点粒度**：当前以"章"为单位，可进一步拆分为"节"或"具体概念"（如"函数的单调性"、"指数运算法则"等）
2. **引入难度权重**：为每条边增加 `difficulty_weight` 字段，量化前置知识的掌握要求
3. **关联教材与切片**：将 `textbooks` 表和 `slices` 表与知识图谱打通，实现"知识点 → 教材原文 → 专题切片"的联动
4. **学生画像**：记录学生各知识点的掌握状态，基于知识图谱进行薄弱点诊断和学习路径推荐
5. **真题标注**：将 `exam_questions` 表中的题目按知识点关联到图谱节点，实现"哪里薄弱练哪里"
