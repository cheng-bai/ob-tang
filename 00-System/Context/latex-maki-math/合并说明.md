# latex-maki-math 合并说明

## 合并结论

`ob-tang` 作为最终主库，负责 Obsidian 知识管理、教学资料索引、题库、试卷与讲义产出。

`latex-maki-math` 不再作为平行主库维护，而是合并为 `ob-tang` 内部的 Maki 讲义与 LaTeX 输出子系统。

## 已合并内容

| 来源 | 合并位置 | 处理 |
|---|---|---|
| `main.tex`、`maki-math.sty`、`chapters/` | `20-Product/Maki核心讲义/` | 保留，作为 Maki 讲义主入口 |
| `AGENTS.md`、`README.md` | `20-Product/Maki核心讲义/` | 保留，作为子系统规则与说明 |
| `docs/` | `00-System/Context/latex-maki-math/docs/` | 保留，作为跨 AI 记忆导入与复盘规范 |
| `ai-context/` | `00-System/Context/latex-maki-math/ai-context/` | 保留，作为已清洗上下文包 |
| `Skills/exam-md-clean-export/` | `Skills/exam-md-clean-export/` | 保留，作为试卷 Markdown 清洗导出技能 |
| `虹口区高三二模-拆分版/` 源文件 | `04-试卷汇总/2026届虹口区高三下二模数学试卷-Huashu/` | 仅合并 Markdown、LaTeX、脚本与必要图片 |

## 不合并内容

以下内容不进入主库：

- `node_modules/`：依赖目录，可重装。
- `.alma-snapshots/`、`.gstack/`：本地运行状态。
- `Users/`：个人记忆导出与本机路径，不应进入教学主库。
- `tmp/`：临时知识库导出。
- `*.pdf`、`*.html`、测试图片、LaTeX 中间文件：可再生成的构建产物。
- 根目录零散实验文件：如 `test.tex`、`curve-rotation*.png`、`parabola_problem_20*.md`，后续确认价值后再迁入正式目录。

## 后续删除候选

确认合并稳定后，可以考虑删除或归档原 `latex-maki-math` 独立目录。删除前必须满足：

1. `20-Product/Maki核心讲义/main.tex` 可以正常编译。
2. 虹口二模 Markdown 与图片引用可在 Obsidian 中打开。
3. `Skills/exam-md-clean-export/` 的校验脚本可运行。
4. Git 已提交并推送，Mac Air 可克隆验证。
