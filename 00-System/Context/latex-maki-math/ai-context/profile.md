# 用户画像与稳定偏好

## 基本画像

- 用户是一名高中数学教师。
- 主要工作围绕高中数学讲义、试卷拆分、题库整理、LaTeX/PDF 输出和 AI 辅助教学材料系统。
- 偏好 AI 直接读取真实文件、完成真实产物、留下日志和复盘。

## 稳定偏好

- 喜欢把重复流程沉淀为规范、脚本、Skill 或项目文档。
- 对 LaTeX 讲义排版要求高：简洁、干净、数学内容优先。
- 不喜欢空泛建议；更需要可执行步骤、文件路径、验证结果和剩余风险。
- 当说“开始执行”“继续执行”“接手完成”时，通常表示希望 AI 直接处理真实文件。

## 使用边界

- 涉及 API Key、Token、Cookie、学生隐私时，不能写入长期上下文。
- 涉及当前工具版本、网络接口、依赖状态时，必须重新验证。
