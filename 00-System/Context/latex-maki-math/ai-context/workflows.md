# 常用工作流

## 任务执行闭环

1. 读取真实目录、入口文档和目标文件。
2. 判断任务类型和目标产物。
3. 复用现有模板、脚本、样式和目录。
4. 生成或修改真实文件。
5. 做最小可行验证。
6. 更新任务记录。
7. 把可复用经验沉淀到 `docs/` 或 `Skills/`。

## 跨 AI 记忆导入

1. 将原始导出放入 `ai-context/raw/YYYY-MM-DD-source-name/`。
2. 去除凭证、隐私和一次性噪声。
3. 分成稳定层、项目层、流程层、情境层。
4. 写入 `profile.md`、`projects.md`、`workflows.md`、`style-guide.md`、`decisions.md` 或 `task-patterns.md`。
5. 在 `import-log.md` 记录来源、范围、保留内容和未导入内容。

## 试卷与讲义处理

- “仅题目版”：删除答案、解析、提示、评分标准，只保留题干、选项、图表。
- “输出 PDF”：必须确认 PDF 真实生成并报告路径。
- “图片没跟题目”：优先修复 Markdown/LaTeX 中图片位置，再重新导出。
- “开始执行”：先处理真实文件，最后给出产物、验证和风险。
