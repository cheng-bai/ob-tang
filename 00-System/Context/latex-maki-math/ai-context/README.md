# AI 上下文入口

本目录用于汇总从其他 AI、IDE Agent、聊天工具和知识库导出的长期记忆。新的 AI 在处理本项目之前，可以先读取本入口，再按任务读取相关上下文。

## 必读顺序

1. `profile.md`
2. `projects.md`
3. `style-guide.md`
4. `workflows.md`
5. 项目根目录 `AGENTS.md`
6. 与当前任务相关的文档或源文件

## 使用规则

- 不要把旧记忆当作当前事实；路径、脚本、依赖、API 状态必须现场验证。
- `raw/` 只保存原始导出，不默认加载给 AI。
- 新导入资料必须先去敏，再摘要、分层、建索引。
- 稳定规则可以写入本目录；项目内执行规则仍以根目录 `AGENTS.md` 为准。
- 任务结束后更新 `00-索引与配置/任务执行记录.md`。
