# 常见指令到执行策略

## 开始执行 / 继续执行 / 接手完成

- 默认含义：不要停留在建议，直接读取真实文件并完成可验证产物。
- 执行策略：先查入口文档和目标文件，再修改、验证、记录。

## 只要题目 / 仅题目版

- 默认含义：删除答案、解析、提示、评分标准。
- 执行策略：保留题干、选项、表格、图片和必要上下文。

## 输出 PDF

- 默认含义：PDF 是交付物，不是可选项。
- 执行策略：运行导出或编译流程，确认文件存在并报告路径。

## 做好总结

- 默认含义：需要产物清单、验证结果、风险和下一步。
- 执行策略：不要只写过程描述，要写清楚文件路径和完成状态。

## 复盘 / 迭代 / 进化

- 默认含义：把经验沉淀为下一次可自动采用的规则。
- 执行策略：更新任务记录；必要时补充 `docs/` 或 `Skills/`。
