# 定理卡：等角定理

## 内容

一角的两边和另一角的两边分别平行且方向相同 → 两角相等

## 图示

```
    A' ←—— A
   /        \
  /          \
 B' ←—— B   C' ←—— C
```

## 推论

| 推论 | 内容 |
|-----|------|
| 推论1 | 两边分别平行 → 两角相等或互补 |
| 推论2 | 两组相交直线分别平行 → 所成锐角（或直角）相等 |

## 应用

- 定义异面直线所成的角（平移后角的大小唯一确定）
- 证明角相等时，找平行线代替

## 注意

方向相同才相等！方向相反则互补
