# 第13章 统计

## 核心流程

```
实际问题 → 数据收集 → 数据整理 → 数据分析 → 推断结论
```

## 主要内容

| 模块 | 内容 |
|-----|------|
| 抽样 | 简单随机抽样、分层抽样、系统抽样 |
| 图表 | 频率分布表、频率分布直方图、茎叶图 |
| 估计 | 用样本估计总体（数字特征、分布） |

## 数字特征

| 特征 | 样本 | 总体 |
|-----|------|------|
| 平均数 | $\bar{x} = \frac{1}{n}\sum x_i$ | $\mu$ |
| 方差 | $s^2 = \frac{1}{n}\sum (x_i - \bar{x})^2$ | $\sigma^2$ |
| 标准差 | $s = \sqrt{s^2}$ | $\sigma$ |

## 估计思想

- 用 **样本平均数** 估计 **总体平均数**
- 用 **样本方差** 估计 **总体方差**
- 用 **样本分布** 估计 **总体分布**
