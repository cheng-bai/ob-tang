# 第10章 系统版骨架（不改原卡）

## 目标
把现有 `10.*` 切片从“平铺碎片”重排为“可学习、可复习、可机读执行”的系统路径。

## 使用方式
1. 先读 [01-导航层.md](./01-导航层.md) 建立主线与依赖。
2. 再按 [02-知识层映射.md](./02-知识层映射.md) 逐节过卡。
3. 做题时用 [03-方法层脚手架.md](./03-方法层脚手架.md) 选流程。
4. 每节结束执行 [04-训练层闭环.md](./04-训练层闭环.md)。
5. 直接开练时用 [06-最少训练题包.md](./06-最少训练题包.md)。
6. 一周统筹按 [05-一周学习路径.md](./05-一周学习路径.md)。

- 本目录只做结构重排与链接，不重写原卡正文。
