3. 证明下列函数是奇函数：

(1) $y = 2^x - 2^{-x}$；(2) $y = \log_2(1 + x) - \log_2(1 - x)$。

在判断一个比较复杂的函数的奇偶性的时候，往往采取"先猜后证"的方法。

**例 4** 判断下列函数的奇偶性，并说明理由：

(1) $y = (x - 1)^2, x \in \mathbf{R}$；

(2) $y = \begin{cases} x(x + 1), & x > 0, \\ x(1 - x), & x < 0. \end{cases}$

**解** (1) 因为当 $x = 1$ 时，$y = 0$；而当 $x = -1$ 时，$y = 4$，两者不相等，所以 $y = (x - 1)^2$ 不是偶函数；

又因为 $0 \neq -4$，所以 $y = (x - 1)^2$ 亦不是奇函数。

综上所述，函数 $y = (x - 1)^2$ 既不是奇函数，又不是偶函数。

(2) 经试验，发现当 $x = 1$ 时，$y = 2$，而当 $x = -1$ 时，$y = -2$；又当 $x = 10$ 时，$y = 110$，而当 $x = -10$ 时，$y = -110$；等等。猜测该函数可能是奇函数。

该函数的定义域为 $\{ x \mid x \neq 0 \}$。记 $g(x) = \begin{cases} x(x + 1), & x > 0, \\ x(1 - x), & x < 0. \end{cases}$

对任意给定的 $x > 0, g(x) = x(x + 1)$。因 $-x < 0$，故

$$g(-x) = (-x)[1 - (-x)] = -x(1 + x) = -g(x)。$$

而对任意给定的 $x < 0, g(x) = x(1 - x)$。因 $-x > 0$，故

$$g(-x) = (-x)[1 + (-x)] = -x(1 - x) = -g(x)。$$

综上所述，$y = g(x)$ 确实是奇函数。

**例 5** 是否存在正数 $a$，使函数 $y = \frac{a^x + 1}{2^x}$ 是偶函数？

**解** 记 $f(x) = \frac{a^x + 1}{2^x}$。由 $f(1) = \frac{1 + a}{2}, f(-1) = \frac{2}{a} + 2$，若 $y = f(x)$ 是偶函数，就应有 $\frac{1 + a}{2} = \frac{2}{a} + 2$。解这个方程，得 $a = -1$（舍去）或 $a = 4$。

因此，$y = f(x)$ 是偶函数的一个必要条件是 $a = 4$。

另一方面，当 $a = 4$ 时，$f(x) = \frac{4^x + 1}{2^x} = 2^x + 2^{-x}$，其定义域为 $\mathbf{R}$。对任意给定的 $x \in \mathbf{R}$，都有 $-x \in \mathbf{R}$，并且

$$f(-x) = 2^{-x} + 2^{-(-x)} = 2^{-x} + 2^x = f(x)。$$

---

可以从函数值的角度来猜测，也可以借助函数图像的几何直观。

也可以将 $y = g(x)$ 表示为 $y = x(1 + |x|), x \neq 0$。以此证明该函数是奇函数。

为了表明存在性，寻找必要条件的过程不是必须表达出来的。

---

因此，当 $a = 4$ 时，$y = f(x)$ 是偶函数。

综上所述，满足条件的正数 $a$ 存在。

**例 6** 已知函数 $y = f(x), x \in \mathbf{R}$，且当 $x \geq 0$ 时，

$$f(x) = 2x^3 + 2^x - 1。$$

(1) 若函数 $y = f(x)$ 是偶函数，求 $f(-2)$；

(2) $y = f(x)$ 是否可能是奇函数？若可能，求 $f(x)$ 的表达式；若不可能，说明理由。

**解** (1) 若 $y = f(x)$ 是偶函数，应有 $f(-2) = f(2)$。而 $f(2) = 2 \times 2^3 + 2^2 - 1 = 19$，因此 $f(-2) = 19$。

(2) 若 $y = f(x)$ 是奇函数，当 $x < 0$ 时，应有

$$f(x) = -f(-x) = -[2(-x)^3 + 2^{-x} - 1] = 2x^3 - 2^{-x} + 1。$$

---

在例 6(2) 的解答中我们并没有验证"当 $x > 0$ 时，$f(x) = -f(-x)$"。事实上，这是由"当 $x < 0$ 时，$f(-x) = -f(x)$"所蕴涵的。

---

此外，当 $x = 0$ 时，

$$f(x) = 2 \times 0^3 + 2^0 - 1 = 0 = -f(-x)。$$

因此，$y = f(x)$ 可能是奇函数，此时

$$f(x) = \begin{cases} 2x^3 + 2^x - 1, & x \geq 0, \\ 2x^3 - 2^{-x} + 1, & x < 0. \end{cases}$$
