# 第7章 三角函数 讲义

## 一、本章解决什么问题

前一章学习了三角，从几何的角度把正弦、余弦和正切看成一个比值。本章将从**函数的角度**看待正弦、余弦和正切，研究这些三角函数的**图像与性质**。

### 核心问题
1. 如何画出正弦函数、余弦函数、正切函数的图像？
2. 三角函数有哪些独特的性质（周期性、奇偶性、单调性）？
3. 如何研究形如 $y = A\sin(\omega x + \varphi)$ 的函数图像变换？
4. 如何利用三角函数模型解决实际问题（简谐运动、潮汐、交流电等）？

### 三角函数的现实意义
三角函数是**刻画周期现象最典型的数学模型**。在现实生活中存在大量的周期现象：
- 四季的交替
- 钟表指针的转动
- 弹簧的振动
- 交流电的变化
- 潮汐的涨落

根据傅里叶级数理论，一般的周期函数都可以用正弦函数和余弦函数构成的无穷级数表示。

## 三、核心知识点详解

### 3.1 正弦函数的图像与性质

#### 3.1.1 正弦函数的图像

**定义**：对于任意给定的实数 $x$，都有唯一确定的正弦值 $\sin x$ 与之对应。函数 $y = \sin x$ 的定义域是实数集 $\mathbf{R}$。

**五点作图法**：在区间 $[0, 2\pi]$ 上，五个关键点为：

| $x$ | 0 | $\frac{\pi}{2}$ | $\pi$ | $\frac{3\pi}{2}$ | $2\pi$ |
|-----|---|----------------|-------|------------------|--------|
| $\sin x$ | 0 | 1 | 0 | -1 | 0 |

**图像特征**：
- 在 $[0, 2\pi]$ 上呈"波浪形"
- 起点 $(0, 0)$，最高点 $(\frac{\pi}{2}, 1)$，中点 $(\pi, 0)$，最低点 $(\frac{3\pi}{2}, -1)$，终点 $(2\pi, 0)$
- 图像关于原点对称

#### 3.1.2 正弦函数的性质

| 性质 | 内容 |
|------|------|
| **定义域** | $\mathbf{R}$ |
| **值域** | $[-1, 1]$ |
| **最大值** | 1，当 $x = 2k\pi + \frac{\pi}{2}$ ($k \in \mathbf{Z}$) 时取得 |
| **最小值** | -1，当 $x = 2k\pi + \frac{3\pi}{2}$ ($k \in \mathbf{Z}$) 时取得 |
| **周期性** | 最小正周期 $T = 2\pi$ |
| **奇偶性** | 奇函数，$\sin(-x) = -\sin x$，图像关于原点对称 |
| **单调增区间** | $[2k\pi - \frac{\pi}{2}, 2k\pi + \frac{\pi}{2}]$ ($k \in \mathbf{Z}$) |
| **单调减区间** | $[2k\pi + \frac{\pi}{2}, 2k\pi + \frac{3\pi}{2}]$ ($k \in \mathbf{Z}$) |

---

### 3.2 余弦函数的图像与性质

#### 3.2.1 余弦函数的图像

**与正弦函数的关系**：$\cos x = \sin(x + \frac{\pi}{2})$

**作图方法**：将正弦函数 $y = \sin x$ 的图像向左平移 $\frac{\pi}{2}$ 个单位，即得余弦函数 $y = \cos x$ 的图像。

**五点作图法**：在区间 $[0, 2\pi]$ 上，五个关键点为：

| $x$ | 0 | $\frac{\pi}{2}$ | $\pi$ | $\frac{3\pi}{2}$ | $2\pi$ |
|-----|---|----------------|-------|------------------|--------|
| $\cos x$ | 1 | 0 | -1 | 0 | 1 |

#### 3.2.2 余弦函数的性质

| 性质 | 内容 |
|------|------|
| **定义域** | $\mathbf{R}$ |
| **值域** | $[-1, 1]$ |
| **最大值** | 1，当 $x = 2k\pi$ ($k \in \mathbf{Z}$) 时取得 |
| **最小值** | -1，当 $x = 2k\pi + \pi$ ($k \in \mathbf{Z}$) 时取得 |
| **周期性** | 最小正周期 $T = 2\pi$ |
| **奇偶性** | 偶函数，$\cos(-x) = \cos x$，图像关于 $y$ 轴对称 |
| **单调增区间** | $[2k\pi - \pi, 2k\pi]$ ($k \in \mathbf{Z}$) |
| **单调减区间** | $[2k\pi, 2k\pi + \pi]$ ($k \in \mathbf{Z}$) |

---

### 3.3 函数 $y = A\sin(\omega x + \varphi)$ 的图像

#### 3.3.1 参数的意义

对于函数 $y = A\sin(\omega x + \varphi)$ ($A > 0, \omega > 0$)：

| 参数 | 名称 | 意义 | 影响 |
|------|------|------|------|
| $A$ | 振幅 | 物体振动时离开平衡位置的最大距离 | 纵向伸缩，值域变为 $[-A, A]$ |
| $\omega$ | 角频率 | 单位时间内转过的角度 | 横向伸缩，周期 $T = \frac{2\pi}{\omega}$ |
| $\varphi$ | 初相位 | $x = 0$ 时的相位 | 左右平移，平移量 $\frac{\varphi}{\omega}$ |

**相关概念**：
- **周期**：$T = \frac{2\pi}{\omega}$，往复振动一次所需的时间
- **频率**：$f = \frac{1}{T} = \frac{\omega}{2\pi}$，单位时间内振动的次数

#### 3.3.2 图像变换规律

1. **振幅变换** ($A$ 的变化)：
   - $y = \sin x \rightarrow y = A\sin x$：纵向伸缩为原来的 $A$ 倍

2. **周期变换** ($\omega$ 的变化)：
   - $y = \sin x \rightarrow y = \sin(\omega x)$：横向压缩为原来的 $\frac{1}{\omega}$ 倍

3. **相位变换** ($\varphi$ 的变化)：
   - $y = \sin(\omega x) \rightarrow y = \sin(\omega x + \varphi)$：向左平移 $\frac{\varphi}{\omega}$ 个单位
   - 口诀："左加右减"（针对 $x$ 而言）

#### 3.3.3 五点法作图步骤

以 $y = 3\sin(2x + \frac{\pi}{4})$ 为例：

1. 求周期：$T = \frac{2\pi}{2} = \pi$
2. 确定一个周期区间：由 $0 \leq 2x + \frac{\pi}{4} \leq 2\pi$，得 $-\frac{\pi}{8} \leq x \leq \frac{7\pi}{8}$
3. 列表求五点：

| $2x + \frac{\pi}{4}$ | 0 | $\frac{\pi}{2}$ | $\pi$ | $\frac{3\pi}{2}$ | $2\pi$ |
|---------------------|---|----------------|-------|------------------|--------|
| $x$ | $-\frac{\pi}{8}$ | $\frac{\pi}{8}$ | $\frac{3\pi}{8}$ | $\frac{5\pi}{8}$ | $\frac{7\pi}{8}$ |
| $y$ | 0 | 3 | 0 | -3 | 0 |

---

### 3.4 正切函数的图像与性质

#### 3.4.1 正切函数的图像

**定义域**：$\{x \mid x \in \mathbf{R}, x \neq k\pi + \frac{\pi}{2}, k \in \mathbf{Z}\}$

**图像特征**：
- 由无穷多支曲线组成
- 被直线 $x = k\pi + \frac{\pi}{2}$ ($k \in \mathbf{Z}$) 隔开
- 在每个区间 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 内单调递增
- 图像关于原点对称

#### 3.4.2 正切函数的性质

| 性质 | 内容 |
|------|------|
| **定义域** | $\{x \mid x \in \mathbf{R}, x \neq k\pi + \frac{\pi}{2}, k \in \mathbf{Z}\}$ |
| **值域** | $\mathbf{R}$（无最大值和最小值） |
| **周期性** | 最小正周期 $T = \pi$ |
| **奇偶性** | 奇函数，$\tan(-x) = -\tan x$ |
| **单调性** | 在每个区间 $(k\pi - \frac{\pi}{2}, k\pi + \frac{\pi}{2})$ ($k \in \mathbf{Z}$) 上严格递增 |
| **零点** | $x = k\pi$ ($k \in \mathbf{Z}$) |

## 四、典型例题精讲

### 例题1：五点法作图

**题目**：用"五点法"作出函数 $y = 1 - \sin x$，$x \in [0, 2\pi]$ 的大致图像，并写出使得 $y < 1$ 的 $x$ 的取值范围。

**解答**：

列表：

| $x$ | 0 | $\frac{\pi}{2}$ | $\pi$ | $\frac{3\pi}{2}$ | $2\pi$ |
|-----|---|----------------|-------|------------------|--------|
| $-\sin x$ | 0 | -1 | 0 | 1 | 0 |
| $1 - \sin x$ | 1 | 0 | 1 | 2 | 1 |

描点连线可得图像。

由图像可知，当 $x \in (0, \pi)$ 时，$y < 1$。

---

### 例题2：求最小正周期

**题目**：求下列函数的最小正周期：

(1) $f(x) = \sin 3x$

(2) $f(x) = 2\sin(-\frac{1}{2}x + \frac{\pi}{3})$

**解答**：

**(1)** 对于 $y = \sin 3x$：

令 $t = 3x$，则 $y = \sin t$ 的周期为 $2\pi$。

当 $t$ 增加 $2\pi$ 时，$x$ 增加 $\frac{2\pi}{3}$。

因此最小正周期 $T = \frac{2\pi}{3}$。

**(2)** 对于 $y = 2\sin(-\frac{1}{2}x + \frac{\pi}{3})$：

先用诱导公式化为正系数：
$$y = 2\sin(-\frac{1}{2}x + \frac{\pi}{3}) = -2\sin(\frac{1}{2}x - \frac{\pi}{3})$$

令 $t = \frac{1}{2}x - \frac{\pi}{3}$，则 $y = -2\sin t$ 的周期为 $2\pi$。

当 $t$ 增加 $2\pi$ 时，$x$ 增加 $4\pi$。

因此最小正周期 $T = 4\pi$。

**一般结论**：函数 $y = A\sin(\omega x + \varphi)$ ($A \neq 0, \omega > 0$) 的最小正周期为 $T = \frac{2\pi}{\omega}$。

---

### 例题3：求最值

**题目**：求函数 $y = \sin x + \sqrt{3}\cos x$ 的最大值和最小值。

**解答**：

利用辅助角公式：
$$y = \sin x + \sqrt{3}\cos x = 2(\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x) = 2\sin(x + \frac{\pi}{3})$$

因为 $-1 \leq \sin(x + \frac{\pi}{3}) \leq 1$，所以：
- 最大值：$2$，当 $x + \frac{\pi}{3} = 2k\pi + \frac{\pi}{2}$，即 $x = 2k\pi + \frac{\pi}{6}$ ($k \in \mathbf{Z}$) 时取得
- 最小值：$-2$，当 $x + \frac{\pi}{3} = 2k\pi + \frac{3\pi}{2}$，即 $x = 2k\pi + \frac{7\pi}{6}$ ($k \in \mathbf{Z}$) 时取得

---

### 例题4：复合函数最值

**题目**：求函数 $y = \sin^2 x - \sin x$ 的最大值和最小值。

**解答**：

令 $t = \sin x$，则 $t \in [-1, 1]$，函数化为：
$$y = t^2 - t = (t - \frac{1}{2})^2 - \frac{1}{4}$$

这是开口向上的抛物线，对称轴 $t = \frac{1}{2}$。

在区间 $[-1, 1]$ 上：
- 当 $t = \frac{1}{2}$ 时，$y_{min} = -\frac{1}{4}$
- 当 $t = -1$ 时，$y_{max} = (-1)^2 - (-1) = 2$

对应 $x$ 值：
- 最小值：$\sin x = \frac{1}{2}$，$x = 2k\pi + \frac{\pi}{6}$ 或 $x = 2k\pi + \frac{5\pi}{6}$
- 最大值：$\sin x = -1$，$x = 2k\pi + \frac{3\pi}{2}$

---

### 例题5：单调区间

**题目**：求函数 $y = 2\sin(-2x + \frac{\pi}{6})$，$x \in (-\pi, 0]$ 的单调增区间。

**解答**：

先用诱导公式：
$$y = 2\sin(-2x + \frac{\pi}{6}) = -2\sin(2x - \frac{\pi}{6})$$

$y$ 的单调增区间即 $y = 2\sin(2x - \frac{\pi}{6})$ 的单调减区间。

由 $2k\pi + \frac{\pi}{2} \leq 2x - \frac{\pi}{6} \leq 2k\pi + \frac{3\pi}{2}$，得：
$$k\pi + \frac{\pi}{3} \leq x \leq k\pi + \frac{5\pi}{6}$$

结合 $x \in (-\pi, 0]$，当 $k = -1$ 时：
$$-\frac{2\pi}{3} \leq x \leq -\frac{\pi}{6}$$

因此单调增区间为 $[-\frac{2\pi}{3}, -\frac{\pi}{6}]$。

---

### 例题6：三角函数模型应用

**题目**：如图，在一个半径为 $r$ 的半圆形铁板中，截取一块矩形 $ABCD$，使得矩形的顶点 $A$、$B$ 在半圆的直径上，$C$、$D$ 在半圆弧上。问：如何截取矩形，使其面积达到最大值？

**解答**：

连接 $OC$，设 $\angle COB = x$，$x \in (0, \frac{\pi}{2})$。

则：
- $OB = r\cos x$，$AB = 2r\cos x$
- $BC = r\sin x$

矩形面积：
$$S = AB \cdot BC = 2r\cos x \cdot r\sin x = r^2 \sin 2x$$

当 $x \in (0, \frac{\pi}{2})$ 时，$2x \in (0, \pi)$。

当 $2x = \frac{\pi}{2}$，即 $x = \frac{\pi}{4}$ 时，$\sin 2x$ 取得最大值 1。

因此：
- 最大面积 $S_{max} = r^2$
- 此时 $AB = 2r\cos\frac{\pi}{4} = \sqrt{2}r$，$BC = r\sin\frac{\pi}{4} = \frac{\sqrt{2}}{2}r$

---

### 例题7：奇偶性判断

**题目**：判断下列函数的奇偶性：

(1) $f(x) = \sin|x|$

(2) $f(x) = \sin(x + \frac{\pi}{2})$

(3) $f(x) = \sin(x - \frac{\pi}{4})$

**解答**：

**(1)** $f(-x) = \sin|-x| = \sin|x| = f(x)$，是**偶函数**。

**(2)** $f(-x) = \sin(-x + \frac{\pi}{2}) = \sin(\pi - (-x + \frac{\pi}{2})) = \sin(x + \frac{\pi}{2}) = f(x)$，是**偶函数**。

（注：实际上 $\sin(x + \frac{\pi}{2}) = \cos x$，显然是偶函数）

**(3)** $f(-\frac{\pi}{4}) = \sin(-\frac{\pi}{2}) = -1$，$f(\frac{\pi}{4}) = \sin 0 = 0$

因为 $f(-\frac{\pi}{4}) \neq f(\frac{\pi}{4})$ 且 $f(-\frac{\pi}{4}) \neq -f(\frac{\pi}{4})$，所以**既不是奇函数也不是偶函数**。

---

### 例题8：正切函数性质

**题目**：求函数 $y = \tan(\frac{\pi}{6}x + \frac{\pi}{3})$ 的定义域和单调区间。

**解答**：

**定义域**：
由 $\frac{\pi}{6}x + \frac{\pi}{3} \neq k\pi + \frac{\pi}{2}$，得：
$$x \neq 6k + 1 \quad (k \in \mathbf{Z})$$

定义域为 $\{x \mid x \in \mathbf{R}, x \neq 6k + 1, k \in \mathbf{Z}\}$。

**单调区间**：
由 $k\pi - \frac{\pi}{2} < \frac{\pi}{6}x + \frac{\pi}{3} < k\pi + \frac{\pi}{2}$，得：
$$6k - 5 < x < 6k + 1 \quad (k \in \mathbf{Z})$$

因此单调增区间为 $(6k - 5, 6k + 1)$ ($k \in \mathbf{Z}$)。

## 五、方法技巧总结

### 5.1 求三角函数周期的常用方法

1. **定义法**：验证 $f(x + T) = f(x)$，找出最小正数 $T$

2. **公式法**：
   - $y = A\sin(\omega x + \varphi)$ 或 $y = A\cos(\omega x + \varphi)$：$T = \frac{2\pi}{|\omega|}$
   - $y = A\tan(\omega x + \varphi)$：$T = \frac{\pi}{|\omega|}$

3. **换元法**：令 $t = \omega x + \varphi$，转化为基本三角函数求周期

### 5.2 求三角函数最值的常用方法

1. **直接利用有界性**：$|\sin x| \leq 1$，$|\cos x| \leq 1$

2. **辅助角公式**：$a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \varphi)$

3. **换元法（转化为二次函数）**：
   - 令 $t = \sin x$ 或 $t = \cos x$，$t \in [-1, 1]$
   - 转化为二次函数在闭区间上的最值问题

4. **利用单调性**：在指定区间上分析函数的单调性

### 5.3 求单调区间的步骤

1. **标准化**：将函数化为 $y = A\sin(\omega x + \varphi)$ 形式（$\omega > 0$）

2. **解不等式**：
   - 增区间：$2k\pi - \frac{\pi}{2} \leq \omega x + \varphi \leq 2k\pi + \frac{\pi}{2}$
   - 减区间：$2k\pi + \frac{\pi}{2} \leq \omega x + \varphi \leq 2k\pi + \frac{3\pi}{2}$

3. **注意**：若 $A < 0$ 或 $\omega < 0$，单调性相反

### 5.4 图像变换的"两途径"

**途径一：先平移后伸缩**
$y = \sin x \xrightarrow{左移\varphi} y = \sin(x + \varphi) \xrightarrow{横坐标变为\frac{1}{\omega}} y = \sin(\omega x + \varphi) \xrightarrow{纵坐标变为A} y = A\sin(\omega x + \varphi)$

**途径二：先伸缩后平移**
$y = \sin x \xrightarrow{横坐标变为\frac{1}{\omega}} y = \sin(\omega x) \xrightarrow{左移\frac{\varphi}{\omega}} y = \sin(\omega x + \varphi) \xrightarrow{纵坐标变为A} y = A\sin(\omega x + \varphi)$

**注意**：两种途径中平移量不同！

## 六、易错点警示

### 易错点1：周期计算忽略绝对值

**错误**：认为 $y = \sin(-2x)$ 的周期是 $-\pi$

**正确**：周期必须为正数，$T = \frac{2\pi}{|-2|} = \pi$

---

### 易错点2：单调区间求解时忽略系数符号

**错误**：求 $y = -\sin x$ 的增区间时，解 $2k\pi - \frac{\pi}{2} \leq x \leq 2k\pi + \frac{\pi}{2}$

**正确**：$y = -\sin x$ 的增区间即 $y = \sin x$ 的减区间：
$$[2k\pi + \frac{\pi}{2}, 2k\pi + \frac{3\pi}{2}]$$

---

### 易错点3：图像平移方向混淆

**错误**：认为 $y = \sin(2x + \frac{\pi}{3})$ 是由 $y = \sin(2x)$ 向右平移 $\frac{\pi}{3}$ 得到

**正确**：$y = \sin(2x + \frac{\pi}{3}) = \sin[2(x + \frac{\pi}{6})]$，是向左平移 $\frac{\pi}{6}$ 得到

**口诀**："左加右减"针对的是 $x$ 本身，而非 $\omega x$。

---

### 易错点4：正切函数定义域遗漏

**错误**：认为 $y = \tan x$ 的定义域是 $\mathbf{R}$

**正确**：定义域为 $\{x \mid x \neq k\pi + \frac{\pi}{2}, k \in \mathbf{Z}\}$

---

### 易错点5：换元时忽略新变量的取值范围

**错误**：求 $y = \sin^2 x - 2\sin x$ 的最值时，直接配方得最小值 $-1$，未考虑 $t = \sin x \in [-1, 1]$

**正确**：令 $t = \sin x \in [-1, 1]$，$y = (t - 1)^2 - 1$
- 当 $t = 1$ 时，$y_{min} = -1$
- 当 $t = -1$ 时，$y_{max} = 3$

---

### 易错点6：判断奇偶性时忽略定义域

**错误**：认为 $y = \frac{\cos x}{1 - \sin x}$ 是偶函数

**正确**：定义域要求 $\sin x \neq 1$，即 $x \neq 2k\pi + \frac{\pi}{2}$，定义域关于原点不对称，**既不是奇函数也不是偶函数**。

## 七、分层练习设计

### 基础巩固（A组）

1. 用五点法作出函数 $y = 2\sin(2x + \frac{\pi}{3})$ 在一个周期内的图像。

2. 求下列函数的最小正周期：
   - (1) $y = \sin\frac{x}{2}$
   - (2) $y = 3\sin(2x - \frac{\pi}{6})$
   - (3) $y = \tan(3x + \frac{\pi}{4})$

3. 求下列函数的最大值和最小值：
   - (1) $y = 3 - 2\sin x$
   - (2) $y = \sin^2 x + \cos x$
   - (3) $y = \sin x + \cos x$，$x \in [0, \frac{\pi}{2}]$

4. 求下列函数的单调区间：
   - (1) $y = \sin(x + \frac{\pi}{4})$
   - (2) $y = 2\cos(2x - \frac{\pi}{3})$
