# 第6章 三角 讲义

## 一、本章解决什么问题

本章旨在解决以下核心问题：

1. **定量刻画三角形的边角关系**：在平面几何中，"大角对大边"只是定性描述，本章通过引入正弦、余弦、正切、余切等概念，建立三角学的基本理论，实现边角关系的定量刻画。

2. **拓展角的概念**：从初中锐角扩展到任意角（正角、负角、零角），引入弧度制，为后续学习三角函数奠定基础。

3. **建立三角恒等变换体系**：学习两角和差公式、倍角公式等，掌握三角表达式的化简与证明方法。

4. **解决斜三角形问题**：通过正弦定理和余弦定理，解决测量、航海、天文等实际问题中的三角形求解。

## 三、核心知识点详解

### 3.1 任意角及其度量

#### 3.1.1 角的概念推广

**定义**：一条射线绕端点旋转形成的图形
- **正角**：逆时针旋转形成的角
- **负角**：顺时针旋转形成的角  
- **零角**：射线没有旋转

**终边相同的角**：与角 $\alpha$ 终边相同的角的集合为
$$\{\beta \mid \beta = k \cdot 360° + \alpha, k \in \mathbf{Z}\}$$

#### 3.1.2 弧度制

**定义**：弧长等于半径的弧所对的圆心角叫做1弧度

**换算关系**：
- $180° = \pi$ 弧度
- $1° = \frac{\pi}{180}$ 弧度
- $1$ 弧度 $= \frac{180°}{\pi}$

**常用特殊角换算表**：

| 角度 | $0°$ | $30°$ | $45°$ | $60°$ | $90°$ | $180°$ | $270°$ | $360°$ |
|------|------|-------|-------|-------|-------|--------|--------|--------|
| 弧度 | $0$ | $\frac{\pi}{6}$ | $\frac{\pi}{4}$ | $\frac{\pi}{3}$ | $\frac{\pi}{2}$ | $\pi$ | $\frac{3\pi}{2}$ | $2\pi$ |

**扇形公式**（弧度制）：
- 弧长：$l = \alpha r$
- 面积：$S = \frac{1}{2}\alpha r^2$

---

### 3.2 任意角的三角函数

#### 3.2.1 定义

设角 $\alpha$ 的终边上任意一点 $P(x, y)$（异于原点），$r = \sqrt{x^2 + y^2} > 0$

$$\sin \alpha = \frac{y}{r}, \quad \cos \alpha = \frac{x}{r}$$

$$\tan \alpha = \frac{y}{x} (x \neq 0), \quad \cot \alpha = \frac{x}{y} (y \neq 0)$$

#### 3.2.2 三角函数值的符号

| 象限 | $\sin \alpha$ | $\cos \alpha$ | $\tan \alpha$ | $\cot \alpha$ |
|------|---------------|---------------|---------------|---------------|
| 第一象限 | $+$ | $+$ | $+$ | $+$ |
| 第二象限 | $+$ | $-$ | $-$ | $-$ |
| 第三象限 | $-$ | $-$ | $+$ | $+$ |
| 第四象限 | $-$ | $+$ | $-$ | $-$ |

**记忆口诀**：一全正，二正弦，三正切，四余弦

#### 3.2.3 同角三角函数关系

**平方关系**：$\sin^2 \alpha + \cos^2 \alpha = 1$

**商数关系**：$\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$

**倒数关系**：$\tan \alpha \cdot \cot \alpha = 1$

---

### 3.3 诱导公式

**口诀：奇变偶不变，符号看象限**

| 公式类型 | 正弦 | 余弦 | 正切 |
|---------|------|------|------|
| $2k\pi + \alpha$ | $\sin \alpha$ | $\cos \alpha$ | $\tan \alpha$ |
| $-\alpha$ | $-\sin \alpha$ | $\cos \alpha$ | $-\tan \alpha$ |
| $\pi - \alpha$ | $\sin \alpha$ | $-\cos \alpha$ | $-\tan \alpha$ |
| $\pi + \alpha$ | $-\sin \alpha$ | $-\cos \alpha$ | $\tan \alpha$ |
| $\frac{\pi}{2} - \alpha$ | $\cos \alpha$ | $\sin \alpha$ | $\cot \alpha$ |
| $\frac{\pi}{2} + \alpha$ | $\cos \alpha$ | $-\sin \alpha$ | $-\cot \alpha$ |

---

### 3.4 两角和与差的三角公式

#### 3.4.1 基本公式

**余弦公式**：
$$\cos(\alpha + \beta) = \cos \alpha \cos \beta - \sin \alpha \sin \beta$$
$$\cos(\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta$$

**正弦公式**：
$$\sin(\alpha + \beta) = \sin \alpha \cos \beta + \cos \alpha \sin \beta$$
$$\sin(\alpha - \beta) = \sin \alpha \cos \beta - \cos \alpha \sin \beta$$

**正切公式**：
$$\tan(\alpha + \beta) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta}$$
$$\tan(\alpha - \beta) = \frac{\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta}$$

#### 3.4.2 倍角公式

$$\sin 2\alpha = 2\sin \alpha \cos \alpha$$

$$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$$

$$\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}$$

#### 3.4.3 半角公式

$$\sin \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{2}}$$

$$\cos \frac{\alpha}{2} = \pm \sqrt{\frac{1 + \cos \alpha}{2}}$$

$$\tan \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{1 + \cos \alpha}} = \frac{\sin \alpha}{1 + \cos \alpha} = \frac{1 - \cos \alpha}{\sin \alpha}$$

### 3.5 解三角形

#### 3.5.1 正弦定理

在 $\triangle ABC$ 中：
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

其中 $R$ 为三角形外接圆半径。

**适用情况**：
- 已知两角及一边
- 已知两边及其中一边的对角（注意可能有两解）

#### 3.5.2 余弦定理

在 $\triangle ABC$ 中：
$$a^2 = b^2 + c^2 - 2bc \cos A$$
$$b^2 = a^2 + c^2 - 2ac \cos B$$
$$c^2 = a^2 + b^2 - 2ab \cos C$$

**变形**：
$$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$$
$$\cos B = \frac{a^2 + c^2 - b^2}{2ac}$$
$$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

**适用情况**：
- 已知三边
- 已知两边及其夹角

#### 3.5.3 三角形面积公式

$$S = \frac{1}{2}ab \sin C = \frac{1}{2}bc \sin A = \frac{1}{2}ac \sin B$$

## 四、典型例题精讲

### 例题1：诱导公式的应用

**题目**：利用诱导公式求值：$\sin \frac{20}{3}\pi$

**解析**：
$$\sin \frac{20}{3}\pi = \sin\left(6\pi + \frac{2}{3}\pi\right) = \sin \frac{2}{3}\pi$$

$$= \sin\left(\pi - \frac{\pi}{3}\right) = \sin \frac{\pi}{3} = \frac{\sqrt{3}}{2}$$

**点评**：利用"奇变偶不变，符号看象限"的口诀，先将大角化为 $[0, 2\pi)$ 范围内的角。

---

### 例题2：已知三角函数值求其他值

**题目**：已知 $\sin \alpha = \frac{3}{5}$，且 $\alpha$ 为第二象限的角，求 $\cos \alpha$、$\tan \alpha$ 及 $\cot \alpha$。

**解析**：

因为 $\alpha$ 为第二象限的角，所以 $\cos \alpha < 0$。

由 $\sin^2 \alpha + \cos^2 \alpha = 1$，得：
$$\cos \alpha = -\sqrt{1 - \sin^2 \alpha} = -\sqrt{1 - \frac{9}{25}} = -\frac{4}{5}$$

从而：
$$\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = \frac{\frac{3}{5}}{-\frac{4}{5}} = -\frac{3}{4}$$

$$\cot \alpha = \frac{1}{\tan \alpha} = -\frac{4}{3}$$

**点评**：注意根据象限确定三角函数值的符号。

---

### 例题3：两角和差公式的应用

**题目**：已知 $\sin \alpha = \frac{4\sqrt{3}}{7}$，$\cos(\alpha + \beta) = -\frac{11}{14}$，且 $\alpha$、$\beta$ 为锐角，求角 $\beta$。

**解析**：

由 $\alpha$ 为锐角，$\sin \alpha = \frac{4\sqrt{3}}{7}$，得：
$$\cos \alpha = \sqrt{1 - \sin^2 \alpha} = \sqrt{1 - \frac{48}{49}} = \frac{1}{7}$$

由 $\alpha$、$\beta$ 为锐角，得 $0 < \alpha + \beta < \pi$，从而：
$$\sin(\alpha + \beta) = \sqrt{1 - \cos^2(\alpha + \beta)} = \sqrt{1 - \frac{121}{196}} = \frac{5\sqrt{3}}{14}$$

于是：
$$\cos \beta = \cos[(\alpha + \beta) - \alpha] = \cos(\alpha + \beta)\cos \alpha + \sin(\alpha + \beta)\sin \alpha$$

$$= \left(-\frac{11}{14}\right) \times \frac{1}{7} + \frac{4\sqrt{3}}{7} \times \frac{5\sqrt{3}}{14} = -\frac{11}{98} + \frac{60}{98} = \frac{49}{98} = \frac{1}{2}$$

因为 $\beta$ 为锐角，所以 $\beta = \frac{\pi}{3}$。

**点评**：关键是将 $\beta$ 表示为 $(\alpha + \beta) - \alpha$，利用两角差的余弦公式。

---

### 例题4：倍角公式的应用

**题目**：已知 $\sin \alpha = \frac{4}{5}$，$\alpha \in \left(\frac{\pi}{2}, \pi\right)$，求 $\sin 2\alpha$、$\cos 2\alpha$ 和 $\tan 2\alpha$。

**解析**：

由 $\sin \alpha = \frac{4}{5}$，$\alpha \in \left(\frac{\pi}{2}, \pi\right)$，得：
$$\cos \alpha = -\sqrt{1 - \sin^2 \alpha} = -\sqrt{1 - \frac{16}{25}} = -\frac{3}{5}$$

$$\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = -\frac{4}{3}$$

于是：
$$\sin 2\alpha = 2\sin \alpha \cos \alpha = 2 \times \frac{4}{5} \times \left(-\frac{3}{5}\right) = -\frac{24}{25}$$

$$\cos 2\alpha = 1 - 2\sin^2 \alpha = 1 - 2 \times \frac{16}{25} = -\frac{7}{25}$$

$$\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha} = \frac{2 \times \left(-\frac{4}{3}\right)}{1 - \frac{16}{9}} = \frac{-\frac{8}{3}}{-\frac{7}{9}} = \frac{24}{7}$$

**点评**：倍角公式有多种形式，根据已知条件选择合适的形式。

---

### 例题5：正弦定理的应用

**题目**：在 $\triangle ABC$ 中，已知 $A = 120°$，$B = 45°$，$AC = 2$，求 $BC$。

**解析**：

由三角形内角和：$C = 180° - 120° - 45° = 15°$

由正弦定理：
$$\frac{BC}{\sin A} = \frac{AC}{\sin B}$$

$$BC = \frac{AC \cdot \sin A}{\sin B} = \frac{2 \cdot \sin 120°}{\sin 45°} = \frac{2 \times \frac{\sqrt{3}}{2}}{\frac{\sqrt{2}}{2}} = \frac{\sqrt{3}}{\frac{\sqrt{2}}{2}} = \sqrt{6}$$

**点评**：正弦定理适用于已知两角一边或两边及其中一边对角的情况。

---

### 例题6：余弦定理的应用（教材例4）

**题目**：在 $\triangle ABC$ 中，已知 $a = \sqrt{6}$，$b = \sqrt{3} + 1$，$C = 45°$，求 $c$、$A$ 及 $B$。

**解析**：

由余弦定理：
$$c^2 = a^2 + b^2 - 2ab \cos C$$

$$= 6 + (\sqrt{3} + 1)^2 - 2\sqrt{6}(\sqrt{3} + 1) \times \frac{\sqrt{2}}{2}$$

$$= 6 + (3 + 2\sqrt{3} + 1) - \sqrt{12}(\sqrt{3} + 1)$$

$$= 6 + 4 + 2\sqrt{3} - 2\sqrt{3}(\sqrt{3} + 1)$$

$$= 10 + 2\sqrt{3} - 6 - 2\sqrt{3} = 4$$

故 $c = 2$。

再由余弦定理求 $\cos A$：
$$\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{(\sqrt{3}+1)^2 + 4 - 6}{2(\sqrt{3}+1) \times 2} = \frac{4 + 2\sqrt{3} + 4 - 6}{4(\sqrt{3}+1)} = \frac{2 + 2\sqrt{3}}{4(\sqrt{3}+1)} = \frac{1}{2}$$

因为 $A$ 为三角形内角，所以 $A = 60°$。

由三角形内角和：$B = 180° - 60° - 45° = 75°$。

**答案**：$c = 2$，$A = 60°$，$B = 75°$

---

### 例题7：解三角形的多解问题（教材例5）

**题目**：在 $\triangle ABC$ 中，已知 $a = 2$，$b = 2\sqrt{3}$，$A = 30°$，求 $B$、$C$ 及 $c$。

**解析**：

**方法一：正弦定理**

由正弦定理：$\frac{2}{\sin 30°} = \frac{2\sqrt{3}}{\sin B}$

$$\sin B = \frac{2\sqrt{3} \times \frac{1}{2}}{2} = \frac{\sqrt{3}}{2}$$

所以 $B = 60°$ 或 $B = 180° - 60° = 120°$。

**情况1**：当 $B = 60°$ 时
- $C = 180° - 30° - 60° = 90°$
- 由 $\frac{2}{\sin 30°} = \frac{c}{\sin 90°}$，得 $c = 4$

**情况2**：当 $B = 120°$ 时
- $C = 180° - 30° - 120° = 30°$
- 由 $\frac{2}{\sin 30°} = \frac{c}{\sin 30°}$，得 $c = 2$

**答案**：$B = 60°$，$C = 90°$，$c = 4$ 或 $B = 120°$，$C = 30°$，$c = 2$

**点评**：已知两边及其中一边对角时，三角形可能有两解、一解或无解，需根据具体情况判断。

---

### 例题8：三角恒等式的证明

**题目**：证明：$\tan A + \tan B + \tan C = \tan A \tan B \tan C$（$\triangle ABC$ 不是直角三角形）

**解析**：

因为 $A + B + C = \pi$，所以 $A + B = \pi - C$

$$\tan(A + B) = \tan(\pi - C) = -\tan C$$

由两角和的正切公式：
$$\frac{\tan A + \tan B}{1 - \tan A \tan B} = -\tan C$$

$$\tan A + \tan B = -\tan C(1 - \tan A \tan B)$$

$$\tan A + \tan B = -\tan C + \tan A \tan B \tan C$$

$$\tan A + \tan B + \tan C = \tan A \tan B \tan C$$

**点评**：这是三角形中一个重要的恒等式，在解题中经常用到。

## 五、方法技巧总结

### 5.1 三角函数求值方法

1. **化负为正**：利用诱导公式将负角化为正角
2. **化大为小**：将大角化为 $[0, 2\pi)$ 范围内的角
3. **化钝为锐**：利用诱导公式将钝角化为锐角

### 5.2 三角恒等变换技巧

1. **"1"的代换**：$1 = \sin^2 \alpha + \cos^2 \alpha = \tan \alpha \cdot \cot \alpha$
2. **齐次式处理**：分子分母同除以 $\cos^n \alpha$ 化为关于 $\tan \alpha$ 的表达式
3. **角的变换**：如 $\alpha = (\alpha + \beta) - \beta$，$2\alpha = (\alpha + \beta) + (\alpha - \beta)$

### 5.3 解三角形策略

| 已知条件 | 选用定理 | 注意事项 |
|---------|---------|---------|
| 两角一边 | 正弦定理 | 先求第三角 |
| 两边及夹角 | 余弦定理 | 先求第三边 |
| 三边 | 余弦定理 | 求角时注意符号 |
| 两边及其中一边对角 | 正弦定理 | 注意多解情况 |

### 5.4 判断三角形形状的方法

1. **化边为角**：利用正弦定理将边化为角的关系
2. **化角为边**：利用余弦定理或正弦定理将角化为边的关系
3. **常用结论**：
   - $a^2 + b^2 = c^2$ ⟹ 直角三角形
   - $a^2 + b^2 > c^2$ ⟹ 锐角三角形
   - $a^2 + b^2 < c^2$ ⟹ 钝角三角形

## 六、易错点警示

### 6.1 概念理解错误

**错误1**：认为小于 $90°$ 的角都是锐角
- **纠正**：锐角是指 $(0°, 90°)$ 范围内的角，负角和零角都不是锐角

**错误2**：混淆角度制与弧度制
- **纠正**：$\sin 1$ 表示1弧度的正弦，$\sin 1°$ 表示1度的正弦，两者不同

### 6.2 计算错误

**错误3**：使用诱导公式时符号错误
- **纠正**：牢记"奇变偶不变，符号看象限"

**错误4**：已知 $\sin \alpha$ 求 $\cos \alpha$ 时忽略符号
- **纠正**：必须先确定角 $\alpha$ 所在的象限

### 6.3 解三角形错误

**错误5**：已知两边及其中一边对角时漏解
- **纠正**：$\sin B = k$ 时，$B$ 可能有两个值（锐角和钝角）

**错误6**：忽略三角形内角和为 $180°$ 的限制
- **纠正**：求出角后要验证三者和是否为 $180°$

### 6.4 公式应用错误

**错误7**：混淆 $\sin(\alpha + \beta)$ 与 $\sin \alpha + \sin \beta$
- **纠正**：一般情况下 $\sin(\alpha + \beta) \neq \sin \alpha + \sin \beta$

**错误8**：倍角公式中系数错误
- **纠正**：$\cos 2\alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$（系数是2不是1）

## 七、分层练习设计

### 基础层（必做）

1. 将 $-240°$ 化为弧度，并判断它是第几象限的角。

3. 利用诱导公式化简：$\sin(\pi + \alpha) \cos(\frac{\pi}{2} + \alpha)$

4. 在 $\triangle ABC$ 中，已知 $A = 60°$，$B = 45°$，$a = 6$，求 $b$。

5. 在 $\triangle ABC$ 中，已知 $a = 3$，$b = 4$，$C = 60°$，求 $c$。

### 提高层（选做）

6. 已知 $\tan \alpha = 2$，求 $\frac{2\sin \alpha + \cos \alpha}{\sin \alpha - \cos \alpha}$ 的值。

8. 在 $\triangle ABC$ 中，已知 $a = 2$，$b = 3$，$c = 4$，求 $\cos C$ 和三角形面积。

## 附录：常用公式速查表

### 基本关系
- $\sin^2 \alpha + \cos^2 \alpha = 1$
- $\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$
- $\tan \alpha \cdot \cot \alpha = 1$

### 诱导公式（口诀：奇变偶不变，符号看象限）

### 和差公式
- $\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$
- $\cos(\alpha \pm \beta) = \cos \alpha \cos \beta \mp \sin \alpha \sin \beta$
- $\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}$

### 倍角公式
- $\sin 2\alpha = 2\sin \alpha \cos \alpha$
- $\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$
- $\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}$

### 正余弦定理
- $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$
- $a^2 = b^2 + c^2 - 2bc \cos A$
- $S = \frac{1}{2}ab \sin C$
