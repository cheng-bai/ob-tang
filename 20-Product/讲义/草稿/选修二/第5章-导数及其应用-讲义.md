# 第5章 导数及其应用 讲义

## 一、本章解决什么问题

本章引入微积分中最基本的概念——**导数**，主要解决以下问题：

1. **变速运动的瞬时速度问题**：如何精确描述物体在某一时刻的瞬时速度？
2. **曲线的切线问题**：如何确定一条曲线上某点处的切线？
3. **函数的单调性、极值与最值问题**：如何研究函数的增减性、寻找函数的极值点和最值？
4. **实际优化问题**：如何在用料最省、利润最大、成本最低等实际问题中寻找最优解？

导数作为研究函数瞬时变化率的工具，为我们提供了处理变化和运动问题的数学方法，是连接初等数学与高等数学的桥梁。

## 三、核心知识点详解

### 3.1 导数的概念

#### 3.1.1 平均变化率与瞬时变化率

**平均变化率**：对于函数 $y = f(x)$，在区间 $[x_0, x_0+h]$ 上的平均变化率为
$$\frac{\Delta y}{\Delta x} = \frac{f(x_0+h) - f(x_0)}{h}$$

**瞬时变化率（导数）**：当 $h \to 0$ 时，平均变化率的极限
$$f'(x_0) = \lim_{h \to 0}\frac{f(x_0+h) - f(x_0)}{h}$$

#### 3.1.2 导数的物理意义

在变速运动中，若位移 $s = f(t)$，则：
- 瞬时速度 $v(t_0) = f'(t_0)$
- 瞬时加速度 $a(t_0) = v'(t_0) = f''(t_0)$

**例**：自由落体运动 $d = 5t^2$，在 $t = 2$ 时的瞬时速度为
$$v = \lim_{h \to 0}\frac{5(2+h)^2 - 5 \times 2^2}{h} = \lim_{h \to 0}(20 + 5h) = 20 \text{ m/s}$$

#### 3.1.3 导数的几何意义

函数 $y = f(x)$ 在点 $P(x_0, f(x_0))$ 处的导数 $f'(x_0)$ 就是曲线在该点处**切线的斜率**。

切线方程：$y - f(x_0) = f'(x_0)(x - x_0)$

**驻点**：导数为零的点，即 $f'(x_0) = 0$，此时切线为水平直线。

---

### 3.2 导数的运算

#### 3.2.1 基本初等函数的导数公式

| 函数 | 导数 | 说明 |
|------|------|------|
| $y = C$（常数） | $y' = 0$ | 常数的导数为0 |
| $y = x^\alpha$ | $y' = \alpha x^{\alpha-1}$ | $\alpha$ 为常数 |
| $y = e^x$ | $y' = e^x$ | 指数函数导数等于自身 |
| $y = \ln x$ | $y' = \frac{1}{x}$ | 对数函数导数 |
| $y = \sin x$ | $y' = \cos x$ | 正弦函数导数 |
| $y = \cos x$ | $y' = -\sin x$ | 余弦函数导数 |

#### 3.2.2 导数的四则运算法则

设 $u = f(x)$，$v = g(x)$，则：

1. **和差法则**：$(u \pm v)' = u' \pm v'$
2. **积法则**：$(uv)' = u'v + uv'$
3. **商法则**：$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$（$v \neq 0$）
4. **常数倍**：$(Cu)' = Cu'$（$C$ 为常数）

#### 3.2.3 简单复合函数的导数

对于 $y = f(ax + b)$ 型复合函数：
$$y' = a \cdot f'(u)，\text{其中 } u = ax + b$$

**常用推导公式**：
- $(\log_a x)' = \frac{1}{x \ln a}$
- $(a^x)' = a^x \ln a$

---

### 3.3 导数的应用

#### 3.3.1 利用导数研究函数的单调性

**定理**：在区间 $I$ 上
- 若 $f'(x) > 0$，则 $f(x)$ 在该区间**严格增**
- 若 $f'(x) < 0$，则 $f(x)$ 在该区间**严格减**

**求单调区间的步骤**：
1. 求导数 $f'(x)$
2. 令 $f'(x) = 0$，求出驻点
3. 用驻点和函数无定义点划分区间
4. 判断各区间内导数的正负

#### 3.3.2 利用导数研究函数的极值

**极值点**：若存在含 $x_0$ 的开区间，使得该区间内其他点的函数值都不大于（或不小于）$f(x_0)$，则 $f(x)$ 在 $x_0$ 处取得极大（小）值。

**极值判定定理**：设 $x_0$ 是驻点
- 若 $f'(x)$ 在 $x_0$ 左侧为正，右侧为负，则 $x_0$ 是**极大值点**
- 若 $f'(x)$ 在 $x_0$ 左侧为负，右侧为正，则 $x_0$ 是**极小值点**

**注意**：驻点不一定是极值点（如 $y = x^3$ 在 $x = 0$ 处）。

#### 3.3.3 利用导数研究函数的最值

闭区间 $[a, b]$ 上的连续函数一定存在最大值和最小值。

**求最值的方法**：比较**驻点**和**区间端点**处的函数值，最大者为最大值，最小者为最小值。

#### 3.3.4 利用导数解决实际问题

解决优化问题的一般步骤：
1. 建立目标函数（需要最大或最小的量）
2. 确定自变量的取值范围
3. 求导数，找驻点
4. 判断驻点是否为最值点
5. 得出结论

## 四、典型例题精讲

### 例题1：用导数定义求导

已知 $f(x) = x^2$，用导数定义求 $f'(1)$。

**解**：
$$f'(1) = \lim_{h \to 0}\frac{f(1+h) - f(1)}{h} = \lim_{h \to 0}\frac{(1+h)^2 - 1}{h}$$
$$= \lim_{h \to 0}\frac{1 + 2h + h^2 - 1}{h} = \lim_{h \to 0}(2 + h) = 2$$

---

### 例题2：基本求导运算

求下列函数的导数：

(1) $f(x) = x^3 - 2x^2 + 3x - 1$

**解**：$f'(x) = 3x^2 - 4x + 3$

(2) $f(x) = x^2 \sin x$

**解**：$f'(x) = (x^2)'\sin x + x^2(\sin x)' = 2x\sin x + x^2\cos x$

(3) $f(x) = \frac{x^2}{x+1}$

**解**：$f'(x) = \frac{2x(x+1) - x^2}{(x+1)^2} = \frac{x^2 + 2x}{(x+1)^2}$

---

### 例题3：复合函数求导

求 $y = \ln(2x + 1)$ 的导数。

**解**：设 $u = 2x + 1$，则 $y = \ln u$
$$y' = \frac{1}{u} \cdot 2 = \frac{2}{2x + 1}$$

---

### 例题4：求切线方程

求曲线 $y = x^3$ 在点 $P(1, 1)$ 处的切线方程。

**解**：
1. 求导数：$y' = 3x^2$
2. 求切线斜率：$k = y'|_{x=1} = 3$
3. 切线方程：$y - 1 = 3(x - 1)$，即 $y = 3x - 2$

---

### 例题5：研究函数单调性

求函数 $f(x) = x^3 - 3x$ 的单调区间。

**解**：
1. 求导数：$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x+1)(x-1)$
2. 令 $f'(x) = 0$，得驻点 $x_1 = -1$，$x_2 = 1$
3. 列表分析：

| $x$ | $(-\infty, -1)$ | $-1$ | $(-1, 1)$ | $1$ | $(1, +\infty)$ |
|-----|------------------|------|-----------|-----|----------------|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | $\nearrow$ | 极大值 | $\searrow$ | 极小值 | $\nearrow$ |

4. 结论：单调增区间为 $(-\infty, -1)$ 和 $(1, +\infty)$；单调减区间为 $(-1, 1)$

---

### 例题6：求函数的极值与最值

求函数 $f(x) = -x^2 + 6x - 1$ 在区间 $[0, 7]$ 上的最大值和最小值。

**解**：
1. 求导数：$f'(x) = -2x + 6$
2. 令 $f'(x) = 0$，得驻点 $x = 3$
3. 计算函数值：
   - $f(3) = -9 + 18 - 1 = 8$（极大值）
   - $f(0) = -1$
   - $f(7) = -49 + 42 - 1 = -8$
4. 结论：最大值为 $8$（在 $x = 3$ 处），最小值为 $-8$（在 $x = 7$ 处）

---

### 例题7：实际优化问题

将边长为 $3$ 的正方形硬纸板四角各裁去边长为 $x$ 的小正方形，折成无盖纸盒。问：$x$ 取何值时，容积最大？

**解**：
1. 建立目标函数：$V(x) = x(3-2x)^2$，$x \in (0, \frac{3}{2})$
2. 求导数：$V'(x) = 12x^2 - 24x + 9 = 3(4x^2 - 8x + 3) = 3(2x-1)(2x-3)$
3. 令 $V'(x) = 0$，得 $x_1 = \frac{1}{2}$，$x_2 = \frac{3}{2}$（舍去，不在定义域内）
4. 分析：当 $x \in (0, \frac{1}{2})$ 时，$V'(x) > 0$；当 $x \in (\frac{1}{2}, \frac{3}{2})$ 时，$V'(x) < 0$
5. 结论：当 $x = \frac{1}{2}$ 时，容积最大，最大容积 $V(\frac{1}{2}) = 2$

---

### 例题8：利用导数研究二次函数

用导数方法求二次函数 $f(x) = ax^2 + bx + c$（$a > 0$）的单调区间、极值及不等式 $ax^2 + bx + c \geq 0$ 的解集。

**解**：
1. 求导数：$f'(x) = 2ax + b$
2. 令 $f'(x) = 0$，得驻点 $x_0 = -\frac{b}{2a}$
3. 当 $x < -\frac{b}{2a}$ 时，$f'(x) < 0$，函数严格减
4. 当 $x > -\frac{b}{2a}$ 时，$f'(x) > 0$，函数严格增
5. 在 $x = -\frac{b}{2a}$ 处取得极小值 $\frac{4ac - b^2}{4a}$

不等式 $ax^2 + bx + c \geq 0$ 的解集：
- 当 $\Delta > 0$ 时，解集为 $(-\infty, \frac{-b-\sqrt{\Delta}}{2a}] \cup [\frac{-b+\sqrt{\Delta}}{2a}, +\infty)$
- 当 $\Delta \leq 0$ 时，解集为 $\mathbb{R}$

## 五、方法技巧总结

### 5.1 求导数的方法

| 类型 | 方法 |
|------|------|
| 基本初等函数 | 直接套用导数公式 |
| 多项式函数 | 逐项求导 |
| 乘积形式 | 使用积的求导法则 |
| 商的形式 | 使用商的求导法则 |
| 复合函数 $f(ax+b)$ | 链式法则：$y' = a \cdot f'(u)$ |
| 复杂表达式 | 先化简再求导 |

### 5.2 研究函数单调性的步骤

1. **确定定义域**
2. **求导数** $f'(x)$
3. **求驻点**：解方程 $f'(x) = 0$
4. **划分区间**：用驻点和无定义点将定义域划分
5. **判断符号**：确定各区间内 $f'(x)$ 的正负
6. **得出结论**

### 5.3 求极值与最值的要点

**求极值**：
- 找出所有驻点
- 判断驻点两侧导数的符号变化
- 左正右负为极大值，左负右正为极小值

**求最值（闭区间）**：
- 找出区间内所有驻点
- 计算驻点和区间端点的函数值
- 比较得出最大值和最小值

### 5.4 解决优化问题的步骤

1. **理解题意**，确定目标量（需要最大或最小）
2. **建立函数关系**，写出目标函数 $y = f(x)$
3. **确定定义域**，根据实际意义确定 $x$ 的范围
4. **求导找驻点**
5. **判断最值**：若区间内只有一个驻点且实际问题必有最值，则该驻点即为最值点
6. **验证并作答**

## 六、易错点警示

### 6.1 导数定义理解不清

**易错点**：混淆平均变化率与瞬时变化率

**正解**：平均变化率 $\frac{\Delta y}{\Delta x}$ 是区间上的变化快慢；瞬时变化率（导数）是某一点处的变化快慢，是平均变化率的极限。

### 6.2 复合函数求导遗漏系数

**易错点**：求 $y = \sin 2x$ 的导数时，只写 $y' = \cos 2x$，漏乘内层函数 $u = 2x$ 的导数。

**正解**：$y' = \cos 2x \cdot 2 = 2\cos 2x$

### 6.3 驻点与极值点混淆

**易错点**：认为驻点一定是极值点

**正解**：驻点不一定是极值点。例如 $y = x^3$ 在 $x = 0$ 处导数为0，但该点不是极值点（函数在整个定义域上单调增）。

### 6.4 忽略定义域

**易错点**：研究函数性质时忽略定义域的限制

**正解**：例如 $f(x) = \frac{1}{x}$，在 $x = 0$ 处无定义，该点是单调区间的分界点，但不是驻点。

### 6.5 最值与极值混淆

**易错点**：认为极大值就是最大值，极小值就是最小值

**正解**：极值是局部概念，最值是整体概念。闭区间上的最值可能在极值点取得，也可能在区间端点取得。

### 6.6 切线方程计算错误

**易错点**：将切线方程写成 $y = f'(x_0)$ 或忘记使用点斜式

**正解**：切线方程为 $y - f(x_0) = f'(x_0)(x - x_0)$，注意切点 $(x_0, f(x_0))$ 在曲线上。

## 七、分层练习设计

### 基础练习（A组）

1. 用导数定义求 $f(x) = 3x^2$ 在 $x = 2$ 处的导数。

2. 求下列函数的导数：
   (1) $f(x) = x^5 - 3x^3 + 2x - 1$
   (2) $f(x) = x^2 \cos x$
   (3) $f(x) = \frac{2x}{x+1}$
   (4) $f(x) = \ln(3x - 2)$

3. 求曲线 $y = x^2 - 2x$ 在点 $(2, 0)$ 处的切线方程。

4. 求函数 $f(x) = x^3 - 3x^2$ 的单调区间和极值。

5. 求函数 $f(x) = x^3 - 3x + 1$ 在区间 $[-2, 2]$ 上的最大值和最小值。

### 提高练习（B组）

6. 已知函数 $f(x) = x^3 + ax^2 + bx + c$ 在 $x = 1$ 处有极值 $0$，求 $a, b, c$ 的值。

7. 证明：函数 $y = x^3 + 4x$ 在 $(-\infty, +\infty)$ 上严格增。

8. 某商品的成本 $C$ 与产量 $q$ 满足 $C(q) = 100 + \frac{1}{4}q^2$，销售单价 $p$ 与产量 $q$ 满足 $p = 24200 - \frac{1}{5}q^2$。问：产量为多少时利润最大？

9. 用长为 $18$ m 的钢条制作长方体框架，长宽比为 $2:1$。问：长、宽、高各为多少时体积最大？

10. 讨论函数 $f(x) = x^3 + ax + b$ 的单调性。

### 参考答案

1. $f'(2) = \lim_{h \to 0}\frac{3(2+h)^2 - 12}{h} = \lim_{h \to 0}(12 + 3h) = 12$

2. (1) $f'(x) = 5x^4 - 9x^2 + 2$
   (2) $f'(x) = 2x\cos x - x^2\sin x$
   (3) $f'(x) = \frac{2}{(x+1)^2}$
   (4) $f'(x) = \frac{3}{3x-2}$

3. $y' = 2x - 2$，$k = y'|_{x=2} = 2$，切线方程：$y = 2(x-2)$，即 $y = 2x - 4$

4. $f'(x) = 3x^2 - 6x = 3x(x-2)$，驻点 $x = 0, 2$
   - 单调增区间：$(-\infty, 0)$ 和 $(2, +\infty)$
   - 单调减区间：$(0, 2)$
   - 极大值 $f(0) = 0$，极小值 $f(2) = -4$

5. $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$，驻点 $x = -1, 1$
   - $f(-2) = -1$，$f(-1) = 3$，$f(1) = -1$，$f(2) = 3$
   - 最大值 $3$，最小值 $-1$

## 附录：常用导数公式表

| 函数 $f(x)$ | 导数 $f'(x)$ |
|-------------|--------------|
| $C$（常数） | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\frac{1}{x}$ | $-\frac{1}{x^2}$ |
| $\sqrt{x}$ | $\frac{1}{2\sqrt{x}}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\log_a x$ | $\frac{1}{x \ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |

**运算法则**：
- $(u \pm v)' = u' \pm v'$
- $(uv)' = u'v + uv'$
- $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
- $[f(ax+b)]' = a \cdot f'(ax+b)$
