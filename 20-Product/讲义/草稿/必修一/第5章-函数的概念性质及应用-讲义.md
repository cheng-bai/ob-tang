## 二、知识点精讲

### 2.1 函数的概念

#### 2.1.1 函数的定义
设 D 是一个非空的实数集，如果按照某种确定的对应关系 f，使对集合 D 中的任意给定的 x，都有唯一的实数 y 与之对应，就称这个对应关系 f 为集合 D 上的一个**函数**，记作

$$y = f(x), x \in D$$

其中：
- **x** 叫做**自变量**（independent variable）
- **D** 称为该函数的**定义域**（domain）
- **y** 是 x 的函数，称为**函数值**
- 所有函数值组成的集合称为函数的**值域**（range）

#### 2.1.2 函数的两个要素
**定义域**和**对应关系**称为函数的两个要素。

> 注意：如果两个函数的定义域和对应关系都完全一致，就称这两个函数是相同的。

**例**：y = x² 与 y = x², x ∈ [-1,1] 是两个不同的函数（定义域不同）。

#### 2.1.3 求定义域的常见类型

| 类型 | 限制条件 | 示例 |
|------|---------|------|
| 分式 | 分母 ≠ 0 | y = 1/(x²-1)，定义域 {x | x ≠ ±1} |
| 偶次根式 | 被开方数 ≥ 0 | y = √(x+3)，定义域 [-3,+∞) |
| 对数 | 真数 > 0 | y = log₂(x+1)，定义域 (-1,+∞) |
| 复合情况 | 同时满足 | y = √x/(x-1)，定义域 [0,1)∪(1,+∞) |

---

### 2.2 函数的表示方法

#### 2.2.1 解析法
用一个数学表达式表示两个变量之间的对应关系。

**例**：y = 3x + 2, y = x² + 2x + 1, s = ½gt² (t ∈ [0,T])

#### 2.2.2 列表法
通过列出自变量的值与对应函数值的表格来表达函数关系。

**适用**：定义域为有限集的情况

#### 2.2.3 图像法
在平面直角坐标系中，把函数 y = f(x) 的所有点 (x, y) 组成的集合 G 叫做函数的**图像**。

$$G = \{(x, y) | y = f(x), x \in D\}$$

**判断图像是否为函数的方法**：垂直于 x 轴的直线与图像最多有一个交点。

#### 2.2.4 分段表示法
同一个函数在不同的区间上可以有不同的表达式。

**例**：绝对值函数
$$y = |x| = \begin{cases} x, & x \geq 0 \\ -x, & x < 0 \end{cases}$$

---

### 2.3 函数的奇偶性

#### 2.3.1 偶函数
对于函数 y = f(x)，如果对于其定义域 D 中任意给定的实数 x，都有 -x ∈ D，并且

$$f(-x) = f(x)$$

就称函数 y = f(x) 为**偶函数**（even function）。

**图像特征**：关于 y 轴成轴对称。

**常见偶函数**：y = x², y = x⁴, y = |x|, y = cos x

#### 2.3.2 奇函数
对于函数 y = f(x)，如果对于其定义域 D 中任意给定的实数 x，都有 -x ∈ D，并且

$$f(-x) = -f(x)$$

就称函数 y = f(x) 为**奇函数**（odd function）。

**图像特征**：关于原点成中心对称。

**常见奇函数**：y = x, y = x³, y = 1/x, y = sin x

#### 2.3.3 判断奇偶性的步骤
1. **先看定义域**：定义域是否关于原点对称（即 x ∈ D 时，-x 也 ∈ D）
2. **再验证关系**：计算 f(-x) 与 f(x) 的关系

> **注意**：定义域关于原点对称是函数具有奇偶性的**必要条件**。

#### 2.3.4 奇偶性的运算性质
- 偶函数 ± 偶函数 = 偶函数
- 奇函数 ± 奇函数 = 奇函数
- 偶函数 × 偶函数 = 偶函数
- 奇函数 × 奇函数 = 偶函数
- 奇函数 × 偶函数 = 奇函数

---

### 2.4 函数的单调性

#### 2.4.1 定义
对于定义在 D 上的函数 y = f(x)，设区间 I 是 D 的一个子集。

**严格增函数**：对于区间 I 上的任意给定的两个自变量的值 x₁、x₂，当 x₁ < x₂ 时，如果总有
$$f(x₁) < f(x₂)$$
就称函数 y = f(x) 在区间 I 上是**严格增函数**。

**严格减函数**：对于区间 I 上的任意给定的两个自变量的值 x₁、x₂，当 x₁ < x₂ 时，如果总有
$$f(x₁) > f(x₂)$$
就称函数 y = f(x) 在区间 I 上是**严格减函数**。

**增函数/减函数**：将上述严格不等号改为非严格不等号（≤ 或 ≥）。

#### 2.4.2 常见函数的单调性

| 函数 | 单调性 | 单调区间 |
|------|--------|---------|
| y = kx + b (k > 0) | 严格增 | (-∞,+∞) |
| y = kx + b (k < 0) | 严格减 | (-∞,+∞) |
| y = x² | 严格减/严格增 | (-∞,0] / [0,+∞) |
| y = aˣ (a > 1) | 严格增 | (-∞,+∞) |
| y = aˣ (0 < a < 1) | 严格减 | (-∞,+∞) |
| y = logₐx (a > 1) | 严格增 | (0,+∞) |
| y = logₐx (0 < a < 1) | 严格减 | (0,+∞) |

#### 2.4.3 证明单调性的步骤
1. **取值**：在区间内任取 x₁ < x₂
2. **作差**：计算 f(x₁) - f(x₂)
3. **变形**：因式分解或配方，便于判断符号
4. **定号**：判断 f(x₁) - f(x₂) 的正负
5. **结论**：得出单调性

---

### 2.5 函数的最值

#### 2.5.1 定义
**最大值**：设函数 y = f(x) 在定义域内的 x₀ 处的函数值是 f(x₀)，对于定义域内任意给定的 x，如果 f(x) ≤ f(x₀) 都成立，那么 f(x₀) 就叫做函数 y = f(x) 的**最大值**。

**最小值**：如果 f(x) ≥ f(x₀) 都成立，那么 f(x₀) 就叫做函数 y = f(x) 的**最小值**。

#### 2.5.2 求最值的常用方法
1. **配方法**（适用于二次函数）
2. **利用单调性**（单调函数在闭区间端点处取最值）
3. **利用基本不等式**
4. **判别式法**

#### 2.5.3 二次函数的最值
对于 y = ax² + bx + c (a ≠ 0)：
- 当 a > 0 时，在 x = -b/(2a) 处取得最小值 (4ac-b²)/(4a)，无最大值
- 当 a < 0 时，在 x = -b/(2a) 处取得最大值 (4ac-b²)/(4a)，无最小值

在闭区间 [m,n] 上求最值时，需要考虑顶点是否在区间内。

### 2.6 函数的应用

#### 2.6.1 建立函数关系
解决实际问题的关键是建立变量之间的函数关系，注意：
- 确定自变量和因变量
- 找出等量关系
- 确定定义域（受实际意义制约）

#### 2.6.2 函数的零点
对于函数 y = f(x), x ∈ D，如果存在实数 c ∈ D，使得 f(c) = 0，就把 c 叫做该函数的**零点**。

**几何意义**：函数图像与 x 轴交点的横坐标。

**与方程的关系**：函数的零点就是方程 f(x) = 0 的解。

#### 2.6.3 二分法求零点
**定理**：如果在区间 [a,b] 上，函数 y = f(x) 的图像是一段连续曲线，并且 f(a)·f(b) < 0，那么 y = f(x) 在区间 (a,b) 上一定有零点。

**二分法步骤**：
1. 确定区间 [a,b]，验证 f(a)·f(b) < 0
2. 求区间中点 c = (a+b)/2
3. 计算 f(c)：
   - 若 f(c) = 0，则 c 就是零点
   - 若 f(a)·f(c) < 0，则零点在 (a,c) 内，令 b = c
   - 若 f(c)·f(b) < 0，则零点在 (c,b) 内，令 a = c
4. 重复步骤2-3，直到区间长度小于要求的精度

---

### 2.7 反函数（*选学）

#### 2.7.1 定义
对于函数 y = f(x), x ∈ D，记其值域为 f(D)。如果对 f(D) 中的任意给定的一个值 y，在 D 中满足 f(x) = y 的 x 值只有一个，那么由此得到的 x 关于 y 的函数叫做 y = f(x) 的**反函数**，记作 x = f⁻¹(y), y ∈ f(D)。

习惯上写成：y = f⁻¹(x), x ∈ f(D)

#### 2.7.2 存在条件
在定义域上的**严格增函数**或**严格减函数**均存在反函数。

#### 2.7.3 性质
1. y = f(x) 与 y = f⁻¹(x) 互为反函数
2. 反函数的定义域是原函数的值域，反函数的值域是原函数的定义域
3. 互为反函数的两函数的图像关于直线 y = x 成轴对称

#### 2.7.4 常见反函数
- y = aˣ 与 y = logₐx 互为反函数 (a > 0, a ≠ 1)
- y = x³ 与 y = ∛x 互为反函数

## 三、典型例题分析

### 题型一：求函数的定义域

**例1** 求下列函数的定义域：

(1) y = 1/(x² - 1)

**解**：由 x² - 1 ≠ 0，得 x ≠ ±1
∴ 定义域 D = {x | x ≠ ±1}

(2) y = log₂(x + 1)

**解**：由 x + 1 > 0，得 x > -1
∴ 定义域 D = (-1, +∞)

(3) y = √(x+3)/(x-1)

**解**：需满足 { x + 3 ≥ 0, x - 1 ≠ 0 }
即 x ≥ -3 且 x ≠ 1
∴ 定义域 D = [-3, 1) ∪ (1, +∞)

---

### 题型二：判断函数的奇偶性

**例2** 判断下列函数的奇偶性：

(1) y = 2x⁴ - 3x²

**解**：定义域为 R，关于原点对称。
记 f(x) = 2x⁴ - 3x²
f(-x) = 2(-x)⁴ - 3(-x)² = 2x⁴ - 3x² = f(x)
∴ 该函数是**偶函数**

(2) y = x³ - 1/x

**解**：定义域 D = {x | x ≠ 0}，关于原点对称。
记 f(x) = x³ - 1/x
f(-x) = (-x)³ - 1/(-x) = -x³ + 1/x = -(x³ - 1/x) = -f(x)
∴ 该函数是**奇函数**

(3) y = (x-1)²

**解**：定义域为 R。
f(1) = 0, f(-1) = 4 ≠ f(1)，不是偶函数
f(-1) = 4 ≠ -f(1) = 0，不是奇函数
∴ 该函数**既不是奇函数也不是偶函数**

---

### 题型三：证明函数的单调性

**例3** 证明：函数 y = x² - 2x 在区间 (-∞, 1] 上是严格减函数。

**证明**：记 f(x) = x² - 2x
设 x₁、x₂ 是区间 (-∞, 1] 上任意给定的两个实数，且 x₁ < x₂

f(x₁) - f(x₂) = (x₁² - 2x₁) - (x₂² - 2x₂)
= (x₁² - x₂²) - 2(x₁ - x₂)
= (x₁ - x₂)(x₁ + x₂ - 2)

∵ x₁ < x₂ ≤ 1
∴ x₁ - x₂ < 0
且 x₁ + x₂ - 2 < 1 + 1 - 2 = 0

∴ f(x₁) - f(x₂) = (负数) × (负数) > 0
即 f(x₁) > f(x₂)

∴ 函数 y = x² - 2x 在区间 (-∞, 1] 上是**严格减函数**。

---

### 题型四：求函数的最值

**例4** 求函数 y = 2x² - 3x + 1, x ∈ R 的最大值与最小值。

**解**：y = 2x² - 3x + 1
= 2(x - 3/4)² - 1/8 ≥ -1/8

当 x = 3/4 时，等号成立。
∴ 该函数的**最小值为 -1/8**，无最大值。

**例5** 求函数 y = 2/x, x ∈ [1, 2] 的最大值与最小值。

**解**：函数 y = 2/x 在区间 [1, 2] 上是严格减函数
∴ 最大值在左端点 x = 1 处取得，y_max = 2/1 = 2
最小值在右端点 x = 2 处取得，y_min = 2/2 = 1

---

### 题型五：建立函数关系

**例6** 要建造一面靠墙、且面积相同的两间相邻的长方形居室，围墙总长度为 30m。当宽 x 为多少时，才能使所建造的居室总面积最大？最大总面积是多少？

**解**：设宽为 x m，则两间居室的总长为 (30 - 3x) m

总面积 y = x(30 - 3x) = -3x² + 30x = -3(x - 5)² + 75

由实际意义，0 < x < 10

当 x = 5 时，y 取得最大值 75

**答**：当居室的宽为 5m 时，其总面积最大，最大总面积为 75m²。

---

### 题型六：用二分法求零点

**例7** 已知函数 y = x³ + 2x - 99，判断方程 x³ + 2x = 99 是否有整数解。

**解**：记 f(x) = x³ + 2x - 99

首先证明 f(x) 是严格增函数：
对任意 x₁ < x₂，有 x₁³ < x₂³ 且 2x₁ < 2x₂
∴ f(x₁) < f(x₂)

计算：f(4) = 64 + 8 - 99 = -27 < 0
f(5) = 125 + 10 - 99 = 36 > 0

由单调性可知，当 n ≤ 4 时，f(n) < 0；当 n ≥ 5 时，f(n) > 0
∴ 方程**没有整数解**。

## 四、方法技巧总结

### 4.1 求定义域的技巧
1. **分式函数**：分母不为零
2. **根式函数**：偶次根号下非负
3. **对数函数**：真数大于零
4. **复合函数**：取各部分定义域的交集
5. **实际问题**：考虑实际意义的限制

### 4.2 判断奇偶性的技巧
1. **先判断定义域**是否关于原点对称（必要条件）
2. **计算 f(-x)**，与 f(x) 和 -f(x) 比较
3. **特殊值检验**：取特殊值快速排除
4. **"先猜后证"**：对复杂函数，先通过特殊值猜测，再严格证明

### 4.3 证明单调性的技巧
1. **作差法**：f(x₁) - f(x₂)，判断符号
2. **作商法**：f(x₁)/f(x₂)，与 1 比较（适用于恒正或恒负函数）
3. **导数法**（后续学习）：利用导数的符号判断

### 4.4 求最值的技巧
1. **二次函数**：配方法，注意顶点是否在区间内
2. **单调函数**：在闭区间端点处取最值
3. **利用奇偶性**：偶函数在对称区间上最值相同
4. **分类讨论**：含参数时，根据参数取值分类讨论

### 4.5 建立函数模型的步骤
1. **审题**：理解题意，找出变量
2. **建模**：建立等量关系，写出函数表达式
3. **定域**：根据实际意义确定定义域
4. **求解**：利用函数性质求解
5. **检验**：检验结果是否符合实际

## 五、常见错误警示

### 错误1：忽视定义域
**错例**：判断 y = x², x ∈ (k, 2) (k < 2) 的奇偶性时，不先考虑定义域是否关于原点对称。

**正解**：只有当 k = -2 时，定义域 (-2, 2) 关于原点对称，才可能是奇函数或偶函数。

### 错误2：混淆"增函数"与"严格增函数"
**注意**：增函数允许 f(x₁) = f(x₂)，严格增函数要求 f(x₁) < f(x₂)。

### 错误3：求最值时忽视定义域
**错例**：求 y = x² - 2x 在 [-2, 2] 上的最值时，只考虑顶点 x = 1。

**正解**：需比较 f(1) = -1, f(-2) = 8, f(2) = 0，最大值为 8，最小值为 -1。

### 错误4：分段函数判断奇偶性时出错
**注意**：分段函数要分别验证各段的奇偶性条件。

### 错误5：用二分法时忽略连续性条件
**注意**：二分法要求函数在区间上的图像是连续曲线。

## 附录：本章公式速查

### 函数概念
- 定义：y = f(x), x ∈ D
- 定义域 + 对应关系 = 函数的两个要素

### 奇偶性
- 偶函数：f(-x) = f(x)，图像关于 y 轴对称
- 奇函数：f(-x) = -f(x)，图像关于原点对称

### 单调性
- 严格增：x₁ < x₂ ⇒ f(x₁) < f(x₂)
- 严格减：x₁ < x₂ ⇒ f(x₁) > f(x₂)

### 二次函数 y = ax² + bx + c (a ≠ 0)
- 顶点：(-b/2a, (4ac-b²)/4a)
- a > 0 时，开口向上，有最小值
- a < 0 时，开口向下，有最大值
