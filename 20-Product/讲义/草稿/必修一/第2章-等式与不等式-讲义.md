# 第2章 等式与不等式 · 讲义

## 1. 本章解决什么问题

本章建立高中数学中数量关系的基础理论：
- **等式**：相等关系的表示与方程求解
- **不等式**：不等关系的表示、求解与证明
- **基本不等式**：最值问题与不等式证明的重要工具

> 先修知识：初中方程与不等式基础
> 后续关联：函数定义域、值域、最值问题

---

## 2. 知识主线图

```
等式与不等式的性质
├── 等式的性质
│   ├── 传递性: a = b, b = c ⇒ a = c
│   ├── 加法性质: a = b ⇒ a + c = b + c
│   └── 乘法性质: a = b ⇒ ac = bc
├── 不等式的性质
│   ├── 传递性: a > b, b > c ⇒ a > c
│   ├── 加法性质: a > b ⇒ a + c > b + c
│   ├── 乘法性质: a > b, c > 0 ⇒ ac > bc
│   │              a > b, c < 0 ⇒ ac < bc
│   ├── 同向可加性: a > b, c > d ⇒ a + c > b + d
│   └── 倒数性质: a > b > 0 ⇒ 1/b > 1/a > 0
│
方程的解集
├── 一元一次方程 ax = b 的解集分类
├── 一元二次方程 ax² + bx + c = 0 (a ≠ 0)
│   ├── Δ > 0: 两不同实根 {x₁, x₂}
│   ├── Δ = 0: 重根 {-b/2a}
│   └── Δ < 0: 无实根 ∅
└── 韦达定理: x₁ + x₂ = -b/a, x₁x₂ = c/a

不等式的求解
├── 一元一次不等式(组)
├── 一元二次不等式 (a > 0)
│   ├── Δ > 0: ax²+bx+c>0 解集 (-∞,x₁)∪(x₂,+∞)
│   │            ax²+bx+c<0 解集 (x₁,x₂)
│   ├── Δ = 0: ax²+bx+c>0 解集 (-∞,x₁)∪(x₁,+∞)
│   │            ax²+bx+c<0 解集 ∅
│   └── Δ < 0: ax²+bx+c>0 解集 R
│               ax²+bx+c<0 解集 ∅
├── 分式不等式: 转化为整式不等式组
└── 含绝对值不等式
    ├── |x| < a (a>0) ⇔ -a < x < a
    └── |x| > a (a>0) ⇔ x > a 或 x < -a

基本不等式及其应用
├── 平均值不等式: (a+b)/2 ≥ √ab (a>0,b>0)
│   └── 等号成立条件: a = b
├── 常用不等式: a² + b² ≥ 2ab
│   └── 等号成立条件: a = b
└── 三角不等式: |a+b| ≤ |a| + |b|
    └── 等号成立条件: ab ≥ 0
```

## 3. 核心概念与判定条件

### 3.1 实数大小比较的基础

| 关系 | 判定条件 |
|------|----------|
| a > b | a - b > 0 |
| a = b | a - b = 0 |
| a < b | a - b < 0 |

### 3.2 一元二次方程解集判定

| 判别式 Δ | 方程 ax²+bx+c=0 | 解集 |
|----------|-----------------|------|
| Δ > 0 | 两不同实根 x₁ < x₂ | {(-b±√Δ)/2a} |
| Δ = 0 | 重根 x₁ = x₂ | {-b/2a} |
| Δ < 0 | 无实根 | ∅ |

### 3.3 一元二次不等式解集 (a > 0)

| Δ | ax²+bx+c > 0 | ax²+bx+c < 0 |
|---|---------------|---------------|
| Δ > 0 | (-∞,x₁)∪(x₂,+∞) | (x₁,x₂) |
| Δ = 0 | (-∞,x₁)∪(x₁,+∞) | ∅ |
| Δ < 0 | R | ∅ |

口诀：**大于取两边，小于取中间** (Δ > 0 时)

### 3.4 基本不等式链 (a > 0, b > 0)

```
调和平均 ≤ 几何平均 ≤ 算术平均 ≤ 平方平均

2/(1/a+1/b) ≤ √ab ≤ (a+b)/2 ≤ √((a²+b²)/2)
```

等号当且仅当 a = b 时成立

## 4. 方法模板

### 模板1：比较两数(式)大小

**识别特征**：需要比较 A 与 B 的大小

**操作步骤**：
1. 作差：计算 A - B
2. 变形：因式分解或配方
3. 定号：判断差的正负
4. 结论：A > B ⇔ A-B > 0

**示例**：比较 a²+b² 与 2ab
- 作差：a²+b² - 2ab = (a-b)²
- 定号：(a-b)² ≥ 0
- 结论：a²+b² ≥ 2ab，等号当且仅当 a = b

---

### 模板2：解一元二次不等式

**识别特征**：形如 ax²+bx+c > 0 (或 < 0, ≥ 0, ≤ 0)

**操作步骤**：
1. 标准化：确保 a > 0 (若 a < 0，两边乘 -1，不等号反向)
2. 求判别式：Δ = b² - 4ac
3. 求根（若 Δ ≥ 0）：x₁, x₂ = (-b±√Δ)/2a
4. 定解集：
   - > 0 取两边，< 0 取中间 (Δ > 0)
   - Δ = 0 或 Δ < 0 查表

**示例**：解 -2x² + 3x - 1/2 ≥ 0
1. 标准化：2x² - 3x + 1/2 ≤ 0
2. Δ = 9 - 4 = 5 > 0
3. 根：x = (3±√5)/4
4. 解集：[(3-√5)/4, (3+√5)/4]

---

### 模板3：解分式不等式

**识别特征**：形如 P(x)/Q(x) > 0 (或 < 0, ≥ 0, ≤ 0)

**操作步骤**：
1. 移项：化为一边为 0 的形式
2. 通分：合并为一个分式
3. 转化：
   - P/Q > 0 ⇔ P·Q > 0 且 Q ≠ 0
   - P/Q < 0 ⇔ P·Q < 0 且 Q ≠ 0
   - P/Q ≥ 0 ⇔ P·Q ≥ 0 且 Q ≠ 0
4. 解整式不等式

**注意**：分母不能为零！

---

### 模板4：解含绝对值不等式

**识别特征**：含 |f(x)| 的不等式

**核心公式** (a > 0)：
- |x| < a ⇔ -a < x < a
- |x| > a ⇔ x > a 或 x < -a
- |x-a| + |x-b| 型：找零点，分段讨论

**操作步骤**：
1. 找零点：令绝对值内表达式 = 0
2. 分区间：用零点划分数轴
3. 去绝对值：在各区间确定符号
4. 求解：在各区间解不等式
5. 合并：取各区间解的并集

---

### 模板5：利用基本不等式求最值

**识别特征**：求最值问题，出现和或积为定值

**核心公式**：
- 若 a > 0, b > 0，则 (a+b)/2 ≥ √ab
- **和定积最大**：a+b = S（定值），则 ab ≤ S²/4
- **积定和最小**：ab = P（定值），则 a+b ≥ 2√P

**操作步骤**：
1. 识别：确定是"和定"还是"积定"
2. 验证：检查是否为正数、能否取等
3. 应用：套用基本不等式
4. 结论：写出最值及取等条件

**注意三要素**：
- 一正：各项为正
- 二定：和或积为定值
- 三相等：等号能取到

## 5. 典型例题

### 例题1：韦达定理的应用

**题目**：已知方程 x² + x - 3 = 0 的两根为 x₁, x₂，求：
(1) x₁²x₂ + x₂²x₁
(2) |x₁ - x₂|

**解析**：
由韦达定理：x₁ + x₂ = -1，x₁x₂ = -3

(1) x₁²x₂ + x₂²x₁ = x₁x₂(x₁+x₂) = (-3)×(-1) = 3

(2) |x₁-x₂| = √[(x₁-x₂)²] = √[(x₁+x₂)² - 4x₁x₂]
   = √[1 - 4×(-3)] = √13

---

### 例题2：一元二次不等式求解

**题目**：解不等式 -x² + 3x - 4 > 0

**解析**：
1. 标准化：x² - 3x + 4 < 0
2. Δ = 9 - 16 = -7 < 0
3. 由表2-2，解集为 ∅

---

### 例题3：分式不等式

**题目**：解不等式 (2x+1)/(x-1) ≤ 3

**解析**：
1. 移项：(2x+1)/(x-1) - 3 ≤ 0
2. 通分：(2x+1-3x+3)/(x-1) ≤ 0，即 (-x+4)/(x-1) ≤ 0
3. 转化为：(x-4)/(x-1) ≥ 0 且 x ≠ 1
4. 解集：(-∞, 1) ∪ [4, +∞)

---

### 例题4：含绝对值不等式

**题目**：解不等式 |x-3| + |x-5| < 4

**解析**：
零点：x = 3, x = 5

**区间1**：x < 3
原式化为：3-x + 5-x < 4，即 8-2x < 4，x > 2
∴ 2 < x < 3

**区间2**：3 ≤ x < 5
原式化为：x-3 + 5-x < 4，即 2 < 4（恒成立）
∴ 3 ≤ x < 5

**区间3**：x ≥ 5
原式化为：x-3 + x-5 < 4，即 2x-8 < 4，x < 6
∴ 5 ≤ x < 6

综上，解集为 (2, 6)

---

### 例题5：基本不等式求最值

**题目**：设 x > 0，求 x + 1/x 的最小值

**解析**：
∵ x > 0，∴ 1/x > 0
由平均值不等式：
x + 1/x ≥ 2√(x·1/x) = 2

等号当且仅当 x = 1/x，即 x = 1 时成立

∴ 最小值为 2

---

### 例题6：三角不等式应用

**题目**：证明 |x-3| + |x-5| ≥ 2 对所有实数 x 恒成立

**解析**：
|x-3| + |x-5| = |x-3| + |5-x|
≥ |(x-3)+(5-x)| = |2| = 2

等号当且仅当 (x-3)(5-x) ≥ 0，即 x ∈ [3,5] 时成立

## 6. 易错点

| 陷阱 | 错误示例 | 正确理解 |
|------|----------|----------|
| **乘负数忘变号** | a > b, c < 0 时 ac > bc ❌ | ac < bc（不等号反向） |
| **分式不等式直接去分母** | (x+1)/(x-2) > 0 两边乘 (x-2) ❌ | 转化为 (x+1)(x-2) > 0 且 x ≠ 2 |
| **忽略分母为零** | (2x+1)/(x-1) ≤ 1 解集含 x=1 ❌ | x=1 使分母为零，必须排除 |
| **基本不等式一正** | x + 1/x ≥ 2 对 x < 0 也成立 ❌ | 必须 x > 0 才能用 |
| **基本不等式三相等** | 求最值时不验证等号条件 ❌ | 必须验证等号能否取到 |
| **绝对值零点遗漏** | |x-1| + |x-2| 分段只分两段 ❌ | n 个绝对值分 n+1 段 |
| **韦达定理条件** | 对无实根方程用韦达定理 ❌ | 前提是 Δ ≥ 0 |
| **解集端点开闭** | ax²+bx+c ≤ 0 解集写成 (x₁,x₂) ❌ | 应写成 [x₁,x₂] |
