# 第3章 幂、指数与对数 讲义

## 一、本章解决什么问题

本章核心任务是建立指数运算的完整体系，并引入对数作为指数运算的逆运算。

**主要解决的问题：**
1. 将指数从正整数拓展到整数、有理数，最终到实数
2. 定义分数指数幂，建立根式与分数指数幂的联系
3. 引入对数概念，掌握对数运算性质及换底公式
4. 为后续学习幂函数、指数函数和对数函数奠定基础

**实际应用背景：**
- 复利计算：解决"1万元以5%年利率复利，多少年超过5万元"的问题
- 声强级计算：分贝的定义与计算
- 地震能量：里氏震级的计算
- 简化多位数乘除运算（历史背景）

## 三、核心概念与判定条件

### 3.1 指数幂的拓展

#### 1. 整数指数幂

**定义：**
- 零指数：a⁰ = 1 (a ≠ 0)
- 负整数指数：a⁻ⁿ = 1/aⁿ (a ≠ 0, n ∈ ℕ⁺)

**运算性质（对任意整数s、t成立）：**
1. aˢ · aᵗ = aˢ⁺ᵗ
2. (aˢ)ᵗ = aˢᵗ
3. (ab)ᵗ = aᵗbᵗ

#### 2. 根式与分数指数幂

**n次方根定义：**
若 xⁿ = a，则 x 叫做 a 的 n 次方根，记作 ⁿ√a

**重要结论：**
- n为奇数：ⁿ√(aⁿ) = a
- n为偶数：ⁿ√(aⁿ) = |a|

**分数指数幂定义：**
- a^(1/n) = ⁿ√a (a > 0, n > 1)
- a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ (a > 0, m ∈ ℤ, n > 1)

**底数限制：**
- 当指数拓展到实数时，要求底数 a > 0
- 当 a < 0 且 n 为正奇数时，a^(1/n) 可定义

#### 3. 实数指数幂的运算性质

对任意正数 a、b 及实数 s、t：
1. aˢ · aᵗ = aˢ⁺ᵗ
2. (aˢ)ᵗ = aˢᵗ
3. (ab)ᵗ = aᵗbᵗ

**幂的基本不等式：**
当 a > 1, s > 0 时，aˢ > 1

---

### 3.2 对数

#### 1. 对数的定义

**定义：**
若 aˣ = N (a > 0, a ≠ 1, N > 0)，则 x = logₐN

**基本恒等式：**
- a^(logₐN) = N
- logₐ(aˣ) = x

**特殊值：**
- logₐ1 = 0
- logₐa = 1

**常用对数：**
- 常用对数：lg N = log₁₀N
- 自然对数：ln N = logₑN (e ≈ 2.71828)

#### 2. 对数运算性质

设 a > 0, a ≠ 1, M > 0, N > 0：

| 性质 | 公式 | 口诀 |
|------|------|------|
| 积的对数 | logₐ(MN) = logₐM + logₐN | 积变和 |
| 商的对数 | logₐ(M/N) = logₐM - logₐN | 商变差 |
| 幂的对数 | logₐ(Nᶜ) = c·logₐN | 幂前移 |

#### 3. 换底公式

**公式：**
logₐb = logₐb / logₐa (a > 0, a ≠ 1, c > 0, c ≠ 1, b > 0)

**常用推论：**
- logₐb · logₐa = 1
- log_(aᵐ)(Nⁿ) = (n/m)·logₐN

## 四、方法模板

### 模板1：指数幂化简

**步骤：**
1. 统一为分数指数幂形式
2. 运用运算性质合并同类项
3. 化简求值

**示例：**
化简 (a^(2/3)·b^(1/2)) · (-3a^(1/2)·b^(1/3)) / (1/3·a^(1/6)·b^(5/6))

解：
= (-3 × 3) · a^(2/3+1/2-1/6) · b^(1/2+1/3-5/6)
= -9 · a¹ · b⁰
= -9a

---

### 模板2：对数式化简求值

**步骤：**
1. 观察底数与真数的关系
2. 灵活运用对数性质（积、商、幂）
3. 必要时使用换底公式统一底数

**常用技巧：**
- 拆：将乘积拆成和
- 合：将和合成乘积
- 换：不同底时换底

**示例：**
求 2log₅10 + log₅3 - log₅12

解：
= log₅10² + log₅3 - log₅12
= log₅(100×3÷12)
= log₅25
= 2

---

### 模板3：指数式与对数式互化

**互化关系：**
aˣ = N ⇔ x = logₐN

**应用场景：**
1. 已知指数式求对数值
2. 已知对数值求指数式中的未知数
3. 解指数方程和对数方程

---

### 模板4：换底公式的应用

**适用场景：**
- 不同底的对数运算
- 求对数值的近似值
- 证明对数恒等式

**示例：**
求 log₂25 · log₃4 · log₅9

解：
= log₂5² · log₃2² · log₅3²
= 2log₂5 · 2log₃2 · 2log₅3
= 8 · (lg5/lg2) · (lg2/lg3) · (lg3/lg5)
= 8

## 五、典型例题

### 例题1：根式与分数指数幂互化

**题目：** 用有理数指数幂的形式表示：
(1) ³√(a²)  (2) a³ · ⁴√(a³)  (3) √(a√a)

**解答：**
(1) ³√(a²) = a^(2/3)

(2) a³ · ⁴√(a³) = a³ · a^(3/4) = a^(3+3/4) = a^(15/4)

(3) √(a√a) = (a · a^(1/2))^(1/2) = (a^(3/2))^(1/2) = a^(3/4)

---

### 例题2：指数幂运算

**题目：** 求值：
(1) 4^(3/2)  (2) (81/625)^(-3/4)

**解答：**
(1) 4^(3/2) = (2²)^(3/2) = 2³ = 8

(2) (81/625)^(-3/4) = (625/81)^(3/4) = [(625/81)^(1/4)]³ = (5/3)³ = 125/27

---

### 例题3：对数求值

**题目：** 求下列各式的值：
(1) log₂8  (2) log₂√2  (3) log₁₀0.00001

**解答：**
(1) ∵ 2³ = 8 ∴ log₂8 = 3

(2) ∵ 2^(1/2) = √2 ∴ log₂√2 = 1/2

(3) ∵ 10⁻⁵ = 0.00001 ∴ log₁₀0.00001 = -5

---

### 例题4：对数运算性质应用

**题目：** 已知 log₅2 = a, 5ᵇ = 3，用a、b表示log₅12

**解答：**
∵ 5ᵇ = 3 ∴ log₅3 = b

log₅12 = log₅(2² × 3) = log₅2² + log₅3 = 2log₅2 + log₅3 = 2a + b

---

### 例题5：换底公式应用

**题目：** 求值：log₄8 - log_(1/9)3 - log_√2 4

**解答：**
log₄8 = log₄4^(3/2) = 3/2

log_(1/9)3 = log_(3⁻²)3 = -1/2 · log₃3 = -1/2

log_√2 4 = log_(2^(1/2))2² = 2/(1/2) · log₂2 = 4

原式 = 3/2 - (-1/2) - 4 = 3/2 + 1/2 - 4 = 2 - 4 = -2

---

### 例题6：综合应用（声强级）

**题目：** 声强级 y = 10lg(I/I₀)，其中I₀ = 10⁻¹² W/m²
(1) 当I = 10 W/m²时，求声强级
(2) 声强级为60dB时的声强度I₆₀是声强级为50dB时的声强度I₅₀的多少倍？

**解答：**
(1) y = 10lg(10/10⁻¹²) = 10lg(10¹³) = 10×13 = 130 dB

(2) 由题意：
60 = 10lg(I₆₀/I₀) → lg(I₆₀/I₀) = 6
50 = 10lg(I₅₀/I₀) → lg(I₅₀/I₀) = 5

两式相减：lg(I₆₀/I₅₀) = 1
∴ I₆₀/I₅₀ = 10

## 六、易错点

### 易错点1：忽略底数限制条件

**错误：** 认为 (-4)^(1/2) = √(-4) 有意义

**纠正：** 
- 当指数拓展到实数时，要求底数 a > 0
- 负数没有偶次方根
- 当 a < 0 且 n 为正奇数时，a^(1/n) 才有意义

---

### 易错点2：混淆 (aᵐ)ⁿ 与 a^(mⁿ)

**错误：** 认为 (aᵐ)ⁿ = a^(mⁿ)

**纠正：**
- (aᵐ)ⁿ = a^(mn) （指数相乘）
- a^(mⁿ) 表示 a 的 (mⁿ) 次幂

**示例：**
(2³)² = 2⁶ = 64
2^(3²) = 2⁹ = 512

---

### 易错点3：对数真数必须为正

**错误：** 计算 log₂(-4)

**纠正：**
- 对数的真数必须大于0
- 对数的底必须大于0且不等于1

---

### 易错点4：混淆 logₐ(M+N) 与 logₐM + logₐN

**错误：** logₐ(M+N) = logₐM + logₐN

**纠正：**
- logₐ(MN) = logₐM + logₐN （积的对数等于对数的和）
- logₐ(M+N) ≠ logₐM + logₐN

---

### 易错点5：换底公式使用不当

**错误：** logₐb = logₐb / logₐa （忘记换底后的底数要一致）

**纠正：**
logₐb = logₐb / logₐa = lgb / lga = lnb / lna

换底后，分子分母的对数底数必须相同。

---

### 易错点6：忽略根式中变量的取值范围

**错误：** √(a-b)² = a-b （未考虑a与b的大小关系）

**纠正：**
√(a-b)² = |a-b| = {
  a-b, 当 a ≥ b
  b-a, 当 a < b
}

## 内容提要总结

### 指数幂
1. **拓展过程：** 正整数 → 整数 → 有理数 → 实数
2. **运算性质：** aˢ·aᵗ=aˢ⁺ᵗ, (aˢ)ᵗ=aˢᵗ, (ab)ᵗ=aᵗbᵗ
3. **分数指数：** a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ

### 对数
1. **定义：** aˣ=N ⇔ x=logₐN (a>0, a≠1, N>0)
2. **运算性质：**
   - logₐ(MN) = logₐM + logₐN
   - logₐ(M/N) = logₐM - logₐN
   - logₐ(Nᶜ) = c·logₐN
3. **换底公式：** logₐb = logₐb/logₐa

### 核心关系
- 指数与对数互为逆运算
- 根式与分数指数幂等价
