# 第1章 集合与逻辑 · 讲义

## 1. 本章解决什么问题

本章建立高中数学的基础语言系统：
- **集合**：现代数学的基本语言，用于准确描述研究对象及其关系
- **逻辑用语**：数学推理的基础，包括命题、条件关系与证明方法

> 核心目标：学会用集合语言描述数学对象，用逻辑语言进行严密推理
> 后续关联：函数定义域、值域、不等式解集等都需要用集合表示

## 2. 知识主线图

```
集合初步
├── 集合的概念
│   ├── 定义：确定对象的全体
│   ├── 元素特性：确定性、互异性、无序性
│   ├── 元素与集合的关系：∈（属于），∉（不属于）
│   └── 常用数集：N（自然数），Z（整数），Q（有理数），R（实数）
│
├── 集合的表示方法
│   ├── 列举法：{1, 2, 3}（适用于有限集或有规律的无限集）
│   ├── 描述法：{x | x满足性质p}
│   └── 区间表示：闭区间[a,b]，开区间(a,b)，半开半闭区间[a,b)
│       └── 无穷区间：(-∞,+∞)，[a,+∞)，(-∞,b)
│
├── 集合间的关系
│   ├── 子集：A ⊆ B（A的每个元素都属于B）
│   ├── 真子集：A ⊂ B（A ⊆ B 且 A ≠ B）
│   ├── 集合相等：A = B ⇔ A ⊆ B 且 B ⊆ A
│   └── 数集的包含关系：N ⊂ Z ⊂ Q ⊂ R
│
└── 集合的运算
    ├── 交集：A ∩ B = {x | x ∈ A 且 x ∈ B}
    ├── 并集：A ∪ B = {x | x ∈ A 或 x ∈ B}
    ├── 补集：Ā = {x | x ∈ U 且 x ∉ A}（U为全集）
    └── 运算律：德摩根定律等

常用逻辑用语
├── 命题
│   ├── 定义：能判断真假的陈述句
│   ├── 真命题与假命题
│   └── 命题的形式："若α，则β"（α为条件，β为结论）
│
├── 充分条件与必要条件
│   ├── α ⇒ β：α是β的充分条件，β是α的必要条件
│   ├── α ⇔ β：α是β的充要条件（等价）
│   ├── 集合语言：α ⇒ β ⇔ {x|α} ⊆ {x|β}
│   └── 判断方法：双向推导或举反例
│
└── 反证法
    ├── 步骤：假设结论不成立 → 推出矛盾 → 结论成立
    ├── 常用否定形式
    └── 经典应用：证明√2是无理数
```

## 3. 核心概念与判定条件

### 3.1 集合元素的三要素

| 特性 | 含义 | 反例 |
|------|------|------|
| **确定性** | 元素是否属于集合是明确的 | "高个子同学"不能构成集合 |
| **互异性** | 同一集合中元素不重复 | {1, 1, 2} = {1, 2} |
| **无序性** | 元素排列顺序无关 | {1, 2, 3} = {3, 2, 1} |

### 3.2 常用数集符号

| 数集 | 符号 | 包含范围 |
|------|------|----------|
| 自然数集 | N | 0, 1, 2, 3, ... |
| 整数集 | Z | ..., -2, -1, 0, 1, 2, ... |
| 有理数集 | Q | 可表示为p/q（p,q∈Z，q≠0）的数 |
| 实数集 | R | 有理数和无理数的全体 |

包含关系：N ⊂ Z ⊂ Q ⊂ R

### 3.3 区间表示法

| 集合 | 区间表示 | 数轴表示 |
|------|----------|----------|
| {x | a ≤ x ≤ b} | [a, b] | 闭区间，端点实心 |
| {x | a < x < b} | (a, b) | 开区间，端点空心 |
| {x | a ≤ x < b} | [a, b) | 左闭右开 |
| {x | x ≥ a} | [a, +∞) | 左实心，向右无限 |
| {x | x < b} | (-∞, b) | 向右空心，向左无限 |
| R | (-∞, +∞) | 整个数轴 |

### 3.4 集合关系判定

| 关系 | 符号 | 定义 | Venn图特征 |
|------|------|------|------------|
| 子集 | A ⊆ B | ∀x∈A, 都有x∈B | A在B内或与B重合 |
| 真子集 | A ⊂ B | A ⊆ B 且 A ≠ B | A在B内但不重合 |
| 相等 | A = B | A ⊆ B 且 B ⊆ A | 两集合完全重合 |
| 交集 | A ∩ B | 同时属于A和B的元素 | 两集合重叠部分 |
| 并集 | A ∪ B | 属于A或属于B的元素 | 两集合全部覆盖区域 |
| 补集 | Ā | 全集中不属于A的元素 | U中A以外的部分 |

### 3.5 子集个数公式

若集合A有n个元素，则：
- 子集个数：$2^n$
- 真子集个数：$2^n - 1$
- 非空子集个数：$2^n - 1$
- 非空真子集个数：$2^n - 2$

### 3.6 条件关系的判定

| 关系 | 符号 | 含义 | 集合表示 |
|------|------|------|----------|
| 充分条件 | α ⇒ β | α成立则β一定成立 | {x|α} ⊆ {x|β} |
| 必要条件 | β ⇒ α | β成立则α一定成立 | {x|β} ⊆ {x|α} |
| 充要条件 | α ⇔ β | α与β等价 | {x|α} = {x|β} |
| 充分不必要 | α ⇒ β 且 β ⇏ α | α是β的真子集 | {x|α} ⊂ {x|β} |
| 必要不充分 | β ⇒ α 且 α ⇏ β | β是α的真子集 | {x|β} ⊂ {x|α} |

### 3.7 常用否定形式

| 原命题 | 否定形式 |
|--------|----------|
| x > 1 | x ≤ 1 |
| x > 1 或 y > 1 | x ≤ 1 且 y ≤ 1 |
| x > 1 且 y > 1 | x ≤ 1 或 y ≤ 1 |
| 所有的a∈A满足p | 至少存在一个a∈A不满足p |
| 至少有一个a∈A满足p | 所有的a∈A都不满足p |

## 4. 方法模板

### 模板1：集合的表示方法选择

**识别特征**：需要将描述转化为集合符号

**选择策略**：
1. **列举法**：元素个数有限且较少，或无限但有明显规律
2. **描述法**：元素有共同特征，或元素个数很多
3. **区间法**：实数集的连续范围

**示例**：
- 大于0且小于10的偶数：列举法 {2, 4, 6, 8}
- 被3除余2的自然数：描述法 {n | n = 3k+2, k∈N}
- -1 < x ≤ 5：区间法 (-1, 5]

---

### 模板2：判断集合间的关系

**识别特征**：比较两个集合的包含关系

**操作步骤**：
1. 化简两个集合（解方程、不等式等）
2. 判断元素归属：A中每个元素是否都属于B
3. 验证反向：B中是否至少有一个元素不属于A
4. 得出结论：
   - A ⊆ B 且 B ⊆ A → A = B
   - A ⊆ B 且 B ⊈ A → A ⊂ B
   - A ⊈ B → 无包含关系

**示例**：判断A = {n | n = 3k+1, k∈N}与B = {n | n = 3m-2, m∈N}的关系
- 当k∈N时，A中元素n = 3k+1 = 3(k+1)-2 ∈ B，∴ A ⊆ B
- 但-2 ∈ B（m=0时）而-2 ∉ A，∴ A ⊂ B

---

### 模板3：集合运算求解

**识别特征**：求交集、并集、补集

**操作步骤**：
1. **交集A ∩ B**：找公共元素（"且"）
2. **并集A ∪ B**：合并所有元素（"或"），注意去重
3. **补集Ā**：全集中去掉A的元素

**数轴法**（适用于实数区间）：
1. 在数轴上标出各集合
2. 交集：重叠部分
3. 并集：覆盖的所有部分
4. 补集：剩余部分

**示例**：A = (-2, 2)，B = (-3, -1) ∪ (1, +∞)
- A ∩ B = (-2, -1) ∪ (1, 2)
- A ∪ B = (-3, +∞)

---

### 模板4：判断条件关系

**识别特征**：判断α是β的什么条件

**操作步骤**：
1. 判断α ⇒ β是否成立（充分性）
   - 成立：α是β的充分条件
   - 不成立：举反例
2. 判断β ⇒ α是否成立（必要性）
   - 成立：α是β的必要条件
   - 不成立：举反例
3. 综合结论：
   - 双向成立：充要条件
   - 仅α ⇒ β：充分不必要
   - 仅β ⇒ α：必要不充分
   - 都不成立：既不充分也不必要

**示例**：α：四边形ABCD是正方形；β：四边形ABCD的四个内角都是直角
- α ⇒ β：正方形四个角都是直角 ✓（充分）
- β ⇒ α：矩形四个角都是直角，但不一定是正方形 ✗
- 结论：α是β的充分不必要条件

---

### 模板5：反证法证明

**识别特征**：直接证明困难，或结论含"不是"、"不存在"、"至少"等

**操作步骤**：
1. **反设**：假设结论不成立（否定结论）
2. **推导**：从假设出发，结合已知条件进行逻辑推理
3. **矛盾**：推出与已知条件、公理、定理矛盾的结果
4. **结论**：假设不成立，原结论成立

**经典应用**：
- 证明√2是无理数
- 证明素数有无穷多个
- 证明"若n²是偶数，则n是偶数"

## 5. 典型例题

### 例题1：集合的表示与运算

**题目**：已知集合A = {x | -2 < x ≤ 1}，B = {x | x² - 3x + 2 ≤ 0}
求：(1) A ∩ B；(2) A ∪ B；(3) 若全集U = R，求∁ᵤA

**解析**：
(1) 先化简B：x² - 3x + 2 ≤ 0 ⇔ (x-1)(x-2) ≤ 0 ⇔ 1 ≤ x ≤ 2
   ∴ B = [1, 2]
   A = (-2, 1]
   A ∩ B = {1}

(2) A ∪ B = (-2, 2]

(3) ∁ᵤA = (-∞, -2] ∪ (1, +∞)

---

### 例题2：集合相等求参数

**题目**：已知集合{2x, x+y} = {4, 8}，求x和y的值

**解析**：
由集合相等，元素相同（不考虑顺序）

情况1：2x = 4 且 x+y = 8
- x = 2，y = 6

情况2：2x = 8 且 x+y = 4
- x = 4，y = 0

验证：两种情况都满足集合相等
∴ {x=2, y=6} 或 {x=4, y=0}

---

### 例题3：子集关系求参数范围

**题目**：已知集合A = {x | x² - 3x + 2 = 0}，B = {x | x² - ax + a - 1 = 0}，且B ⊆ A，求实数a的值

**解析**：
A = {1, 2}（解方程x² - 3x + 2 = 0）

B中方程：x² - ax + a - 1 = 0
判别式Δ = a² - 4(a-1) = (a-2)² ≥ 0

B ⊆ A，则B可能为：∅，{1}，{2}，{1, 2}

由于Δ ≥ 0，B ≠ ∅

若B = {1}：则1是重根，Δ = 0，a = 2
   验证：x² - 2x + 1 = 0，x = 1 ✓

若B = {2}：则2是重根，Δ = 0，a = 2
   但此时x = 1，不是{2}，矛盾

若B = {1, 2}：由韦达定理，1+2 = a，1×2 = a-1
   ∴ a = 3，且a-1 = 2，即a = 3 ✓

综上，a = 2 或 a = 3

---

### 例题4：条件关系的判定

**题目**：判断下列各组中α是β的什么条件：
(1) α：x = 1；β：x² = 1
(2) α：x > 1；β：x² > 1
(3) α：a > b；β：ac² > bc²

**解析**：
(1) α ⇒ β：x = 1 ⇒ x² = 1 ✓
   β ⇒ α：x² = 1 ⇒ x = ±1，不一定x = 1 ✗
   ∴ α是β的充分不必要条件

(2) α ⇒ β：x > 1 ⇒ x² > 1 ✓
   β ⇒ α：x² > 1 ⇒ x > 1 或 x < -1，不一定x > 1 ✗
   ∴ α是β的充分不必要条件

(3) α ⇒ β：当c = 0时，ac² = bc² = 0，不满足ac² > bc² ✗
   β ⇒ α：ac² > bc² ⇒ c² > 0（即c ≠ 0），则a > b ✓
   ∴ α是β的必要不充分条件

---

### 例题5：充要条件的证明

**题目**：已知m是实数，M = {2, 3, m+6}，N = {0, 7}
证明："m = 1"是"M ∩ N = {7}"的充要条件

**解析**：
**充分性**（m = 1 ⇒ M ∩ N = {7}）：
当m = 1时，M = {2, 3, 7}
M ∩ N = {2, 3, 7} ∩ {0, 7} = {7} ✓

**必要性**（M ∩ N = {7} ⇒ m = 1）：
若M ∩ N = {7}，则7 ∈ M
∴ m + 6 = 7，即m = 1

综上，"m = 1"是"M ∩ N = {7}"的充要条件

---

### 例题6：反证法证明

**题目**：设n∈Z，证明：若n²是偶数，则n是偶数

**解析**：
**证明**：假设结论不成立，即假设n是奇数

设n = 2k + 1，其中k∈Z

则n² = (2k+1)² = 4k² + 4k + 1 = 4(k² + k) + 1

∴ n²是奇数，与已知条件"n²是偶数"矛盾

∴ 假设不成立，即n是偶数

---

### 例题7：德摩根定律应用

**题目**：设全集U = {a, b, c, d, e}，A = {a, b, c}，B = {c, d}
求：(1) ∁ᵤ(A ∪ B)；(2) ∁ᵤA ∩ ∁ᵤB；(3) ∁ᵤ(A ∩ B)；(4) ∁ᵤA ∪ ∁ᵤB

**解析**：
A ∪ B = {a, b, c, d}，A ∩ B = {c}
∁ᵤA = {d, e}，∁ᵤB = {a, b, e}

(1) ∁ᵤ(A ∪ B) = {e}
(2) ∁ᵤA ∩ ∁ᵤB = {d, e} ∩ {a, b, e} = {e}
(3) ∁ᵤ(A ∩ B) = {a, b, d, e}
(4) ∁ᵤA ∪ ∁ᵤB = {d, e} ∪ {a, b, e} = {a, b, d, e}

**结论**：验证了德摩根定律：
∁ᵤ(A ∪ B) = ∁ᵤA ∩ ∁ᵤB
∁ᵤ(A ∩ B) = ∁ᵤA ∪ ∁ᵤB

## 6. 易错点

| 陷阱 | 错误示例 | 正确理解 |
|------|----------|----------|
| **忽略空集** | 求子集时漏掉∅ | 空集是任何集合的子集 |
| **元素互异性** | {a, a²} = {4, 16}直接得a=4 | 需验证a²≠a，即a≠0,1 |
| **描述法理解错误** | {(x,y) | y=x}与{x | y=x}混淆 | 前者是点集（直线），后者是数集（实数集） |
| **区间端点开闭** | {x | -2 < x ≤ 1}写成[-2,1] | 应为(-2, 1] |
| **补集全集不明确** | 求补集时未指明全集 | 必须明确全集U |
| **条件关系方向** | 把"A是B的充分条件"理解为B⇒A | α是β的充分条件 ⇔ α⇒β |
| **反证法否定错误** | "x>1或y>1"的否定写成"x≤1或y≤1" | 应为"x≤1且y≤1" |
| **集合运算符号混淆** | ∩与∪写反 | ∩是交集（公共部分），∪是并集（全部） |
| **忽略分母为零** | 解方程时未检验分母 | 解分式方程必须验根 |
| **无限集列举** | {1, 2, 3, ...}表示所有自然数 | 注意省略号的使用前提 |
