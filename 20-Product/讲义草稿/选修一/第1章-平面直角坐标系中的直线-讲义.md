# 第1章 平面直角坐标系中的直线 - 讲义

---

## 一、本章解决什么问题

本章是解析几何的入门章节，主要解决以下核心问题：

1. **如何用代数方法描述直线的位置**：通过建立坐标系，将几何问题转化为代数问题
2. **如何确定直线的方向**：引入倾斜角和斜率的概念
3. **如何表示直线的方程**：掌握各种形式的直线方程
4. **如何判断直线间的位置关系**：相交、平行、重合、垂直
5. **如何计算距离**：点到直线的距离、平行线之间的距离

**核心思想**：解析几何的基本思想是通过引进坐标系，建立"点"与"数"之间的一一对应，从而用代数的观点与方法解决几何问题。

## 三、核心知识点详解

### 3.1 直线的倾斜角与斜率

#### 3.1.1 倾斜角
- **定义**：将x轴绕直线与x轴的交点沿逆时针方向旋转到与直线重合时所转过的最小正角θ
- **取值范围**：$\theta \in [0, \pi)$
- **特殊情况**：
  - 当直线与x轴平行或重合时，$\theta = 0$
  - 当直线与x轴垂直时，$\theta = \frac{\pi}{2}$

#### 3.1.2 斜率
- **定义**：当$\theta \neq \frac{\pi}{2}$时，$k = \tan\theta$
- **斜率公式**：过两点$A(x_1, y_1)$、$B(x_2, y_2)$（$x_1 \neq x_2$）的直线斜率为
$$k = \frac{y_2 - y_1}{x_2 - x_1}$$
- **注意**：垂直于x轴的直线斜率不存在

**斜率与倾斜角的关系**：
| 倾斜角θ | 斜率k |
|---------|-------|
| $0$ | $0$ |
| $(0, \frac{\pi}{2})$ | $(0, +\infty)$ |
| $\frac{\pi}{2}$ | 不存在 |
| $(\frac{\pi}{2}, \pi)$ | $(-\infty, 0)$ |

---

### 3.2 直线的方程

#### 3.2.1 点斜式方程
**条件**：已知直线过点$M(x_0, y_0)$，斜率为$k$

**方程**：$y - y_0 = k(x - x_0)$

**适用范围**：斜率存在的直线

#### 3.2.2 斜截式方程
**条件**：已知斜率$k$，y轴截距$b$

**方程**：$y = kx + b$

**说明**：
- 一次函数$y = kx + b$（$k \neq 0$）的图像就是直线
- 当$k = 0$时，直线与x轴平行，方程为$y = b$

#### 3.2.3 两点式方程
**条件**：已知直线过两点$M(x_1, y_1)$、$N(x_2, y_2)$（$x_1 \neq x_2$且$y_1 \neq y_2$）

**方程**：$\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1}$

**等价形式**：$(x_2 - x_1)(y - y_1) = (y_2 - y_1)(x - x_1)$（适用于所有情况）

#### 3.2.4 截距式方程
**条件**：x轴截距$a$，y轴截距$b$（$a \neq 0, b \neq 0$）

**方程**：$\frac{x}{a} + \frac{y}{b} = 1$

#### 3.2.5 点法式方程
**条件**：已知直线过点$M(x_0, y_0)$，法向量$\vec{n} = (a, b)$

**方程**：$a(x - x_0) + b(y - y_0) = 0$

**说明**：法向量是与直线上任意向量都垂直的非零向量

#### 3.2.6 一般式方程
**方程**：$ax + by + c = 0$（$a$、$b$不同时为零）

**性质**：
- 法向量$\vec{n} = (a, b)$
- 当$b \neq 0$时，斜率$k = -\frac{a}{b}$
- 当$b = 0$时，直线垂直于x轴

---

### 3.3 两条直线的位置关系

设直线$l_1: a_1x + b_1y + c_1 = 0$，$l_2: a_2x + b_2y + c_2 = 0$

#### 3.3.1 相交、平行与重合

| 位置关系 | 代数条件 | 系数关系（$a_2, b_2, c_2 \neq 0$） |
|---------|---------|----------------------------------|
| **重合** | 存在$\lambda$，使$a_1=\lambda a_2, b_1=\lambda b_2, c_1=\lambda c_2$ | $\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$ |
| **平行** | 存在$\lambda$，使$a_1=\lambda a_2, b_1=\lambda b_2, c_1 \neq \lambda c_2$ | $\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$ |
| **相交** | $a_1b_2 \neq a_2b_1$ | $\frac{a_1}{a_2} \neq \frac{b_1}{b_2}$ |

**交点坐标**：解方程组$\begin{cases} a_1x + b_1y + c_1 = 0 \\ a_2x + b_2y + c_2 = 0 \end{cases}$

$$x = \frac{c_2b_1 - c_1b_2}{a_1b_2 - a_2b_1}, \quad y = \frac{c_1a_2 - c_2a_1}{a_1b_2 - a_2b_1}$$

#### 3.3.2 垂直

**充要条件**：$l_1 \perp l_2 \Leftrightarrow a_1a_2 + b_1b_2 = 0$

**斜率形式**（斜率都存在时）：$k_1 \cdot k_2 = -1$

#### 3.3.3 夹角

**定义**：两条相交直线所成的锐角或直角

**余弦公式**：$$\cos\alpha = \frac{|a_1a_2 + b_1b_2|}{\sqrt{a_1^2 + b_1^2} \cdot \sqrt{a_2^2 + b_2^2}}$$

**斜率形式**（斜率都存在时）：$$\tan\alpha = \left|\frac{k_1 - k_2}{1 + k_1k_2}\right|$$

---

### 3.4 点到直线的距离

#### 3.4.1 点到直线的距离公式
点$P(x_0, y_0)$到直线$ax + by + c = 0$的距离：

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

#### 3.4.2 平行线间的距离
两条平行线$l_1: ax + by + c_1 = 0$与$l_2: ax + by + c_2 = 0$之间的距离：

$$d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$$

## 四、典型例题精讲

### 例题1：求直线的斜率和倾斜角

**题目**：求经过点$P(-2, 2)$和$Q(2, -2)$的直线的斜率和倾斜角。

**解答**：
斜率$k = \frac{-2 - 2}{2 - (-2)} = \frac{-4}{4} = -1$

由$\tan\theta = -1$且$\theta \in [0, \pi)$，得$\theta = \frac{3\pi}{4}$

**答案**：斜率为$-1$，倾斜角为$\frac{3\pi}{4}$

---

### 例题2：直线方程的求法

**题目**：求倾斜角是$\frac{2\pi}{3}$且在x轴上的截距为$-3$的直线$l$的点斜式方程。

**解答**：
斜率$k = \tan\frac{2\pi}{3} = -\sqrt{3}$

x轴截距为$-3$，说明直线过点$(-3, 0)$

点斜式方程：$y - 0 = -\sqrt{3}(x + 3)$

即$y = -\sqrt{3}(x + 3)$

---

### 例题3：三点共线问题

**题目**：已知三点$A(-1, 2)$、$B(3, 4)$、$C(x, y)$共线，求点$C$的坐标满足的关系式。

**解答**：
直线$AB$的斜率$k_{AB} = \frac{4 - 2}{3 - (-1)} = \frac{1}{2}$

因为$A$、$B$、$C$共线，所以$k_{AC} = k_{AB}$

$$\frac{y - 2}{x + 1} = \frac{1}{2}$$

整理得：$y - 2 = \frac{1}{2}(x + 1)$

或写成一般式：$x - 2y + 5 = 0$

---

### 例题4：两条直线的位置关系

**题目**：判断直线$l_1: 0.5x - y + 1 = 0$与$l_2: 3x - 6y + 8 = 0$的位置关系。

**解答**：
将$l_1$化为：$x - 2y + 2 = 0$

比较系数：$\frac{1}{3} = \frac{-2}{-6} = \frac{1}{3} \neq \frac{2}{8} = \frac{1}{4}$

因为$\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$

所以$l_1 \parallel l_2$（两直线平行）

---

### 例题5：垂直直线的方程

**题目**：求经过点$(4, 5)$且与直线$l: y = -\frac{1}{3}x + 2$垂直的直线$l'$的方程。

**解答**：
直线$l$的斜率$k = -\frac{1}{3}$

因为$l \perp l'$，所以$k_{l'} = 3$（负倒数）

点斜式：$y - 5 = 3(x - 4)$

整理得：$3x - y - 7 = 0$

---

### 例题6：求两条直线的夹角

**题目**：求直线$l_1: x + 3y - 1 = 0$与$l_2: y = 2x + 7$的夹角大小。

**解答**：
$l_2$化为一般式：$2x - y + 7 = 0$

使用夹角余弦公式：
$$\cos\alpha = \frac{|1 \times 2 + 3 \times (-1)|}{\sqrt{1 + 9} \cdot \sqrt{4 + 1}} = \frac{|2 - 3|}{\sqrt{10} \cdot \sqrt{5}} = \frac{1}{\sqrt{50}} = \frac{\sqrt{2}}{10}$$

所以$\alpha = \arccos\frac{\sqrt{2}}{10}$

---

### 例题7：点到直线的距离

**题目**：求点$P(1, 2)$到直线$l: x + 2y + 5 = 0$的距离。

**解答**：
$$d = \frac{|1 \times 1 + 2 \times 2 + 5|}{\sqrt{1^2 + 2^2}} = \frac{|1 + 4 + 5|}{\sqrt{5}} = \frac{10}{\sqrt{5}} = 2\sqrt{5}$$

---

### 例题8：平行线间的距离

**题目**：求平行直线$l_1: \sqrt{2}x + y + 1 = 0$与$l_2: \sqrt{2}x + y + 4 = 0$之间的距离。

**解答**：
$$d = \frac{|1 - 4|}{\sqrt{(\sqrt{2})^2 + 1^2}} = \frac{3}{\sqrt{3}} = \sqrt{3}$$

## 五、方法技巧总结

### 5.1 求直线方程的常用策略

| 已知条件 | 选用方程形式 |
|---------|-------------|
| 一点和斜率 | 点斜式 |
| 斜率和y截距 | 斜截式 |
| 两点 | 两点式或点斜式 |
| 两截距 | 截距式 |
| 一点和法向量 | 点法式 |
| 一般情况 | 一般式 |

### 5.2 判断位置关系的关键

1. **化为同一形式**：通常化为一般式$ax + by + c = 0$便于比较
2. **注意特殊情况**：垂直于坐标轴的直线斜率不存在
3. **验证结果**：求出结果后回代验证

### 5.3 距离问题的技巧

1. **点到直线距离**：
   - 确保直线方程为一般式$ax + by + c = 0$
   - 分子代入点坐标后取绝对值

2. **平行线间距离**：
   - 确保$x$、$y$系数完全相同
   - 公式中只需常数项之差的绝对值

### 5.4 含参数问题的处理

1. **分类讨论**：注意斜率是否存在
2. **定点问题**：将方程整理为参数的一次式，令系数为零求定点
3. **范围问题**：利用斜率与倾斜角的关系，或利用判别式

## 六、易错点警示

### 6.1 倾斜角与斜率的易错点

❌ **错误**：认为所有直线都有斜率
✅ **正确**：垂直于x轴的直线（$\theta = \frac{\pi}{2}$）斜率不存在

❌ **错误**：斜率为负时，倾斜角为负角
✅ **正确**：倾斜角范围是$[0, \pi)$，斜率为负时$\theta \in (\frac{\pi}{2}, \pi)$

### 6.2 直线方程的易错点

❌ **错误**：截距式方程$\frac{x}{a} + \frac{y}{b} = 1$可以表示所有直线
✅ **正确**：截距式要求$a \neq 0$且$b \neq 0$，过原点和垂直于坐标轴的直线不能用截距式

❌ **错误**：认为$y = kx + b$可以表示所有直线
✅ **正确**：垂直于x轴的直线（$x = a$）不能用斜截式表示

### 6.3 位置关系的易错点

❌ **错误**：两直线斜率相等就一定平行
✅ **正确**：斜率相等可能平行也可能重合，需检验截距

❌ **错误**：$k_1 \cdot k_2 = -1$是垂直的充要条件
✅ **正确**：$k_1 \cdot k_2 = -1$仅在两斜率都存在时成立，一条水平一条垂直时也垂直

### 6.4 距离公式的易错点

❌ **错误**：使用距离公式时忘记绝对值
✅ **正确**：距离非负，分子必须取绝对值

❌ **错误**：平行线间距离公式中，$x$、$y$系数不同直接使用
✅ **正确**：必须先将两直线$x$、$y$系数化为相同

| 点到直线距离 | $d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$ |
| 平行线间距离 | $d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$ |
