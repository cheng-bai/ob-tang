## 三、核心知识

### 4.1 幂函数

#### 1. 定义
当指数a固定时，等式 **y = x^a** 确定了变量y随变量x变化的规律，称为指数为a的幂函数。

#### 2. 定义域
幂函数的定义域与指数a有关：
- 当a为正整数时，定义域为 **R**
- 当a = 1/2时，y = x^(1/2) = √x，定义域为 **[0, +∞)**
- 当a = -2/3时，y = x^(-2/3) = 1/∛(x²)，定义域为 **(-∞, 0) ∪ (0, +∞)**

#### 3. 单调性
- 当 **a > 0** 时，幂函数在区间 **(0, +∞)** 上是**严格增函数**
- 当 **a < 0** 时，幂函数在区间 **(0, +∞)** 上是**严格减函数**

#### 4. 定点
无论a取何值（只要定义域包含1），幂函数的图像都经过点 **(1, 1)**。

#### 5. 对称性
- y = x³ 的图像关于**原点**成中心对称（奇函数）
- y = x^(-2/3) 的图像关于**y轴**成轴对称（偶函数）

---

### 4.2 指数函数

#### 1. 定义
当底数a固定，且 **a > 0, a ≠ 1** 时，等式 **y = a^x** 称为底为a的指数函数。

#### 2. 定义域
指数函数的定义域为 **R**（全体实数）。

#### 3. 图像与性质

| 性质 | a > 1 | 0 < a < 1 |
|------|-------|-----------|
| 图像趋势 | 由左至右上升 | 由左至右下降 |
| 单调性 | 严格增函数 | 严格减函数 |
| 函数值 | 当x > 0时，y > 1；当x < 0时，0 < y < 1 | 当x > 0时，0 < y < 1；当x < 0时，y > 1 |

#### 4. 重要性质
- 函数值恒大于0，图像在x轴上方
- 图像都经过定点 **(0, 1)**
- y = a^x 与 y = (a⁻¹)^x 的图像关于**y轴**对称

#### 5. 指数增长
当a > 1时，a^x随着x的增长而增长，且增长得越来越快，称为"**指数增长**"。

---

### 4.3 对数函数

#### 1. 定义
当底数a固定，且 **a > 0, a ≠ 1** 时，等式 **y = log_a x** 称为底为a的对数函数。

#### 2. 定义域
对数函数的定义域为 **(0, +∞)**（全体正实数）。

#### 3. 图像与性质

| 性质 | a > 1 | 0 < a < 1 |
|------|-------|-----------|
| 图像趋势 | 由左至右上升 | 由左至右下降 |
| 单调性 | 严格增函数 | 严格减函数 |
| 函数值 | 当x > 1时，y > 0；当0 < x < 1时，y < 0 | 当x > 1时，y < 0；当0 < x < 1时，y > 0 |

#### 4. 重要性质
- 图像都在y轴右侧，无限趋近于y轴但永不相交
- 图像都经过定点 **(1, 0)**
- y = log_a x 与 y = log_(a⁻¹) x 的图像关于**x轴**对称

#### 5. 与指数函数的关系
- 对数函数 **y = log_a x** 是指数函数 **y = a^x** 的**反函数**
- 它们的图像关于直线 **y = x** 对称

#### 6. 换底公式
**log_b x = (log_a x)/(log_a b)** = (1/log_a b) · log_a x

## 四、例题精讲

### 题型一：求函数定义域

**例1** 求下列函数的定义域：
(1) y = x^(1/3)  
(2) y = x^(-1/2)  
(3) y = log₂(x - 1)

**解：**
(1) y = x^(1/3) = ∛x，对一切实数x都有意义，定义域为 **R**。

(2) y = x^(-1/2) = 1/√x，当x > 0时才有意义，定义域为 **(0, +∞)**。

(3) 对数函数要求真数大于0，即x - 1 > 0，所以x > 1，定义域为 **(1, +∞)**。

---

### 题型二：比较大小

**例2** 比较下列各题中两个数的大小：
(1) 2.5^(-2) 与 1.8^(-2)  
(2) 1.7^(2.5) 与 1.7³  
(3) log₂5 与 log₂6

**解：**
(1) 考虑幂函数y = x^(-2)，指数-2 < 0，在(0, +∞)上是严格减函数。  
因为2.5 > 1.8，所以 **2.5^(-2) < 1.8^(-2)**。

(2) 考虑指数函数y = 1.7^x，底数1.7 > 1，在R上是严格增函数。  
因为2.5 < 3，所以 **1.7^(2.5) < 1.7³**。

(3) 考虑对数函数y = log₂x，底数2 > 1，在(0, +∞)上是严格增函数。  
因为5 < 6，所以 **log₂5 < log₂6**。

---

### 题型三：解不等式

**例3** 求下列不等式的解集：
(1) 3^x > 1/27  
(2) log_(1/2)(x - 1) > -2

**解：**
(1) 将1/27写成3^(-3)，因为y = 3^x是严格增函数，  
所以x > -3，解集为 **(-3, +∞)**。

(2) 首先x - 1 > 0，即x > 1。  
将-2写成log_(1/2) 4，因为底数1/2 ∈ (0,1)，对数函数是严格减函数，  
所以x - 1 < 4，即x < 5。  
结合x > 1，解集为 **(1, 5)**。

---

### 题型四：函数图像与性质综合

**例4** 已知指数函数y = a^x (a > 1)在区间[1, 2]上的最大值比最小值大a/3，求实数a的值。

**解：**
当a > 1时，y = a^x在[1, 2]上是严格增函数。  
最大值在x = 2处取得，为a²；  
最小值在x = 1处取得，为a。  

由题意：a² - a = a/3  
a² - (4/3)a = 0  
a(a - 4/3) = 0

因为a > 1，所以 **a = 4/3**。

## 五、方法总结

### 1. 比较大小的一般方法

| 函数类型 | 比较方法 |
|---------|---------|
| 幂函数y = x^a | 看指数a：a > 0时，底数大则值大；a < 0时，底数大则值小 |
| 指数函数y = a^x | 看底数a：a > 1时，指数大则值大；0 < a < 1时，指数大则值小 |
| 对数函数y = log_a x | 看底数a：a > 1时，真数大则值大；0 < a < 1时，真数大则值小 |

### 2. 解指数、对数不等式的步骤
1. **统一底数**：将不等式两边化为同底数的幂或对数
2. **利用单调性**：根据底数大小判断函数单调性
3. **去底数**：利用单调性去掉底数，转化为普通不等式
4. **求解**：解转化后的不等式
5. **检验**：对数不等式需检验真数大于0

### 3. 定点问题
- 指数函数y = a^x恒过定点 **(0, 1)**
- 对数函数y = log_a x恒过定点 **(1, 0)**
- 函数y = a^(x-h) + k恒过定点 **(h, 1 + k)**
- 函数y = log_a(x - h) + k恒过定点 **(1 + h, k)**

## 六、易错提醒

### 1. 定义域问题
- 幂函数y = x^a的定义域与a的取值有关，不一定是R
- 指数函数y = a^x的定义域总是R
- 对数函数y = log_a x的定义域总是(0, +∞)，真数必须大于0

### 2. 单调性判断
- 指数函数和对数函数的单调性都与底数a有关：
  - a > 1时，都是增函数
  - 0 < a < 1时，都是减函数
- 注意：当0 < a < 1时，解不等式要**改变不等号方向**

### 3. 比较大小的常见错误
- 不同底的指数或对数比较，可利用换底公式或中间量（如0、1）
- 注意负数的情况：比较(-√2)^(4/5)和1.32^(4/5)时，先化为正数

### 4. 图像特征
- 指数函数y = a^x的图像永远在x轴上方
- 对数函数y = log_a x的图像永远在y轴右侧
- y = a^x与y = (1/a)^x的图像关于y轴对称
- y = log_a x与y = log_(1/a) x的图像关于x轴对称

## 附录：本章公式汇总

### 幂函数
- 定义：y = x^a（a为常数）
- 单调性：a > 0时在(0, +∞)上递增；a < 0时在(0, +∞)上递减

### 指数函数
- 定义：y = a^x（a > 0且a ≠ 1）
- 定义域：R
- 值域：(0, +∞)
- 定点：(0, 1)
- 单调性：a > 1时递增；0 < a < 1时递减

### 对数函数
- 定义：y = log_a x（a > 0且a ≠ 1）
- 定义域：(0, +∞)
- 值域：R
- 定点：(1, 0)
- 单调性：a > 1时递增；0 < a < 1时递减
- 换底公式：log_b x = (log_a x)/(log_a b)

### 反函数关系
- y = a^x 与 y = log_a x 互为反函数
- 图像关于直线y = x对称
