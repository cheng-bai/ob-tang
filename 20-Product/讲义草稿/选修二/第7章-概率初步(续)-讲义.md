# 第7章 概率初步(续) 讲义

## 一、本章解决什么问题

本章作为概率初步（必修课程第12章）的续篇，重点解决以下问题：

1. **条件概率问题**：如何在已知某些信息（条件）的情况下，计算事件发生的概率
2. **复杂概率计算**：利用全概率公式和贝叶斯公式解决多阶段、多条件下的概率问题
3. **随机变量的刻画**：如何用数学工具描述随机现象的数量特征
4. **随机变量的数字特征**：如何计算随机变量的期望（均值）和方差（离散程度）
5. **常见概率模型**：掌握二项分布、超几何分布、正态分布等重要的概率分布模型

**核心思想**：从定性分析到定量刻画，从单一事件到随机变量，从离散分布到连续分布。

## 三、核心知识点详解

### 3.1 条件概率

**定义**：在事件A发生的条件下，事件B发生的概率称为条件概率，记作P(B|A)。

**计算公式**：
$$P(B|A) = \frac{P(A \cap B)}{P(A)} \quad (P(A) > 0)$$

**古典概型中的计算**：
$$P(B|A) = \frac{|A \cap B|}{|A|}$$

**关键理解**：
- 条件概率是在缩减的样本空间A上计算概率
- 事件A发生后，样本空间从Ω变为A
- 条件概率满足概率的所有性质

**与独立性的关系**：
- 若A、B独立，则P(B|A) = P(B)
- 若P(B|A) = P(B)，则A、B独立

---

### 3.2 乘法公式

**公式**：
$$P(A \cap B) = P(A) \cdot P(B|A)$$

**推广到n个事件**：
$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \cdot P(A_2|A_1) \cdot P(A_3|A_1 \cap A_2) \cdots P(A_n|A_1 \cap \cdots \cap A_{n-1})$$

**应用场景**：计算多个事件同时发生的概率，特别是有先后顺序的随机试验。

---

### 3.3 全概率公式

**背景**：当事件A的发生可能由多种原因（或经过多个途径）引起时，计算P(A)需要综合考虑各种情况。

**公式**：设Ω₁, Ω₂, ..., Ωₙ构成样本空间的一个划分（互斥且穷尽），则：
$$P(A) = \sum_{k=1}^{n} P(A|\Omega_k) \cdot P(\Omega_k)$$

**直观理解**：P(A)是各条件下条件概率的加权平均，权重为各条件发生的概率。

**典型应用**：
- 多来源产品的合格率计算
- 多路径问题的概率计算
- 抽签公平性证明

---

### 3.4 贝叶斯公式（选学）

**公式**：
$$P(\Omega_i|A) = \frac{P(A|\Omega_i) \cdot P(\Omega_i)}{\sum_{k=1}^{n} P(A|\Omega_k) \cdot P(\Omega_k)}$$

**意义**：
- **先验概率**P(Ωᵢ)：在观察到事件A之前，对Ωᵢ发生概率的判断
- **后验概率**P(Ωᵢ|A)：在观察到事件A发生后，对Ωᵢ发生概率的修正

**应用**：医学检测准确率评估、机器学习中的概率更新。

---

### 3.5 随机变量及其分布

**定义**：以样本空间为定义域的函数X称为随机变量。

**分布列**：离散型随机变量X的分布用下表表示：

| X | x₁ | x₂ | ... | xₙ |
|---|----|----|-----|----|
| P | p₁ | p₂ | ... | pₙ |

其中p₁ + p₂ + ... + pₙ = 1

**常见离散分布**：

| 分布名称 | 定义 | 分布列 |
|---------|------|--------|
| 伯努利分布 | 只取0,1两个值的随机变量 | P(X=1)=p, P(X=0)=1-p |
| 均匀分布 | 所有取值概率相等 | P(X=xᵢ)=1/n |

---

### 3.6 期望（数学期望）

**定义**：
$$E[X] = x_1p_1 + x_2p_2 + \cdots + x_np_n = \sum_{i=1}^{n} x_ip_i$$

**意义**：随机变量取值的加权平均，权重为相应概率；反映随机变量的"中心位置"。

**线性性质**：
1. E[aX] = aE[X]（齐次性）
2. E[X + Y] = E[X] + E[Y]（可加性）

**应用**：利用线性性质简化复杂随机变量的期望计算。

---

### 3.7 方差

**定义**：
$$D[X] = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

**意义**：衡量随机变量取值相对于期望的离散程度。

**计算公式**：
$$D[X] = \sum_{i=1}^{n} x_i^2p_i - (E[X])^2$$

**性质**：
1. D[aX] = a²D[X]
2. 若X、Y独立，则D[X + Y] = D[X] + D[Y]

**标准差**：σ = √D[X]，与期望同量纲。

---

### 3.8 二项分布 B(n,p)

**背景**：n次独立重复的伯努利试验中成功的次数。

**概率质量函数**：
$$P(X = k) = C_n^k \cdot p^k \cdot (1-p)^{n-k}, \quad k = 0, 1, 2, ..., n$$

**数字特征**：
- 期望：E[X] = np
- 方差：D[X] = np(1-p)

**与二项式定理的关系**：
$$\sum_{k=0}^{n} C_n^k p^k q^{n-k} = (p+q)^n = 1$$

---

### 3.9 超几何分布

**背景**：从含有a个白球、b个黑球的袋中不放回地取n个球，其中白球数X的分布。

**概率质量函数**：
$$P(X = k) = \frac{C_a^k \cdot C_b^{n-k}}{C_{a+b}^n}$$

其中k满足：max(0, n-b) ≤ k ≤ min(n, a)

**数字特征**：
- 期望：E[X] = n · a/(a+b)
- （与二项分布期望形式相同）

**与二项分布的关系**：
- 当总体数量a+b远大于抽取数量n时，超几何分布近似于二项分布
- 放回抽样→二项分布；不放回抽样→超几何分布

---

### 3.10 正态分布 N(μ, σ²)

**密度函数**：
$$\varphi_{\mu,\sigma^2}(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

**参数意义**：
- μ：期望（位置参数，决定分布中心）
- σ²：方差（形状参数，决定分布分散程度）
- σ越小，曲线越"高瘦"；σ越大，曲线越"矮胖"

**3σ原则**：
- P(|X-μ| < σ) ≈ 68.3%
- P(|X-μ| < 2σ) ≈ 95.4%
- P(|X-μ| < 3σ) ≈ 99.7%

**标准正态分布**：
- N(0, 1)，密度函数记为φ(x)
- 分布函数记为Φ(x)
- 性质：Φ(-x) = 1 - Φ(x)

**标准化变换**：
若X ~ N(μ, σ²)，则Z = (X-μ)/σ ~ N(0, 1)

## 四、典型例题精讲

### 例题1：条件概率的计算

**题目**：掷一颗骰子并观察出现的点数。已知出现的点数不超过3，求出现的点数是奇数的概率。

**解析**：
设事件A表示"出现的点数不超过3"，事件B表示"出现的点数是奇数"。

样本空间Ω = {1, 2, 3, 4, 5, 6}

A = {1, 2, 3}，B = {1, 3, 5}

A ∩ B = {1, 3}

**解法一（定义法）**：
$$P(B|A) = \frac{P(A \cap B)}{P(A)} = \frac{\frac{2}{6}}{\frac{3}{6}} = \frac{2}{3}$$

**解法二（缩减样本空间法）**：
在A发生的条件下，样本空间缩减为{1, 2, 3}，其中奇数有{1, 3}两个，故：
$$P(B|A) = \frac{2}{3}$$

**答案**：2/3

---

### 例题2：乘法公式的应用

**题目**：一个罐子中有大小与质地相同的黑、白、红三个球，不放回地摸球。求：
(1) 在第一次没有摸到黑球的条件下，第二次也没有摸到黑球的概率；
(2) 两次都没有摸到黑球的概率。

**解析**：
用A、B分别表示第一次、第二次没有摸到黑球的事件。

**(1) 条件概率**：
A发生后，罐子中还有两个球（白、红），其中没有黑球，所以：
$$P(B|A) = \frac{2}{2} = 1$$

等等，重新分析：罐子中有黑、白、红三个球，第一次没摸到黑球，说明摸到的是白球或红球，剩下两个球中有一个是黑球。

所以：
$$P(B|A) = \frac{1}{2}$$

**(2) 两次都没摸到黑球的概率**：
$$P(A \cap B) = P(A) \cdot P(B|A) = \frac{2}{3} \times \frac{1}{2} = \frac{1}{3}$$

**答案**：(1) 1/2；(2) 1/3

---

### 例题3：全概率公式的应用

**题目**：公司库房中的某个零件的70%来自A公司，30%来自B公司，两个公司的正品率分别是95%和90%。从库房中任取一个零件，求它是正品的概率。

**解析**：
设事件Ω₁表示"零件来自A公司"，Ω₂表示"零件来自B公司"，A表示"零件是正品"。

已知：
- P(Ω₁) = 0.7，P(Ω₂) = 0.3
- P(A|Ω₁) = 0.95，P(A|Ω₂) = 0.90

由全概率公式：
$$P(A) = P(A|\Omega_1)P(\Omega_1) + P(A|\Omega_2)P(\Omega_2)$$
$$= 0.95 \times 0.7 + 0.90 \times 0.3$$
$$= 0.665 + 0.27 = 0.935$$

**答案**：93.5%

---

### 例题4：随机变量的分布与期望

**题目**：抛掷n枚硬币，用X表示正面朝上的硬币数。求X的分布及期望。

**解析**：
**分布**：
这是n次独立重复的伯努利试验，X ~ B(n, 1/2)。

$$P(X = k) = C_n^k \cdot \left(\frac{1}{2}\right)^k \cdot \left(\frac{1}{2}\right)^{n-k} = \frac{C_n^k}{2^n}$$

其中k = 0, 1, 2, ..., n。

**期望计算（两种方法）**：

**方法一：利用二项分布期望公式**
$$E[X] = np = n \times \frac{1}{2} = \frac{n}{2}$$

**方法二：利用期望线性性质**
设Xₖ表示第k枚硬币的结果（正面为1，反面为0），则：
$$X = X_1 + X_2 + \cdots + X_n$$

每个Xₖ的分布为：
$$P(X_k = 1) = \frac{1}{2}, \quad P(X_k = 0) = \frac{1}{2}$$

所以：
$$E[X_k] = 1 \times \frac{1}{2} + 0 \times \frac{1}{2} = \frac{1}{2}$$

由期望线性性质：
$$E[X] = E[X_1] + E[X_2] + \cdots + E[X_n] = n \times \frac{1}{2} = \frac{n}{2}$$

**答案**：分布为二项分布B(n, 1/2)，期望为n/2。

---

### 例题5：方差的计算

**题目**：掷一颗骰子，用X表示掷得的点数。求X的方差。

**解析**：
**第一步：求期望**
$$E[X] = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = 3.5$$

**第二步：求E[X²]**
$$E[X^2] = \frac{1^2+2^2+3^2+4^2+5^2+6^2}{6} = \frac{91}{6}$$

**第三步：求方差**
$$D[X] = E[X^2] - (E[X])^2 = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{91}{6} - \frac{49}{4}$$

通分计算：
$$= \frac{182}{12} - \frac{147}{12} = \frac{35}{12}$$

**答案**：D[X] = 35/12

### 例题6：二项分布的综合应用

**题目**：一批产品的二等品率为0.3。从这批产品中每次随机抽取一件，并有放回地抽取20次。用X表示抽到二等品的件数，求D[X]。

**解析**：
**识别分布**：
有放回抽取，每次抽到二等品的概率p=0.3不变，n=20次独立重复试验。

所以X ~ B(20, 0.3)

**计算方差**：
对于二项分布B(n, p)：
$$D[X] = np(1-p) = 20 \times 0.3 \times 0.7 = 20 \times 0.21 = 4.2$$

**答案**：D[X] = 4.2

### 例题7：超几何分布

**题目**：从放有6黑2白共8颗珠子的袋子中抓3颗珠子，分别求黑珠颗数X与白珠颗数Y的分布、期望与方差。

**解析**：
**分析**：
- 总体：8颗珠子（6黑2白）
- 抽取：3颗不放回
- X：黑珠颗数，服从超几何分布
- Y：白珠颗数，Y = 3 - X

**X的分布**：
$$P(X = k) = \frac{C_6^k \cdot C_2^{3-k}}{C_8^3}, \quad k = 1, 2, 3$$

（k最小为1，因为最多只能取2颗白珠）

具体计算：
- $P(X=1) = \frac{C_6^1 \cdot C_2^2}{C_8^3} = \frac{6 \times 1}{56} = \frac{6}{56} = \frac{3}{28}$
- $P(X=2) = \frac{C_6^2 \cdot C_2^1}{C_8^3} = \frac{15 \times 2}{56} = \frac{30}{56} = \frac{15}{28}$
- $P(X=3) = \frac{C_6^3 \cdot C_2^0}{C_8^3} = \frac{20 \times 1}{56} = \frac{20}{56} = \frac{5}{14}$

**X的期望**：
$$E[X] = n \cdot \frac{a}{a+b} = 3 \times \frac{6}{8} = \frac{18}{8} = \frac{9}{4} = 2.25$$

**Y的分布**：
Y = 3 - X，所以Y可取0, 1, 2
- $P(Y=0) = P(X=3) = \frac{5}{14}$
- $P(Y=1) = P(X=2) = \frac{15}{28}$
- $P(Y=2) = P(X=1) = \frac{3}{28}$

**Y的期望**：
$$E[Y] = 3 - E[X] = 3 - 2.25 = 0.75$$
或直接：
$$E[Y] = n \cdot \frac{b}{a+b} = 3 \times \frac{2}{8} = \frac{6}{8} = 0.75$$

**答案**：
- X的分布：P(X=1)=3/28, P(X=2)=15/28, P(X=3)=5/14；E[X]=9/4
- Y的分布：P(Y=0)=5/14, P(Y=1)=15/28, P(Y=2)=3/28；E[Y]=3/4

### 例题8：正态分布的3σ原则

**题目**：某校高中三年级1600名学生参加了区第一次高考模拟统一考试，已知数学考试成绩X服从正态分布N(100, σ²)（试卷满分为150分）。统计结果显示，数学考试成绩在80分到120分之间的人数约为总人数的3/4，则此次统考中成绩不低于120分的学生人数约为（ ）

A. 80  B. 100  C. 120  D. 200

**解析**：
**分析已知条件**：
- X ~ N(100, σ²)，即μ = 100
- P(80 < X < 120) = 3/4 = 0.75

**利用对称性**：
区间(80, 120)关于μ=100对称，所以：
$$P(80 < X < 100) = P(100 < X < 120) = \frac{3}{8}$$

**计算P(X ≥ 120)**：
由正态分布的对称性：
$$P(X \geq 120) = P(X \leq 80)$$

而：
$$P(X \leq 80) + P(80 < X < 120) + P(X \geq 120) = 1$$

$$2P(X \geq 120) + 0.75 = 1$$

$$P(X \geq 120) = \frac{1 - 0.75}{2} = \frac{0.25}{2} = 0.125$$

**计算人数**：
$$1600 \times 0.125 = 200$$

**答案**：D. 200

## 五、方法技巧总结

### 5.1 条件概率问题解题策略

1. **识别条件**：明确"已知什么"和"求什么"
2. **选择方法**：
   - 定义法：P(B|A) = P(A∩B)/P(A)
   - 缩减样本空间法：直接在缩减后的样本空间中计算
3. **注意区分**：
   - P(B|A)：A发生后B发生的概率
   - P(A∩B)：A和B同时发生的概率
   - P(A|B)：B发生后A发生的概率

### 5.2 全概率公式应用步骤

1. **找出划分**：确定样本空间的完备事件组Ω₁, Ω₂, ..., Ωₙ
2. **确定概率**：
   - 各划分事件的概率P(Ωₖ)
   - 各条件概率P(A|Ωₖ)
3. **代入公式**：$P(A) = \sum_{k=1}^{n} P(A|\Omega_k)P(\Omega_k)$

### 5.3 随机变量期望计算方法

| 方法 | 适用场景 | 公式 |
|------|---------|------|
| 定义法 | 已知分布列 | E[X] = Σxᵢpᵢ |
| 线性性质法 | 复杂随机变量可分解 | E[X+Y] = E[X]+E[Y] |
| 公式法 | 已知分布类型 | 如二项分布E[X]=np |

### 5.4 方差计算技巧

1. **公式选择**：
   - 定义式：D[X] = E[(X-E[X])²]
   - 计算式：D[X] = E[X²] - (E[X])²（推荐，通常更简便）

2. **常用结论**：
   - 二项分布：D[X] = np(1-p)
   - 若Y = aX + b，则D[Y] = a²D[X]

### 5.5 分布识别要点

| 特征 | 二项分布 | 超几何分布 | 正态分布 |
|------|---------|-----------|---------|
| 抽样方式 | 有放回 | 不放回 | 连续型 |
| 独立性 | 独立 | 不独立 | - |
| 总体大小 | 可视为无限 | 有限且较小 | - |
| 应用场景 | n次独立重复试验 | 有限总体不放回抽样 | 测量误差、自然现象 |

## 六、易错点警示

### 易错点1：混淆P(B|A)与P(A|B)

**错误**：认为P(B|A) = P(A|B)

**纠正**：
- P(B|A)：在A发生的条件下B发生的概率
- P(A|B)：在B发生的条件下A发生的概率
- 两者一般不相等，满足贝叶斯关系

**示例**：
- 患病条件下检测阳性的概率 ≠ 检测阳性条件下患病的概率

---

### 易错点2：混淆P(A∩B)与P(B|A)

**错误**：将"A、B同时发生的概率"与"A发生后B发生的概率"混淆

**纠正**：
- P(A∩B) = P(A)·P(B|A)
- P(B|A) = P(A∩B)/P(A)
- 当P(A)≠1时，两者数值不同

---

### 易错点3：全概率公式中划分不完整

**错误**：遗漏某些可能的情况，导致划分不完备

**纠正**：
- 划分必须满足：互斥且穷尽（并集为全集）
- 常用技巧：用A和Ā作为最简单的划分

---

### 易错点4：二项分布与超几何分布混淆

**错误**：将不放回抽样问题错误地使用二项分布

**纠正**：
- **关键区别**：是否放回
- 有放回→二项分布
- 不放回→超几何分布
- 当总体很大、抽取量很小时，超几何分布可近似为二项分布

---

### 易错点5：方差性质应用错误

**错误1**：D[aX] = aD[X]（漏掉平方）
**纠正**：D[aX] = a²D[X]

**错误2**：D[X+Y] = D[X]+D[Y]（忽略独立性条件）
**纠正**：只有当X、Y独立时，D[X+Y] = D[X]+D[Y]

---

### 易错点6：正态分布概率计算错误

**错误**：直接计算密度函数值作为概率

**纠正**：
- 正态分布的概率是密度函数曲线下的面积
- P(a < X < b) = Φ((b-μ)/σ) - Φ((a-μ)/σ)
- 利用标准正态分布表或计算器求值

## 附录：公式速查表

### 条件概率与相关公式
| 公式名称 | 公式表达式 |
|---------|-----------|
| 条件概率 | $P(B\|A) = \frac{P(A \cap B)}{P(A)}$ |
| 乘法公式 | $P(A \cap B) = P(A) \cdot P(B\|A)$ |
| 全概率公式 | $P(A) = \sum_{k=1}^{n} P(A\|\Omega_k)P(\Omega_k)$ |
| 贝叶斯公式 | $P(\Omega_i\|A) = \frac{P(A\|\Omega_i)P(\Omega_i)}{\sum_{k=1}^{n} P(A\|\Omega_k)P(\Omega_k)}$ |

### 随机变量的数字特征
| 特征 | 定义/公式 |
|------|----------|
| 期望 | $E[X] = \sum_{i=1}^{n} x_ip_i$ |
| 方差 | $D[X] = E[(X-E[X])^2] = E[X^2] - (E[X])^2$ |
| 期望线性性 | $E[aX+bY] = aE[X] + bE[Y]$ |
| 方差性质 | $D[aX] = a^2D[X]$；若独立，$D[X+Y] = D[X]+D[Y]$ |

### 常用分布
| 分布 | 概率/密度 | 期望 | 方差 |
|------|----------|------|------|
| 二项分布B(n,p) | $P(X=k)=C_n^kp^k(1-p)^{n-k}$ | np | np(1-p) |
| 超几何分布 | $P(X=k)=\frac{C_a^kC_b^{n-k}}{C_{a+b}^n}$ | $n\frac{a}{a+b}$ | - |
| 正态分布N(μ,σ²) | $\varphi(x)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | μ | σ² |
