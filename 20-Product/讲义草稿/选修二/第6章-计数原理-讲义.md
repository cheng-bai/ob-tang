# 第6章 计数原理 - 讲义

## 一、本章解决什么问题

计数原理是数学中研究"有多少种方法"的基础理论。在实际生活中，我们经常遇到需要计算完成某件事情有多少种不同方法的问题：

- **路线选择问题**：从甲地到乙地有多少种不同的走法？
- **排列组合问题**：从n个元素中选取m个元素有多少种选法？
- **概率计算问题**：古典概率的计算往往需要用到计数方法
- **编码问题**：密码、电话号码等有多少种可能？

本章将学习两个基本计数原理（乘法原理和加法原理），以及排列、组合、二项式定理等核心内容，为解决各类计数问题提供系统的方法。

## 三、核心知识点详解

### 3.1 乘法原理（分步计数原理）

**定义**：做一件事，需要依次完成n个步骤，其中完成第一步有a₁种不同的方法，完成第二步有a₂种不同的方法，……，完成第n步有aₙ种不同的方法。那么完成这件事共有 **a₁ × a₂ × … × aₙ** 种不同的方法。

**关键特征**：
- 完成一件事需要分**若干步骤**
- 各步骤之间是**依次进行**的
- 用**乘法**计算总数

**例1**：一个三层书架，第一层有4本不同的语文书，第二层有3本不同的数学书，第三层有2本不同的外语书。从每层各取1本书，有多少种不同的取法？

**解**：分三步完成：
- 第一步：从第一层取语文书，有4种方法
- 第二步：从第二层取数学书，有3种方法  
- 第三步：从第三层取外语书，有2种方法

根据乘法原理，共有 **4 × 3 × 2 = 24** 种不同的取法。

---

### 3.2 加法原理（分类计数原理）

**定义**：做一件事，完成它有n类办法，其中第一类办法有a₁种不同的方法，第二类办法有a₂种不同的方法，……，第n类办法有aₙ种不同的方法。那么完成这件事共有 **a₁ + a₂ + … + aₙ** 种不同的方法。

**关键特征**：
- 完成一件事有**若干类办法**
- 各类办法之间是**相互独立**的
- 用**加法**计算总数

**例2**：从甲地到乙地，可乘飞机（4班）、轮船（3班）或汽车（2班）。一天中共有多少种不同的走法？

**解**：分三类：
- 第一类：乘飞机，有4种方法
- 第二类：乘轮船，有3种方法
- 第三类：乘汽车，有2种方法

根据加法原理，共有 **4 + 3 + 2 = 9** 种不同的走法。

---

### 3.3 乘法原理与加法原理的区别

| 比较项 | 乘法原理 | 加法原理 |
|--------|----------|----------|
| 完成方式 | 分步完成 | 分类完成 |
| 各方法关系 | 相互依存，缺一不可 | 相互独立，任选其一 |
| 计算方法 | 相乘 | 相加 |
| 关键词 | "先……再……" | "或者……或者……" |

---

### 3.4 排列

**定义**：从n个互不相同的元素中，取出m（m ≤ n）个不同元素按照一定的顺序排成一列，叫做从n个元素中取出m个元素的一个**排列**。

**排列数公式**：

$$P_n^m = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{(n-m)!}$$

其中 n! = n×(n-1)×(n-2)×…×3×2×1，称为n的阶乘。

**规定**：0! = 1

**例3**：用1、2、3、4、5可以组成多少个没有重复数字的三位数？

**解**：从5个数字中选3个进行排列：

$$P_5^3 = 5 × 4 × 3 = 60$$

---

### 3.5 组合

**定义**：从n个互不相同的元素中，取出m（m ≤ n）个不同元素作为一组，叫做从n个元素中取出m个元素的一个**组合**。

**组合数公式**：

$$C_n^m = \frac{P_n^m}{P_m^m} = \frac{n!}{m!(n-m)!}$$

**规定**：C_n^0 = 1

**排列与组合的区别**：
- **排列**：与顺序有关（ab 与 ba 是不同的排列）
- **组合**：与顺序无关（ab 与 ba 是相同的组合）

**例4**：圆上有10个不同的点，以其中任意3个点为顶点，可以组成多少个不同的三角形？

**解**：从10个点中选3个点，与顺序无关：

$$C_{10}^3 = \frac{10 × 9 × 8}{3 × 2 × 1} = 120$$

---

### 3.6 组合数的性质

**性质1**：$C_n^m = C_n^{n-m}$

**解释**：从n个元素中选m个元素，相当于从n个元素中留下n-m个元素。

**性质2**：$C_{n+1}^m = C_n^m + C_n^{m-1}$

**解释**：从n+1个元素中选m个，可以分为两类：
- 包含某个特定元素的：从剩下n个选m-1个，有C_n^{m-1}种
- 不包含该特定元素的：从剩下n个选m个，有C_n^m种

**例5**：计算 C_{100}^{97}

**解**：利用性质1：

$$C_{100}^{97} = C_{100}^3 = \frac{100 × 99 × 98}{3 × 2 × 1} = 161700$$

---

### 3.7 二项式定理

**定理**：对于任意正整数n，有

$$(a+b)^n = C_n^0 a^n + C_n^1 a^{n-1}b + C_n^2 a^{n-2}b^2 + \cdots + C_n^r a^{n-r}b^r + \cdots + C_n^n b^n$$

**通项公式**：第r+1项为 $T_{r+1} = C_n^r a^{n-r}b^r$（其中r = 0,1,2,…,n）

**杨辉三角**：

```
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
   1 5 10 10 5 1
```

**特点**：
1. 每行两端都是1
2. 每个数等于它"肩上"两个数之和
3. 第n行对应(a+b)^{n-1}的展开式系数

**例6**：求 $(3-2x)^6$ 展开式中 $x^3$ 项的系数。

**解**：通项为 $T_{r+1} = C_6^r · 3^{6-r} · (-2x)^r$

令r=3，得 $x^3$ 项的系数为：

$$C_6^3 · 3^3 · (-2)^3 = 20 × 27 × (-8) = -4320$$

---

### 3.8 二项式系数的性质

1. **对称性**：$C_n^k = C_n^{n-k}$

2. **单调性**：
   - 当k < (n+1)/2时，C_n^k 随k增大而增大
   - 当k > (n+1)/2时，C_n^k 随k增大而减小

3. **最大值**：
   - 当n为偶数时，中间一项 $C_n^{n/2}$ 最大
   - 当n为奇数时，中间两项 $C_n^{(n-1)/2}$ 和 $C_n^{(n+1)/2}$ 最大

4. **各项系数和**：$C_n^0 + C_n^1 + C_n^2 + \cdots + C_n^n = 2^n$

5. **奇数项与偶数项系数和相等**：
   
   $$C_n^0 + C_n^2 + C_n^4 + \cdots = C_n^1 + C_n^3 + C_n^5 + \cdots = 2^{n-1}$$

## 四、典型例题精讲

### 例题1：基本计数原理的应用

**题目**：公园有4个门，从一个门进，再从另一个门出，共有多少种不同的走法？

**分析**：
- 进门：有4种选择
- 出门：必须从另外3个门出（不能从同一个门进出）

**解答**：

根据乘法原理，共有 **4 × 3 = 12** 种不同的走法。

---

### 例题2：排列中的限制条件

**题目**：7个人站成一排，若甲和乙不能相邻排列，有多少种不同的排法？

**解法一（间接法）**：
- 7人全排列：$P_7^7 = 7! = 5040$
- 甲乙相邻的排法：将甲乙看作一个整体，有 $P_6^6 × P_2^2 = 720 × 2 = 1440$
- 甲乙不相邻的排法：$5040 - 1440 = 3600$

**解法二（插空法）**：
- 先排其余5人：$P_5^5 = 120$
- 5人形成6个空位，选2个空位放甲乙：$P_6^2 = 30$
- 共有：$120 × 30 = 3600$ 种

**答案**：3600种

---

### 例题3：组合应用

**题目**：某班有20名男生、18名女生，现从中任选5人组成一个宣传小组，其中男生和女生都有的选法有多少种？

**分析**：
- 总选法：$C_{38}^5$
- 全是男生的选法：$C_{20}^5$
- 全是女生的选法：$C_{18}^5$

**解答**：

男生和女生都有的选法 = 总选法 - 全是男生 - 全是女生

$$= C_{38}^5 - C_{20}^5 - C_{18}^5$$

$$= \frac{38×37×36×35×34}{5×4×3×2×1} - \frac{20×19×18×17×16}{5×4×3×2×1} - \frac{18×17×16×15×14}{5×4×3×2×1}$$

$$= 501942 - 15504 - 8568 = 477870$$

**答案**：477870种

---

### 例题4：分组分配问题

**题目**：把4本不同的书全部分给3名学生，每人至少1本，有多少种不同的分法？

**分析**：
4本书分给3人，每人至少1本，必有一人得2本，其余两人各得1本。

**解答**：

第一步：从4本书中选2本作为一组：$C_4^2 = 6$

第二步：将这三组（2本、1本、1本）分给3名学生：$P_3^3 = 6$

根据乘法原理，共有 $6 × 6 = 36$ 种分法。

**答案**：36种

---

### 例题5：二项式定理应用

**题目**：已知 $(1+x)^{10} = a_0 + a_1(1-x) + a_2(1-x)^2 + \cdots + a_{10}(1-x)^{10}$，求 $a_8$ 的值。

**分析**：
令 $1-x = y$，则 $x = 1-y$，原式变为：

$$(2-y)^{10} = a_0 + a_1y + a_2y^2 + \cdots + a_{10}y^{10}$$

**解答**：

$(2-y)^{10}$ 展开式中 $y^8$ 的系数为：

$$a_8 = C_{10}^8 · 2^2 · (-1)^8 = C_{10}^2 × 4 = 45 × 4 = 180$$

**答案**：$a_8 = 180$

---

### 例题6：综合应用

**题目**：从0、1、2、3、4、5六个数字中任取四个数字，可以组成多少个没有重复数字、且为奇数的四位数？

**分析**：
- 四位数：千位不能为0
- 奇数：个位必须是1、3、5中的一个

**解答**：

分两类讨论：

**第一类**：个位为1或3或5（3种），千位不为0且不与个位重复
- 个位：3种选择
- 千位：不能为0和个位数字，有4种选择
- 中间两位：从剩下4个数字中选2个排列，$P_4^2 = 12$

共有：$3 × 4 × 12 = 144$

**第二类**：个位为1或3或5，千位为0（不可能，因为千位不能为0）

所以总共有 **144** 个满足条件的四位数。

**答案**：144个

---

### 例题7：排列组合方程

**题目**：解关于正整数x的方程：$C_{16}^{x^2-x} = C_{16}^{5x-5}$

**分析**：
由组合数性质 $C_n^m = C_n^{n-m}$，有两种情况：

**情况1**：$x^2 - x = 5x - 5$
$$x^2 - 6x + 5 = 0$$
$$(x-1)(x-5) = 0$$
$$x = 1 \text{ 或 } x = 5$$

**情况2**：$x^2 - x + 5x - 5 = 16$
$$x^2 + 4x - 21 = 0$$
$$(x+7)(x-3) = 0$$
$$x = 3 \text{ 或 } x = -7 \text{（舍去负值）}$$

**验证**：
- x=1：$C_{16}^0 = C_{16}^0$ ✓
- x=3：$C_{16}^6 = C_{16}^{10}$ ✓
- x=5：$C_{16}^{20}$ 无意义（舍去）

**答案**：x = 1 或 x = 3

---

### 例题8：计数原理在概率中的应用

**题目**：袋中装有4个红球、3个黄球、3个白球，所有小球的大小与质地完全相同。从中同时任取2个小球，求取出的2个球颜色相同的概率。

**解答**：

总的取法：$C_{10}^2 = 45$

颜色相同的情况：
- 两个红球：$C_4^2 = 6$
- 两个黄球：$C_3^2 = 3$
- 两个白球：$C_3^2 = 3$

颜色相同的取法：$6 + 3 + 3 = 12$

概率：$P = \frac{12}{45} = \frac{4}{15}$

**答案**：$\frac{4}{15}$

## 五、方法技巧总结

### 5.1 计数问题的解题策略

| 问题类型 | 解题方法 | 关键要点 |
|----------|----------|----------|
| 排队问题 | 优先考虑特殊位置或特殊元素 | 注意限制条件 |
| 不相邻问题 | 插空法 | 先排无限制元素，再插入受限元素 |
| 相邻问题 | 捆绑法 | 将相邻元素视为一个整体 |
| 分组分配 | 先分组再分配 | 注意平均分组要除以组数的阶乘 |
| 至少/至多 | 间接法（补集思想） | 总数减去不满足条件的 |
| 定序问题 | 除法原理 | 先全排再除以定序元素的排列数 |

### 5.2 排列组合解题口诀

1. **分类加法，分步乘法** —— 区分使用加法原理还是乘法原理
2. **有序排列，无序组合** —— 判断是否与顺序有关
3. **特殊优先，一般随后** —— 优先处理特殊元素或位置
4. **正难则反，间接求解** —— 正面复杂时考虑反面
5. **相邻捆绑，不相邻插空** —— 处理相邻与不相邻问题
6. **定序除法，平均分组** —— 注意定序和平均分组的处理

### 5.3 易混淆概念辨析

**排列 vs 组合**：
- 排列：选取的元素有顺序要求
- 组合：选取的元素无顺序要求

**P_n^m vs C_n^m**：
- $P_n^m = C_n^m × P_m^m$（先选后排）
- $C_n^m = \frac{P_n^m}{P_m^m}$（只选不排）

**二项式系数 vs 项的系数**：
- 二项式系数：$C_n^r$（只与n、r有关）
- 项的系数：包含字母前面的所有常数因子

## 六、易错点警示

### 易错点1：混淆乘法原理与加法原理

**错误**：该用乘法时用加法，该用加法时用乘法

**纠正**：
- "完成一件事有n类办法" → 加法原理
- "完成一件事需要n个步骤" → 乘法原理

**例**：从甲地到乙地有2条路，从乙地到丙地有3条路。从甲地到丙地有多少种走法？
- 错误：2 + 3 = 5
- 正确：2 × 3 = 6（分两步完成）

---

### 易错点2：排列组合区分不清

**错误**：该用组合时用排列，或反之

**纠正**：关键看"顺序是否影响结果"
- 选小组（无序）→ 组合
- 排队（有序）→ 排列

---

### 易错点3：重复计数或遗漏

**错误**：在分组问题中，平均分组未除以组数的阶乘

**例**：将4人平均分成2组
- 错误：$C_4^2 = 6$
- 正确：$\frac{C_4^2}{2!} = 3$（两组无区别，需除以2!）

---

### 易错点4：忽视限制条件

**错误**：计算含0的数字排列时，未考虑0不能在首位

**纠正**：优先考虑特殊位置（如首位不能为0）

---

### 易错点5：二项式展开的错误

**错误**：
1. 通项公式记错：$T_{r+1} = C_n^r a^{n-r}b^r$（不是 $C_n^r a^r b^{n-r}$）
2. 混淆"第r项"与"第r+1项"
3. 求系数时忽略符号

**纠正**：
- 牢记通项公式中a的指数是n-r，b的指数是r
- 第k项对应r = k-1
- 注意(-b)^r的符号

---

### 易错点6：组合数计算错误

**错误**：$C_n^m$ 的计算中分子分母写错

**纠正**：

$$C_n^m = \frac{n(n-1)(n-2)\cdots(n-m+1)}{m(m-1)(m-2)\cdots 1}$$

- 分子：m个连续递减的数相乘，从n开始
- 分母：m的阶乘

## 附录：重要公式汇总

### 1. 排列数公式
$$P_n^m = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{(n-m)!}$$

### 2. 组合数公式
$$C_n^m = \frac{P_n^m}{P_m^m} = \frac{n!}{m!(n-m)!}$$

### 3. 组合数性质
- $C_n^m = C_n^{n-m}$
- $C_{n+1}^m = C_n^m + C_n^{m-1}$
- $C_n^0 + C_n^1 + C_n^2 + \cdots + C_n^n = 2^n$

### 4. 二项式定理
$$(a+b)^n = \sum_{r=0}^{n} C_n^r a^{n-r}b^r$$

### 5. 通项公式
$$T_{r+1} = C_n^r a^{n-r}b^r \quad (r = 0, 1, 2, \ldots, n)$$
