# 第9章 复数 讲义

## 一、本章解决什么问题

复数这一章的核心问题是：**解决实数范围内无法求解的方程问题**，特别是负数开平方和实系数一元二次方程在判别式小于0时的求根问题。

### 主要应用场景：
1. **代数领域**：求解实系数一元二次方程（包括判别式小于0的情况）
2. **几何领域**：通过复平面建立复数与平面向量、几何变换的联系
3. **物理应用**：交流电路分析、振动与波动等（大学物理基础）

### 学习价值：
- 复数是人类理性思维的演绎成果，扩展了数的概念
- 建立了代数与几何的桥梁（复平面）
- 为后续学习高等数学、物理奠定基础

## 三、核心知识点详解

### 3.1 复数的概念与分类

#### 1. 虚数单位的定义
- **定义**：$i^2 = -1$，$i$ 称为虚数单位
- **性质**：$i$ 是 $-1$ 的一个平方根

#### 2. 复数的代数形式
形如 $z = a + bi$（$a, b \in \mathbb{R}$）的数称为**复数**
- $a$ 称为**实部**，记作 $\text{Re}(z)$
- $b$ 称为**虚部**，记作 $\text{Im}(z)$

#### 3. 复数的分类
```
复数 z = a + bi
    │
    ├── 实数 (b = 0)
    │
    └── 虚数 (b ≠ 0)
            │
            ├── 纯虚数 (a = 0, b ≠ 0)
            │
            └── 非纯虚数 (a ≠ 0, b ≠ 0)
```

#### 4. 复数相等的条件
$z_1 = a + bi = z_2 = c + di \Leftrightarrow a = c$ 且 $b = d$

**特例**：$a + bi = 0 \Leftrightarrow a = 0$ 且 $b = 0$

---

### 3.2 复数的四则运算

#### 1. 加法与减法
$$(a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i$$

**运算特点**：实部与实部相加减，虚部与虚部相加减

#### 2. 乘法
$$(a + bi)(c + di) = (ac - bd) + (bc + ad)i$$

**运算特点**：按多项式乘法展开，利用 $i^2 = -1$ 化简

#### 3. 除法（核心技巧：分母实数化）
$$\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{(ac + bd) + (bc - ad)i}{c^2 + d^2}$$

**关键步骤**：分子分母同乘分母的**共轭复数**

---

### 3.3 共轭复数

#### 1. 定义
复数 $z = a + bi$ 的共轭复数为 $\bar{z} = a - bi$

#### 2. 重要性质
| 性质 | 公式 |
|------|------|
| 双重共轭 | $\overline{\bar{z}} = z$ |
| 加减法 | $\overline{z_1 \pm z_2} = \bar{z}_1 \pm \bar{z}_2$ |
| 乘法 | $\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2$ |
| 除法 | $\overline{\left(\frac{z_1}{z_2}\right)} = \frac{\bar{z}_1}{\bar{z}_2}$ |
| 实数判定 | $z \in \mathbb{R} \Leftrightarrow z = \bar{z}$ |
| 纯虚数判定 | $z$ 为纯虚数 $\Leftrightarrow z + \bar{z} = 0$ 且 $z \neq 0$ |

---

### 3.4 复数的几何意义

#### 1. 复平面
- **实轴**（$x$轴）：表示实数
- **虚轴**（$y$轴）：表示纯虚数（原点除外）
- 复数 $z = a + bi$ 对应点 $Z(a, b)$

#### 2. 向量表示
复数 $z = a + bi$ 对应向量 $\overrightarrow{OZ} = (a, b)$

#### 3. 复数加法的几何意义（平行四边形法则）
$$\overrightarrow{OZ} = \overrightarrow{OZ_1} + \overrightarrow{OZ_2}$$

#### 4. 复数减法的几何意义
$$|z_1 - z_2| = \text{两点 } Z_1, Z_2 \text{ 之间的距离}$$

---

### 3.5 复数的模

#### 1. 定义
$$|z| = |a + bi| = \sqrt{a^2 + b^2}$$

#### 2. 几何意义
- 复数 $z$ 对应的点到原点的距离
- 向量 $\overrightarrow{OZ}$ 的长度

#### 3. 重要性质
| 性质 | 公式 |
|------|------|
| 模与共轭 | $|z| = |\bar{z}|$，$z \cdot \bar{z} = |z|^2$ |
| 乘法 | $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$ |
| 除法 | $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$ |
| 三角不等式 | $|z_1| + |z_2| \geq |z_1 + z_2|$ |

---

### 3.6 实系数一元二次方程

#### 1. 求根公式
对于方程 $ax^2 + bx + c = 0$（$a \neq 0$，$a, b, c \in \mathbb{R}$）

判别式 $\Delta = b^2 - 4ac$

| $\Delta$ 的情况 | 根的情况 | 求根公式 |
|---------------|---------|---------|
| $\Delta > 0$ | 两个不等实根 | $x = \frac{-b \pm \sqrt{\Delta}}{2a}$ |
| $\Delta = 0$ | 两个相等实根 | $x = -\frac{b}{2a}$ |
| $\Delta < 0$ | 一对共轭虚根 | $x = \frac{-b \pm \sqrt{-\Delta}i}{2a}$ |

#### 2. 韦达定理（对虚根也成立）
$$x_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a}$$

#### 3. 重要结论
- 实系数方程的虚根成对出现（共轭复数）
- 若 $a + bi$ 是根，则 $a - bi$ 也是根

---

### 3.7 复数的三角形式（选学）

#### 1. 辐角与辐角主值
- **辐角**：$\text{Arg } z = \theta$（有无穷多个，相差 $2k\pi$）
- **辐角主值**：$\arg z = \theta \in [0, 2\pi)$

#### 2. 三角形式
$$z = r(\cos\theta + i\sin\theta)$$
其中 $r = |z|$，$\theta = \arg z$

#### 3. 三角形式下的乘除运算（棣莫弗公式）
**乘法**：
$$z_1 \cdot z_2 = r_1r_2[\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)]$$

**除法**：
$$\frac{z_1}{z_2} = \frac{r_1}{r_2}[\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)]$$

**几何意义**：
- 乘法 = 模相乘 + 辐角相加（旋转 + 伸缩）
- 除法 = 模相除 + 辐角相减

#### 4. 乘方与开方
**乘方**：
$$z^n = r^n(\cos n\theta + i\sin n\theta)$$

**$n$次方根**：
$$\sqrt[n]{z} = \sqrt[n]{r}\left(\cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n}\right), \quad k = 0, 1, ..., n-1$$

## 四、典型例题精讲

### 例题1：复数的概念与分类
**题目**：求实数 $m$ 的值，使得复数 $z = (m^2 + m - 2) + (m^2 - 1)i$ 分别是：
(1) 实数；(2) 虚数；(3) 纯虚数；(4) 零

**解析**：
(1) **实数**：虚部为0，即 $m^2 - 1 = 0$，得 $m = \pm 1$

(2) **虚数**：虚部不为0，即 $m^2 - 1 \neq 0$，得 $m \neq \pm 1$

(3) **纯虚数**：实部为0且虚部不为0
$$\begin{cases} m^2 + m - 2 = 0 \\ m^2 - 1 \neq 0 \end{cases} \Rightarrow \begin{cases} (m+2)(m-1) = 0 \\ m \neq \pm 1 \end{cases} \Rightarrow m = -2$$

(4) **零**：实部和虚部都为0
$$\begin{cases} m^2 + m - 2 = 0 \\ m^2 - 1 = 0 \end{cases} \Rightarrow m = 1$$

---

### 例题2：复数的四则运算
**题目**：计算：
(1) $(1 + 3i) + (-4 + 2i)$
(2) $(3 - 2i) - (3 + 2i)$
(3) $(2 - 3i)(4 + 2i)$
(4) $\frac{3 + i}{2 - i}$

**解析**：
(1) $(1 + 3i) + (-4 + 2i) = (1 - 4) + (3 + 2)i = -3 + 5i$

(2) $(3 - 2i) - (3 + 2i) = (3 - 3) + (-2 - 2)i = -4i$

(3) $(2 - 3i)(4 + 2i) = 8 + 4i - 12i - 6i^2 = 8 - 8i + 6 = 14 - 8i$

(4) $\frac{3 + i}{2 - i} = \frac{(3 + i)(2 + i)}{(2 - i)(2 + i)} = \frac{6 + 3i + 2i + i^2}{4 + 1} = \frac{5 + 5i}{5} = 1 + i$

---

### 例题3：共轭复数的性质应用
**题目**：设 $z_1 = 1 + 3i$，$z_2 = 1 - i$，求复数 $z$ 使得 $\bar{z} = \frac{z_1}{z_2}$

**解析**：
由共轭性质，$z = \overline{\left(\frac{z_1}{z_2}\right)} = \frac{\bar{z}_1}{\bar{z}_2}$

$$\frac{\bar{z}_1}{\bar{z}_2} = \frac{1 - 3i}{1 + i} = \frac{(1 - 3i)(1 - i)}{(1 + i)(1 - i)} = \frac{1 - i - 3i + 3i^2}{2} = \frac{-2 - 4i}{2} = -1 - 2i$$

所以 $z = -1 - 2i$

---

### 例题4：复数的几何意义
**题目**：已知复平面上的平行四边形 $OABC$，点 $A$ 和点 $C$ 分别对应复数 $z_A = -1 + i$ 和 $z_C = 3 + 2i$，求点 $B$ 对应的复数。

**解析**：
由平行四边形法则：$\overrightarrow{OB} = \overrightarrow{OA} + \overrightarrow{OC}$

所以 $z_B = z_A + z_C = (-1 + i) + (3 + 2i) = 2 + 3i$

---

### 例题5：复数的模
**题目**：求下列复数的模：
(1) $z_1 = 3 + 4i$
(2) $z_2 = -\frac{1}{2} - \sqrt{2}i$
(3) $\left|\frac{(1 - i)(1 + 2i)}{4 + 3i}\right|$

**解析**：
(1) $|z_1| = \sqrt{3^2 + 4^2} = 5$

(2) $|z_2| = \sqrt{\left(-\frac{1}{2}\right)^2 + (-\sqrt{2})^2} = \sqrt{\frac{1}{4} + 2} = \frac{3}{2}$

(3) 利用模的性质：$\left|\frac{z_1 \cdot z_2}{z_3}\right| = \frac{|z_1| \cdot |z_2|}{|z_3|}$

$$\left|\frac{(1 - i)(1 + 2i)}{4 + 3i}\right| = \frac{|1 - i| \cdot |1 + 2i|}{|4 + 3i|} = \frac{\sqrt{2} \cdot \sqrt{5}}{5} = \frac{\sqrt{10}}{5}$$

---

### 例题6：实系数一元二次方程
**题目**：在复数范围内解方程 $2x^2 - 4x + 5 = 0$

**解析**：
判别式 $\Delta = (-4)^2 - 4 \times 2 \times 5 = 16 - 40 = -24 < 0$

方程有一对共轭虚根：
$$x = \frac{4 \pm \sqrt{24}i}{4} = \frac{4 \pm 2\sqrt{6}i}{4} = 1 \pm \frac{\sqrt{6}}{2}i$$

---

### 例题7：韦达定理的应用
**题目**：若 $p, q$ 都是实数，方程 $2x^2 + px + q = 0$ 有一个根 $-2 + 3i$，求 $p, q$ 的值。

**解析**：
由于实系数方程的虚根成对出现，另一个根为 $-2 - 3i$

由韦达定理：
$$\begin{cases} (-2 + 3i) + (-2 - 3i) = -\frac{p}{2} \\ (-2 + 3i)(-2 - 3i) = \frac{q}{2} \end{cases}$$

$$\begin{cases} -4 = -\frac{p}{2} \Rightarrow p = 8 \\ 4 + 9 = \frac{q}{2} \Rightarrow q = 26 \end{cases}$$

---

### 例题8：复数的三角形式（选学）
**题目**：将 $\sqrt{3} + i$ 表示为三角形式

**解析**：
模：$r = \sqrt{(\sqrt{3})^2 + 1^2} = 2$

辐角：$\cos\theta = \frac{\sqrt{3}}{2}$，$\sin\theta = \frac{1}{2}$，所以 $\theta = \frac{\pi}{6}$

三角形式：$\sqrt{3} + i = 2\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right)$

## 五、方法技巧总结

### 技巧1：复数除法的"分母实数化"
```
核心：分子分母同乘分母的共轭复数

例：1/(a+bi) = (a-bi)/[(a+bi)(a-bi)] = (a-bi)/(a²+b²)
```

### 技巧2：利用模的性质简化计算
```
|z₁·z₂| = |z₁|·|z₂|
|z₁/z₂| = |z₁|/|z₂|
|zⁿ| = |z|ⁿ

适用：只需求模，不求具体复数值时
```

### 技巧3：实系数方程虚根成对
```
若 a+bi 是实系数方程的根，则 a-bi 也是根

应用：已知一个虚根，可直接写出另一个虚根
      然后用韦达定理求系数
```

### 技巧4：复数与向量的转化
```
复数差的几何意义：|z₁ - z₂| = 两点间距离

应用：求轨迹方程、最值问题
```

### 技巧5：i的幂的周期性
```
i¹ = i    i² = -1    i³ = -i    i⁴ = 1
周期为4：i^(4n+k) = i^k

常用结论：
• i⁴ⁿ = 1
• i⁴ⁿ⁺¹ = i
• i⁴ⁿ⁺² = -1
• i⁴ⁿ⁺³ = -i
• i⁴ⁿ + i⁴ⁿ⁺¹ + i⁴ⁿ⁺² + i⁴ⁿ⁺³ = 0
```

## 六、易错点警示

### 易错点1：混淆实部和虚部的符号
```
错误：z = 3 - 2i 的虚部是 -2
正确：z = 3 - 2i 的虚部是 -2（注意：虚部是实数！）

提醒：虚部是 bi 中的 b，不是 bi
```

### 易错点2：复数比较大小的误区
```
错误：认为复数可以比较大小
正确：只有实数才能比较大小，复数（非实数）不能比较大小

例：不能比较 1+i 和 2+i 的大小
```

### 易错点3：纯虚数的条件
```
错误：z = a+bi 是纯虚数 ⇔ b ≠ 0
正确：z = a+bi 是纯虚数 ⇔ a = 0 且 b ≠ 0

注意：必须同时满足实部为0且虚部不为0
```

### 易错点4：复数除法忘记分母实数化
```
错误：直接计算 (1+i)/(1-i)
正确：必须分子分母同乘 (1+i)

(1+i)/(1-i) = (1+i)²/[(1-i)(1+i)] = 2i/2 = i
```

### 易错点5：混淆 |z|² 与 z²
```
错误：认为 |z|² = z²
正确：|z|² = z·z̄ = a² + b²
      z² = (a+bi)² = a² - b² + 2abi

例：z = 1+i 时，|z|² = 2，z² = 2i
```

### 易错点6：实系数方程虚根的共轭关系
```
错误：认为所有方程的虚根都成对出现
正确：只有实系数方程的虚根才成对出现

例：方程 x² + ix = 0 的根是 0 和 -i，不是共轭的
    （因为系数不是实数）
```

| 加法 | $(a+bi) + (c+di) = (a+c) + (b+d)i$ |
| 减法 | $(a+bi) - (c+di) = (a-c) + (b-d)i$ |
| 乘法 | $(a+bi)(c+di) = (ac-bd) + (bc+ad)i$ |
| 除法 | $\frac{a+bi}{c+di} = \frac{(ac+bd) + (bc-ad)i}{c^2+d^2}$ |

### 3. 重要性质
| 性质 | 公式 |
|------|------|
| 模与共轭 | $z \cdot \bar{z} = |z|^2$ |
| 模的乘法 | $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$ |
| 模的除法 | $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$ |
| 实数判定 | $z \in \mathbb{R} \Leftrightarrow z = \bar{z}$ |

### 4. 一元二次方程
| 判别式 | 根的情况 | 求根公式 |
|--------|---------|---------|
| $\Delta > 0$ | 两不等实根 | $x = \frac{-b \pm \sqrt{\Delta}}{2a}$ |

| $\Delta < 0$ | 共轭虚根 | $x = \frac{-b \pm \sqrt{-\Delta}i}{2a}$ |
