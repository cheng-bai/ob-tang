# 数学试卷切分工作流

> **版本**：0.1.0
> **创建日期**：2026-04-20
> **用途**：将完整高中数学试卷按单题/小问切分为独立 MD 文件，支持按知识点检索、专题组卷、教研分析、AI 讲题与错题归因等下游应用

---

## 一、设计原则

语文切片库的核心单位是“板块”，数学切片库的核心单位应改为“单题”，必要时细化到“小问”。

原因：

- 数学教学的复用对象通常不是整张试卷的大板块，而是某一道题或某一问
- 同一题往往对应明确的知识点、方法和难度，适合做标准化标签
- 后续若要做 AI 讲题、同类题推荐、错因分析、专题组卷，单题粒度更合适

因此，数学版采用“两层结构”：

1. **试卷切片层**：忠实保留原题来源、题号、原始表述、图片和答案
2. **题库标准化层**：在 frontmatter 中补齐知识点、题型、方法、难度、易错点等结构化信息

---

## 二、输出目录结构

推荐使用“按知识模块建目录，按来源信息命名文件”的组织方式。

```text
数学试卷切片库/
├── 00-数学试卷切分工作流.md
├── 01-集合复数与逻辑/
├── 02-函数与导数/
├── 03-三角与向量/
├── 04-数列与不等式/
├── 05-立体几何与空间向量/
├── 06-解析几何/
├── 07-概率统计/
├── 08-综合与压轴/
└── 99-未归类待整理/
```

说明：

- 目录层级体现“教学使用方式”，而不是试卷原有大题顺序
- 区、届、考试类型、题号等信息不体现在目录层级，统一写入文件名和 frontmatter
- 暂时无法准确归类的题放入 `99-未归类待整理/`

## 三、知识模块定义

> **重要：模块识别优先按考查核心，不按题目出现位置。**

| 目录 | 模块 | 识别要点 |
|------|------|----------|
| `01-集合复数与逻辑` | 集合、常用逻辑、复数 | 集合运算、充分必要条件、命题真假、复数运算与几何意义 |
| `02-函数与导数` | 函数、导数及其应用 | 定义域、奇偶性、单调性、最值、零点、导数证明与参数讨论 |
| `03-三角与向量` | 三角函数、解三角形、平面向量 | 诱导公式、恒等变形、图像性质、向量数量积、向量表示与证明 |
| `04-数列与不等式` | 数列、不等式、数学归纳 | 通项与求和、递推、放缩、均值不等式、构造证明 |
| `05-立体几何与空间向量` | 空间几何体、线面关系、空间向量 | 平行垂直判定、角与距离、体积、空间向量坐标法 |
| `06-解析几何` | 直线、圆、圆锥曲线 | 方程、轨迹、位置关系、弦长、离心率、定点定值、最值 |
| `07-概率统计` | 计数、概率、随机变量、统计 | 排列组合、古典概型、二项分布、期望方差、统计图表与数据分析 |
| `08-综合与压轴` | 多知识点综合题 | 一题跨多个核心模块，且主考查点不易单独归类 |

### 归类原则

- **优先按主考点归类**：如导数题中含不等式证明，仍优先归入 `02-函数与导数`
- **允许多标签**：目录只能有一个主目录，但 frontmatter 中可保留多个 `subtopics`
- **整卷最后压轴题**不必强行放入 `08-综合与压轴`，若主考点明确，仍放回具体模块
- **选择题/填空题/解答题**都遵循相同归类逻辑

## 四、切分粒度

### 默认粒度：单题

每一道题作为一个独立题目单元。

示例：

- 第1题 选择题 → 一个题目单元
- 第15题 填空题 → 一个题目单元
- 第18题 解答题（含 3 个小问）→ 一个题目单元

### 细化粒度：小问

满足以下任一条件时，建议按小问继续切分：

- 解答题各小问考查点差异明显
- 各小问可独立用于专题训练
- 某些小问明显适合做“压轴第 1 问 / 第 2 问 / 第 3 问”分层训练

此时保留两级文件：

1. 题目级总文件
2. 小问级子文件

示例：

```text
2026-26届-浦东-一模-Q16-解析几何-题目.md
2026-26届-浦东-一模-Q16-解析几何-答案.md
2026-26届-浦东-一模-Q16-解析几何-解析.md
2026-26届-浦东-一模-Q16-1问-解析几何-题目.md
2026-26届-浦东-一模-Q16-1问-解析几何-答案.md
2026-26届-浦东-一模-Q16-2问-解析几何-题目.md
```

### 不建议切得过细的情况

- 选择题不要拆成“题干”和“选项”两个文件
- 一般填空题不要按空拆分
- 若小问强依赖前一问的结论，保留题目级文件即可，小问只作为标签信息记录

## 五、每道题切出的子文件

每道题推荐切出以下文件：

| 子文件后缀 | 内容 | 必须性 |
|-----------|------|--------|
| `-题目` | 题干、选项、图形、分值、作答要求 | 必须 |
| `-答案` | 标准答案、结果、结论、评分点 | 必须 |
| `-解析` | 解题步骤、思路说明、方法总结、常见错误 | 强烈建议 |
| `-变式` | 同类迁移题、条件变换题、拓展问法 | 可选 |

### 内容要求

- `-题目`：完整保留原题，不改写数学表达
- `-答案`：保留最终答案和必要步骤；若源文件仅给结果，也照实保留
- `-解析`：允许在忠实原题的前提下补充结构化讲解
- `-变式`：如无现成材料，可以后续再补

## 六、文件命名规则

### 题目级命名

```text
{年份}-{届}-{区名}-{考试}-Q{题号}-{模块名}-{功能}.md
```

示例：

```text
2026-26届-松江-一模-Q08-函数与导数-题目.md
2026-26届-浦东-二模-Q16-解析几何-答案.md
2026-26届-奉贤-一模-Q19-概率统计-解析.md
```

### 小问级命名

```text
{年份}-{届}-{区名}-{考试}-Q{题号}-{小问号}-{模块名}-{功能}.md
```

示例：

```text
2026-26届-浦东-一模-Q16-1问-解析几何-题目.md
2026-26届-浦东-一模-Q16-2问-解析几何-答案.md
```

### 命名约束

- 题号统一使用 `Q01`、`Q02` 这类格式，便于排序
- 小问统一使用 `1问`、`2问`、`3问`
- 模块名统一使用短名：
  - 集合复数与逻辑
  - 函数与导数
  - 三角与向量
  - 数列与不等式
  - 立体几何与空间向量
  - 解析几何
  - 概率统计
  - 综合与压轴

## 七、Frontmatter 规范

每个切出的 MD 文件必须包含以下 YAML frontmatter：

```yaml
---
title: "2026浦东一模第16题第2问"
subject: 高中数学
module: 06-解析几何
module_name: 解析几何
function: 题目
exam: 一模
year: 2026
class: 26届
district: 浦东
question_no: 16
subquestion_no: 2
question_type: 解答题
difficulty: 4
source: "2026年浦东新区高三数学一模试卷.pdf"
subtopics:
  - 椭圆
  - 直线与圆锥曲线位置关系
methods:
  - 设点
  - 联立方程
  - 韦达定理
tags:
  - 试卷切片
  - 高三数学
  - 一模
  - 浦东
  - 解析几何
---
```

### 必填字段

- `title`
- `subject`
- `module`
- `module_name`
- `function`
- `exam`
- `year`
- `class`
- `district`
- `question_no`
- `question_type`
- `source`
- `tags`

### 推荐字段

- `subquestion_no`
- `difficulty`
- `subtopics`
- `methods`
- `answer_type`
- `has_figure`
- `is_comprehensive`
- `related_questions`
- `common_mistakes`

### 字段建议

```yaml
answer_type: 结论型        # 选择题 / 填空题 / 结论型 / 过程型 / 证明型
has_figure: true
is_comprehensive: false
related_questions: []
common_mistakes:
  - 忽略定义域
  - 漏掉分类讨论
```

### 难度标记建议

统一采用 `1-5` 五级制：

- `1`：基础识记或直接套公式
- `2`：常规题，单一方法即可完成
- `3`：中档题，需要一定转化
- `4`：较难题，含参数、分类、综合推理
- `5`：压轴题或高区分度题

## 八、题型识别规范

| 题型 | 识别特征 |
|------|----------|
| 选择题 | 出现 A/B/C/D 等选项 |
| 填空题 | 只有题干，无选项，要求填写结果 |
| 解答题 | 含“解答下列问题”“求证”“求”“证明”等完整作答要求 |
| 多问解答题 | 解答题中出现“（1）”“（2）”“（3）”等小问 |

### 特殊情况

- 若选择题本质考查多步骤推理，题型仍标为 `选择题`
- 若填空题带简短证明要求，按 `解答题` 处理
- 若压轴题第一问较基础、后两问较综合，小问可分别标难度

## 九、执行工作流

### Step 1：提取文本与公式

从 docx / pdf 中提取试卷全文，尽量保留：

- 原题编号
- 数学公式
- 图形说明
- 小问层级
- 分值

建议：

- docx 优先提取原始文本结构
- pdf 优先读取文本层
- 对公式提取不稳定的题，保留原图并在题目中注明

### Step 2：识别题目边界

按题号识别单题边界，关键线索：

- `1.` `2.` `3.` 等题号
- `第16题`
- 小问标记 `（1）` `（2）` `（3）`
- 分值信息

### Step 3：识别模块与标签

对每题标注：

- 主模块
- 子知识点
- 题型
- 难度
- 方法
- 是否有图形

### Step 4：切分题目/答案/解析

按题号将试题部分与答案部分对应起来：

1. 从试卷正文提取 `-题目`
2. 从答案或评分标准中提取 `-答案`
3. 若存在教师版、讲评稿、评分细则，则整理成 `-解析`
4. 若存在附加变式题或同类题，整理成 `-变式`

### Step 5：写入文件

- 生成 frontmatter
- 写入对应模块目录
- 保留原始题号和来源
- 数学表达不做意译式改写

### Step 6：校验

切分完成后检查：

- [ ] 每道题是否都有 `-题目`
- [ ] 每道题是否匹配到了对应 `-答案`
- [ ] 多问题的小问编号是否完整
- [ ] frontmatter 字段是否齐全
- [ ] 模块归类是否合理
- [ ] 图形是否正确提取和引用
- [ ] 公式是否出现乱码或丢失

## 十、附加材料处理

数学试卷常见附加材料：

| 材料类型 | 处理方式 |
|----------|----------|
| 评分标准 | 合并到对应题目的 `-答案` 或 `-解析` |
| 教师版讲评 | 优先整理为 `-解析` |
| PPT 讲评 | 提取文字和关键图形，整理为 `-解析` |
| 学生典型错误 | 写入 `common_mistakes`，并可附加到 `-解析` |
| 同类题精选 | 整理为 `-变式` |

### 处理原则

- 评分标准是“答案层”信息
- 讲评稿和方法总结是“解析层”信息
- 错因反馈是“教学层”信息，优先进入 `-解析`

---

## 十一、图片与图形处理

数学比语文更依赖图形，因此图片处理是关键能力。

### 图片来源

- docx 内嵌图形
- pdf 中的统计图、几何图、函数图像
- 教师版中的补充示意图

### 提取规则

1. 识别图片在文档中的位置
2. 判断其对应题号
3. 复制到对应模块目录下的 `images/` 子目录
4. 在题目或解析文件中插入相对路径引用

### 目录结构示例

```text
06-解析几何/
├── images/
│   └── 2026-26届-浦东-一模-Q16-fig1.png
├── 2026-26届-浦东-一模-Q16-解析几何-题目.md
└── 2026-26届-浦东-一模-Q16-解析几何-解析.md
```

### 图片命名规则

```text
{年份}-{届}-{区名}-{考试}-Q{题号}-fig{序号}.{ext}
```

### MD 中引用格式

```markdown
![Q16题图](images/2026-26届-浦东-一模-Q16-fig1.png)
```

### Frontmatter 补充字段

```yaml
has_figure: true
figure_count: 1
```

## 十二、答案与解析分层标准

数学题库中，“答案”和“解析”不应混为一谈。

### `-答案`

只保留：

- 最终结果
- 必要中间结果
- 评分点
- 标准结论

### `-解析`

重点补充：

- 解题入口
- 每一步依据
- 关键转化
- 易错点
- 其他解法
- 方法总结

### 示例

同一道导数题：

- `-答案`：写出导函数、单调区间、最值结论
- `-解析`：解释为什么先构造辅助函数、为什么要分类讨论、哪里容易漏解

## 十三、批量处理规则

当一次性处理多套试卷时：

- 每套试卷独立执行完整 Step 1-6
- 每道题归入对应模块目录
- 同一目录下允许聚合多个区、多个年份的同类题
- 处理完毕后输出汇总表

建议至少输出以下矩阵：

1. 区 × 题号完成矩阵
2. 区 × 模块分布矩阵
3. 模块 × 难度分布矩阵

## 十四、与现有语文切片库的关系

- **语文切片库**：按阅读板块切分，强调素材来源完整性
- **数学切片库**：按单题切分，强调题目复用和知识点组织

二者可共享的部分：

- 文件命名规范
- frontmatter 思路
- 来源保留方式
- 图片提取机制
- 批量处理 workflow

数学版需要新增的部分：

- 知识模块归类
- 难度标记
- 方法标签
- 小问级切分
- 答案/解析分层

## 十五、推荐的后续增强

如果要把这个库真正做成高可用数学题库，建议后续继续补三层结构：

### 1. 知识点索引

建立统一词表，避免同义标签混乱。

例如：

- “导数单调性”
- “利用导数研究函数单调性”
- “导数与单调区间”

应统一映射到同一个标准标签。

### 2. 方法标签索引

例如：

- 分类讨论
- 数形结合
- 构造函数
- 换元
- 设而不求
- 韦达定理
- 空间向量法

### 3. 错因标签索引

例如：

- 漏讨论参数范围
- 忽略定义域
- 计算失误
- 结论不充分
- 图形判断错误

## 十六、最小可行版本建议

如果先做 MVP，建议只要求每道题具备以下信息：

- `-题目`
- `-答案`
- `module`
- `question_type`
- `difficulty`
- `subtopics`

在这个基础上，后续再逐步补：

- `-解析`
- `methods`
- `common_mistakes`
- `-变式`

这样能更快把现有试卷先铺进库里，而不会一开始就卡在精细标注上。

---

## 十七、推荐起步策略

建议不要一上来处理全部试卷，先拿 2 到 3 份格式较规范的一模试卷做试点。

推荐流程：

1. 先做一套完整样板卷
2. 检查模块归类是否稳定
3. 检查题号与答案映射是否稳定
4. 检查公式和图形提取质量
5. 再批量扩展到多区

---

## 十八、结论

数学版不是把“文学/诗歌/写作”替换成“函数/数列/几何”这么简单，而是要把底层单位从“板块”改成“单题”，把库从“试卷素材库”升级成“可检索、可组卷、可讲解”的结构化题库。

这份工作流的目标，就是把这个转型标准化。
