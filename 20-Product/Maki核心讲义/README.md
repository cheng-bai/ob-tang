# 高中数学核心讲义

B站@Maki的完美算术教室 出品

## 项目结构

```
latex-maki-math/
├── AGENTS.md             # AI 协作规则与执行约定
├── ai-context/           # 跨 AI 记忆与上下文包
├── 00-索引与配置/        # 任务记录、索引与项目配置
├── docs/                 # 工作流规范与复盘机制
├── main.tex              # 主文档入口
├── maki-math.sty         # 自定义排版样式包（核心）
├── chapters/             # 章节文件夹
│   ├── 01-sets_and_logic.tex    # 第1章：集合与常用逻辑用语
│   ├── 02-functions.tex         # 第2章：函数的概念与性质
│   ├── 03-derivatives.tex       # 第3章：导数及其应用
│   ├── 04-geometry.tex          # 第4章：立体几何
│   ├── 05-conic_sections.tex    # 第5章：圆锥曲线
│   ├── 06-sequences.tex         # 第6章：数列
│   ├── 07-trigonometry.tex      # 第7章：三角函数
│   └── 08-inequalities.tex      # 第8章：不等式
```

## AI 协作与任务记录

- 根目录 `AGENTS.md`：说明 AI 在本项目中的默认执行规则。
- `ai-context/`：存放从其他 AI 导入并清洗后的上下文包。
- `docs/自我复盘与迭代机制.md`：规定“完成任务 -> 复盘 -> 迭代 -> 进化”的闭环。
- `docs/跨AI记忆导入工作流.md`：用于把其他 AI 的记忆导出、去敏、分层并整理成可复用上下文。
- `00-索引与配置/任务执行记录.md`：记录每次真实修改、验证结果、风险和下次自动采用的规则。

## 样式特色

本讲义使用自定义的 `maki-math.sty` 样式包，具有以下特色：

### 环境定义
- `definition` - 定义框（橙色主题）
- `theorem` - 定理框（紫红色主题）
- `example` / `exercise` - 例题/练习框（蓝色主题）
- `property` - 性质框
- `note` - 注释/提示
- `proof` - 证明环境

### 记忆口诀
每章都配有精心设计的记忆口诀，帮助学生快速掌握核心概念：
- 集合："交小并大"、"子交并补"
- 导数："正增负减"
- 立体几何："柱平锥尖台球圆"
- 圆锥曲线："大分母定轴向"、"一次项定轴，系数定方向"
- 三角函数："一全正，二正弦，三正切，四余弦"、"奇变偶不变，符号看象限"
- 不等式："大于取两边，小于取中间"、"一正二定三相等"

### 交互元素
- `\selectbracket` - 选择题括号
- `\fillin` - 填空下划线
