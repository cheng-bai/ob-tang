\end{center}

\section*{知识概要}
\addcontentsline{toc}{section}{知识概要}

排列与组合是计数原理的核心内容，是解决计数问题的基础工具。正确区分排列与组合，掌握其计算公式和应用技巧，对于解决各类计数问题至关重要。

\begin{definition}[排列]
    从 $n$ 个不同元素中取出 $m$ ($m \leq n$) 个元素，按照一定的顺序排成一列，叫做从 $n$ 个不同元素中取出 $m$ 个元素的一个\textbf{排列}。
    
    从 $n$ 个不同元素中取出 $m$ 个元素的排列数记作 $A_n^m$ (或 $P_n^m$)，计算公式为：
    \[
        A_n^m = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{(n-m)!}
    \]
    特别地，当 $m = n$ 时，$A_n^n = n!$，称为 $n$ 个元素的全排列。
\end{definition}

\begin{definition}[组合]
    从 $n$ 个不同元素中取出 $m$ ($m \leq n$) 个元素并成一组，叫做从 $n$ 个不同元素中取出 $m$ 个元素的一个\textbf{组合}。
    
    从 $n$ 个不同元素中取出 $m$ 个元素的组合数记作 $C_n^m$ (或 $\binom{n}{m}$)，计算公式为：
    \[
        C_n^m = \frac{A_n^m}{A_m^m} = \frac{n!}{m!(n-m)!}
    \]
\end{definition}

\begin{property}[排列与组合的基本性质]
    \begin{enumerate}
        \item \textbf{排列数性质}：
        \begin{itemize}
            \item $A_n^m = n \cdot A_{n-1}^{m-1}$
            \item $A_n^m = (n-m+1) \cdot A_n^{m-1}$
        \end{itemize}
        
        \item \textbf{组合数性质}：
        \begin{itemize}
            \item $C_n^m = C_n^{n-m}$ (对称性)
            \item $C_n^m = C_{n-1}^{m-1} + C_{n-1}^m$ (递推公式/帕斯卡法则)
            \item $C_n^0 + C_n^1 + C_n^2 + \cdots + C_n^n = 2^n$
            \item $kC_n^k = nC_{n-1}^{k-1}$
        \end{itemize}
    \end{enumerate}
\end{property}

\begin{property}[排列与组合的区别]
    \begin{itemize}
        \item \textbf{排列}：与顺序有关，选出的元素有位置要求
        \item \textbf{组合}：与顺序无关，只关心选出了哪些元素
    \end{itemize}
    判断关键是：交换两个元素的位置，若结果不同则是排列问题，若结果相同则是组合问题。
\end{property}

\section*{典型例题}
\addcontentsline{toc}{section}{典型例题}

\begin{example}[基础排列计算]
    从 $5$ 名男同学和 $4$ 名女同学中选出 $3$ 名男同学和 $2$ 名女同学，分别担任班长、副班长、学习委员、文艺委员、体育委员 $5$ 种不同的职务，共有多少种不同的选法？
\end{example}

\textbf{解.} 这是一个分步完成的排列组合问题。

第一步：从 $5$ 名男同学中选 $3$ 名，有 $C_5^3 = 10$ 种选法；

第二步：从 $4$ 名女同学中选 $2$ 名，有 $C_4^2 = 6$ 种选法；

第三步：将选出的 $5$ 人分配到 $5$ 个不同的职务，有 $A_5^5 = 5! = 120$ 种分配方法。

根据乘法原理，共有 $C_5^3 \cdot C_4^2 \cdot A_5^5 = 10 \times 6 \times 120 = 7200$ 种不同的选法。

\begin{example}[特殊位置优先法]
    用数字 $0, 1, 2, 3, 4, 5$ 组成没有重复数字的五位数，其中比 $40000$ 大的偶数共有多少个？
\end{example}

\textbf{解.} 要组成比 $40000$ 大的五位数，万位必须是 $4$ 或 $5$。同时要求是偶数，个位必须是 $0, 2, 4$。

\textbf{情况一：万位是 $4$}

此时个位只能是 $0$ 或 $2$（不能是 $4$，因为 $4$ 已在万位）。

- 若个位是 $0$：中间三位从剩余 $4$ 个数中选 $3$ 个排列，有 $A_4^3 = 24$ 个
- 若个位是 $2$：中间三位从剩余 $4$ 个数中选 $3$ 个排列，有 $A_4^3 = 24$ 个

情况一共有 $24 + 24 = 48$ 个。

\textbf{情况二：万位是 $5$}

此时个位可以是 $0, 2, 4$。

- 若个位是 $0$：中间三位从剩余 $4$ 个数中选 $3$ 个排列，有 $A_4^3 = 24$ 个
- 若个位是 $2$：中间三位从剩余 $4$ 个数中选 $3$ 个排列，有 $A_4^3 = 24$ 个
- 若个位是 $4$：中间三位从剩余 $4$ 个数中选 $3$ 个排列，有 $A_4^3 = 24$ 个

情况二共有 $24 \times 3 = 72$ 个。

综上所述，共有 $48 + 72 = 120$ 个满足条件的五位数。

\begin{example}[捆绑法与插空法]
    某班一天上午有语文、数学、英语、物理、化学 $5$ 节课，要求数学课不排在第一节，语文课与英语课相邻，共有多少种不同的排课方法？
\end{example}

\textbf{解.} 采用捆绑法处理相邻问题。

第一步：将语文课与英语课捆绑在一起，看作一个整体，内部有 $A_2^2 = 2$ 种排列方式；

第二步：将这个整体与数学、物理、化学共 $4$ 个"元素"进行排列。但数学不能排在第一节。

先不考虑限制，$4$ 个元素全排列有 $A_4^4 = 24$ 种。

数学排在第一节的情况：将数学固定在第一节，其余 $3$ 个元素全排列有 $A_3^3 = 6$ 种。

所以满足条件的排法有 $24 - 6 = 18$ 种。

根据乘法原理，共有 $2 \times 18 = 36$ 种不同的排课方法。

\begin{realexam}[2025 上海高三一模]
    从 $6$ 名志愿者中选出 $4$ 人分别从事翻译、导游、导购、保洁四项不同的工作，若其中甲、乙两名志愿者都不能从事翻译工作，则不同的选派方案共有多少种？
\end{realexam}

\textbf{解.} 采用位置优先法，先考虑特殊位置——翻译工作。

翻译工作只能从除甲、乙外的 $4$ 人中选 $1$ 人，有 $4$ 种选法。

剩余 $3$ 项工作从剩下的 $5$ 人中选 $3$ 人进行排列，有 $A_5^3 = 60$ 种选法。

根据乘法原理，共有 $4 \times 60 = 240$ 种不同的选派方案。

\begin{realexam}[练习]
    某学校要从 $5$ 名男教师和 $3$ 名女教师中选出 $3$ 人参加培训，要求至少有 $1$ 名女教师，共有多少种不同的选法？
\end{realexam}

\textbf{解.} 方法一（直接法）：按女教师人数分类。

- $1$ 名女教师、$2$ 名男教师：$C_3^1 \cdot C_5^2 = 3 \times 10 = 30$ 种
- $2$ 名女教师、$1$ 名男教师：$C_3^2 \cdot C_5^1 = 3 \times 5 = 15$ 种
- $3$ 名女教师：$C_3^3 = 1$ 种

共有 $30 + 15 + 1 = 46$ 种选法。

方法二（间接法）：总选法减去全是男教师的选法。

总选法：$C_8^3 = 56$ 种

全是男教师：$C_5^3 = 10$ 种

共有 $56 - 10 = 46$ 种选法。

\section*{方法总结}
\addcontentsline{toc}{section}{方法总结}

\begin{enumerate}
    \item \textbf{特殊位置（元素）优先法}：
    当某些位置或元素有特殊限制时，优先安排这些特殊位置或元素。
    
    \item \textbf{捆绑法}：
    用于解决"必须相邻"的问题。将必须相邻的元素捆绑成一个整体，与其他元素一起排列，再考虑捆绑内部的排列。
    
    \item \textbf{插空法}：
    用于解决"不能相邻"的问题。先排好其他元素，再将不能相邻的元素插入到已排元素形成的空隙中。
    
    \item \textbf{间接法（排除法）}：
    当正面分类较复杂时，先求总数，再减去不符合条件的情况。常用于"至少"、"至多"等问题。
    
    \item \textbf{定序问题除法}：
    当某些元素的相对顺序固定时，先用全排列，再除以定序元素的排列数。
    
    \item \textbf{分组分配问题}：
    \begin{itemize}
        \item 平均分组要注意消除重复（除以组数的阶乘）
        \item 非平均分组直接按组合数计算
        \item 分配问题先分组再排列
    \end{itemize}
    
    \item \textbf{易错点提醒}：
    \begin{itemize}
        \item 区分排列与组合：是否与顺序有关
        \item 注意元素是否可重复
        \item 注意"至少"、"至多"、"恰有"等关键词的含义
        \item 分类要做到不重不漏，分步要做到步骤完整
    \end{itemize}
\end{enumerate}
