    {\LARGE\bfseries 专题：计数原理在概率中的应用}
\end{center}

\section*{知识概要}
\addcontentsline{toc}{section}{知识概要}

计数原理（分类加法计数原理和分步乘法计数原理）是概率计算的基础工具。古典概型中，事件概率的计算本质上是计数问题——计算基本事件总数和事件包含的基本事件数。

\begin{definition}[分类加法计数原理]
    完成一件事，有 $n$ 类办法，在第 $1$ 类办法中有 $m_1$ 种不同的方法，在第 $2$ 类办法中有 $m_2$ 种不同的方法，……，在第 $n$ 类办法中有 $m_n$ 种不同的方法，那么完成这件事共有
    \[
        N = m_1 + m_2 + \cdots + m_n
    \]
    种不同的方法。
    
    关键词：\textbf{分类}——各类方法相互独立，任选一类方法中的任一种都能独立完成这件事。
\end{definition}

\begin{definition}[分步乘法计数原理]
    完成一件事，需要分成 $n$ 个步骤，做第 $1$ 步有 $m_1$ 种不同的方法，做第 $2$ 步有 $m_2$ 种不同的方法，……，做第 $n$ 步有 $m_n$ 种不同的方法，那么完成这件事共有
    \[
        N = m_1 \times m_2 \times \cdots \times m_n
    \]
    种不同的方法。
    
    关键词：\textbf{分步}——各步骤相互依存，只有依次完成所有步骤才能完成这件事。
\end{definition}

\begin{property}[古典概型的概率公式]
    若试验的样本空间 $\Omega$ 包含 $n$ 个等可能的基本事件，事件 $A$ 包含其中的 $k$ 个基本事件，则事件 $A$ 发生的概率为：
    \[
        P(A) = \frac{k}{n} = \frac{\text{事件 } A \text{ 包含的基本事件数}}{\text{样本空间包含的基本事件总数}}
    \]
    
    计算的关键在于正确运用计数原理求出分子和分母。
\end{property}

\begin{property}[计数原理与概率计算的关联]
    \begin{enumerate}
        \item \textbf{基本事件总数的计算}：根据问题的特点，选择分类或分步方法计算样本空间的大小
        \item \textbf{事件包含的基本事件数}：分析事件的结构，用计数原理计算符合条件的基本事件个数
        \item \textbf{复杂事件的处理}：利用对立事件、互斥事件等性质，将复杂事件分解为简单事件的组合
    \end{enumerate}
\end{property}

\section*{典型例题}
\addcontentsline{toc}{section}{典型例题}

\begin{example}[分类与分步的综合应用]
    从 $1, 2, 3, 4, 5$ 这 $5$ 个数字中任取 $3$ 个组成没有重复数字的三位数，求：
    \begin{enumerate}
        \item 这个三位数是偶数的概率
        \item 这个三位数大于 $400$ 的概率
    \end{enumerate}
\end{example}

\textbf{解.} 首先计算基本事件总数：从 $5$ 个数字中任取 $3$ 个组成三位数，有 $A_5^3 = 5 \times 4 \times 3 = 60$ 个。

(1) 三位数是偶数，则个位必须是 $2$ 或 $4$。

- 个位是 $2$：百位和十位从剩余 $4$ 个数中选 $2$ 个排列，有 $A_4^2 = 12$ 个
- 个位是 $4$：百位和十位从剩余 $4$ 个数中选 $2$ 个排列，有 $A_4^2 = 12$ 个

共有 $12 + 12 = 24$ 个偶数。

所以三位数是偶数的概率为 $P = \dfrac{24}{60} = \dfrac{2}{5}$。

(2) 三位数大于 $400$，则百位必须是 $4$ 或 $5$。

- 百位是 $4$：十位和个位从剩余 $4$ 个数中选 $2$ 个排列，有 $A_4^2 = 12$ 个
- 百位是 $5$：十位和个位从剩余 $4$ 个数中选 $2$ 个排列，有 $A_4^2 = 12$ 个

共有 $12 + 12 = 24$ 个大于 $400$ 的三位数。

所以三位数大于 $400$ 的概率为 $P = \dfrac{24}{60} = \dfrac{2}{5}$。

\begin{example}[排列组合在概率中的应用]
    从 $6$ 名男同学和 $4$ 名女同学中随机选出 $3$ 人，求：
    \begin{enumerate}
        \item 选出的 $3$ 人都是男同学的概率
        \item 选出的 $3$ 人中至少有 $1$ 名女同学的概率
        \item 选出的 $3$ 人中男女人数不全相同的概率
    \end{enumerate}
\end{example}

\textbf{解.} 基本事件总数：从 $10$ 人中选 $3$ 人，有 $C_{10}^3 = 120$ 种选法。

(1) 选出的 $3$ 人都是男同学：从 $6$ 名男同学中选 $3$ 人，有 $C_6^3 = 20$ 种选法。

概率为 $P = \dfrac{20}{120} = \dfrac{1}{6}$。

(2) 方法1（直接法）：按女同学人数分类。

- $1$ 女 $2$ 男：$C_4^1 \cdot C_6^2 = 4 \times 15 = 60$ 种
- $2$ 女 $1$ 男：$C_4^2 \cdot C_6^1 = 6 \times 6 = 36$ 种
- $3$ 女 $0$ 男：$C_4^3 = 4$ 种

共有 $60 + 36 + 4 = 100$ 种。

概率为 $P = \dfrac{100}{120} = \dfrac{5}{6}$。

方法2（间接法）：用 $1$ 减去"全是男同学"的概率。

$P = 1 - \dfrac{1}{6} = \dfrac{5}{6}$。

(3) "男女人数不全相同"的对立事件是"男女人数全相同"。

由于选出 $3$ 人，不可能出现男女人数全相同的情况（$3$ 是奇数，无法均分）。

所以概率为 $P = 1 - 0 = 1$。

\begin{example}[分步计数与条件概率]
    甲、乙、丙三人独立地破译一份密码，已知甲、乙、丙各自能破译密码的概率分别为 $\dfrac{1}{2}$、$\dfrac{1}{3}$、$\dfrac{1}{4}$，求：
    \begin{enumerate}
        \item 密码被破译的概率
        \item 恰有两人破译出密码的概率
    \end{enumerate}
\end{example}

\textbf{解.} (1) 密码被破译的对立事件是"三人都不能破译"。

三人都不能破译的概率为：
\[
    P(\text{都不能}) = \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{3}\right) \times \left(1 - \frac{1}{4}\right) = \frac{1}{2} \times \frac{2}{3} \times \frac{3}{4} = \frac{1}{4}
\]

所以密码被破译的概率为 $P = 1 - \dfrac{1}{4} = \dfrac{3}{4}$。

(2) 恰有两人破译出密码，有三种情况：

- 甲、乙破译，丙没破译：$\dfrac{1}{2} \times \dfrac{1}{3} \times \dfrac{3}{4} = \dfrac{1}{8}$
- 甲、丙破译，乙没破译：$\dfrac{1}{2} \times \dfrac{2}{3} \times \dfrac{1}{4} = \dfrac{1}{12}$
- 乙、丙破译，甲没破译：$\dfrac{1}{2} \times \dfrac{1}{3} \times \dfrac{1}{4} = \dfrac{1}{24}$

恰有两人破译出密码的概率为：
\[
    P = \frac{1}{8} + \frac{1}{12} + \frac{1}{24} = \frac{3}{24} + \frac{2}{24} + \frac{1}{24} = \frac{6}{24} = \frac{1}{4}
\]

\begin{realexam}[2025 上海高三一模]
    袋中有 $5$ 个白球和 $3$ 个黑球，从中任意摸出 $3$ 个球，求：
    \begin{enumerate}
        \item 摸出的 $3$ 个球都是白球的概率
        \item 摸出的 $3$ 个球中至少有 $1$ 个黑球的概率
        \item 摸出的 $3$ 个球中白球比黑球多的概率
    \end{enumerate}
\end{realexam}

\textbf{解.} 基本事件总数：从 $8$ 个球中选 $3$ 个，有 $C_8^3 = 56$ 种选法。

(1) 摸出的 $3$ 个球都是白球：从 $5$ 个白球中选 $3$ 个，有 $C_5^3 = 10$ 种选法。

概率为 $P = \dfrac{10}{56} = \dfrac{5}{28}$。

(2) 方法1（直接法）：按黑球个数分类。

- $1$ 黑 $2$ 白：$C_3^1 \cdot C_5^2 = 3 \times 10 = 30$ 种
- $2$ 黑 $1$ 白：$C_3^2 \cdot C_5^1 = 3 \times 5 = 15$ 种
- $3$ 黑 $0$ 白：$C_3^3 = 1$ 种

共有 $30 + 15 + 1 = 46$ 种。

概率为 $P = \dfrac{46}{56} = \dfrac{23}{28}$。

方法2（间接法）：$P = 1 - \dfrac{5}{28} = \dfrac{23}{28}$。

(3) 白球比黑球多，即白球数为 $2$ 或 $3$。

- $3$ 白 $0$ 黑：$C_5^3 = 10$ 种
- $2$ 白 $1$ 黑：$C_5^2 \cdot C_3^1 = 10 \times 3 = 30$ 种

共有 $10 + 30 = 40$ 种。

概率为 $P = \dfrac{40}{56} = \dfrac{5}{7}$。

\begin{realexam}[练习]
    从一副 $52$ 张的扑克牌（不含大小王）中随机抽取 $5$ 张，求：
    \begin{enumerate}
        \item 抽到 $5$ 张同花色的概率
        \item 抽到 $3$ 张同一点数（三张相同）另外 $2$ 张也同一点数（但对数不同）的概率（即"葫芦"）
    \end{enumerate}
\end{realexam}

\textbf{解.} 基本事件总数：$C_{52}^5 = 2598960$。

(1) 抽到 $5$ 张同花色：

一副牌有 $4$ 种花色，每种花色 $13$ 张。

从某一花色中选 $5$ 张有 $C_{13}^5$ 种，共 $4$ 种花色。

所以同花色的选法有 $4 \cdot C_{13}^5 = 4 \times 1287 = 5148$ 种。

概率为 $P = \dfrac{5148}{2598960} = \dfrac{33}{16660} \approx 0.00198$。

(2) 抽到"葫芦"（三张同一点数 + 两张同一点数）：

第一步：选三张的点数（$13$ 种），再从 $4$ 张中选 $3$ 张：$C_{13}^1 \cdot C_4^3 = 13 \times 4 = 52$ 种

第二步：选对子的点数（剩余 $12$ 种），再从 $4$ 张中选 $2$ 张：$C_{12}^1 \cdot C_4^2 = 12 \times 6 = 72$ 种

共有 $52 \times 72 = 3744$ 种。

概率为 $P = \dfrac{3744}{2598960} = \dfrac{6}{4165} \approx 0.00144$。

\section*{方法总结}
\addcontentsline{toc}{section}{方法总结}

\begin{enumerate}
    \item \textbf{确定计数方法}：
    \begin{itemize}
        \item 分类加法：完成一件事有多类方法，各类相互独立
        \item 分步乘法：完成一件事需要多个步骤，各步相互依存
        \item 实际问题中常需分类与分步结合使用
    \end{itemize}
    
    \item \textbf{古典概型概率计算步骤}：
    \begin{enumerate}
        \item 确定试验的样本空间，计算基本事件总数 $n$
        \item 分析事件 $A$ 的结构，计算事件 $A$ 包含的基本事件数 $k$
        \item 计算概率 $P(A) = \dfrac{k}{n}$
    \end{enumerate}
    
    \item \textbf{常用解题策略}：
    \begin{itemize}
        \item \textbf{直接法}：直接计算符合条件的基本事件数
        \item \textbf{间接法}：利用 $P(A) = 1 - P(\bar{A})$，适用于"至少"、"至多"问题
        \item \textbf{分类讨论}：将复杂事件分解为互斥的简单事件之和
        \item \textbf{分步计数}：将复杂事件分解为相互独立的步骤之积
    \end{itemize}
    
    \item \textbf{排列与组合的选择}：
    \begin{itemize}
        \item 与顺序有关用排列 $A_n^m$
        \item 与顺序无关用组合 $C_n^m$
        \item 注意区分"有序选取"和"无序选取"
    \end{itemize}
    
    \item \textbf{易错点提醒}：
    \begin{itemize}
        \item 确保每个基本事件等可能
        \item 分子分母计数标准要统一（都用排列或都用组合）
        \item 注意"至少"、"至多"、"恰有"等关键词的准确理解
        \item 分类要做到不重不漏，可使用韦恩图辅助分析
        \item 复杂问题可先考虑其对立事件
    \end{itemize}
\end{enumerate}
