# 试卷切分工作流

> **版本**：1.0.0
> **创建日期**：2026-04-13
> **用途**：将完整试卷 docx 按板块切分为独立 MD 文件，支持按板块检索、教研分析、AI 答题机等下游应用

---

## 一、输出目录结构

```
试卷切片库/
├── 00-试卷切分工作流.md          ← 本文件
├── 01a-默写/
├── 01b-语用/
├── 02-社科文/
├── 03-文学/
├── 04a-诗歌/
├── 04b-文言传记/
├── 04c-文言散文/
└── 05-写作/
```

区、届、考试类型等信息**不体现在目录层级**，统一用文件 frontmatter 标签标识。

---

## 二、板块定义与识别

> **重要：识别靠自然语义理解，不靠固定题号。** 不同区、不同年份的题号顺序可能不同。

| 板块 | 名称 | 识别要点 |
|------|------|----------|
| `01a-默写` | 古诗文默写 | 出现"按要求填空""默写"，内容为古诗文上下句，有空格/下划线待填 |
| `01b-语用` | 语言运用 | 积累应用部分的选择题：语句排序、成语辨析、病句修改、语境理解等 |
| `02-社科文` | 社科文阅读 | 多材料组合的论述性/学术性文本阅读，材料来源为学术论文、评论、书评等 |
| `03-文学` | 文学类文本阅读 | 现代文散文或小说，有作者署名，题目涉及赏析、理解、分析 |
| `04a-诗歌` | 古诗词鉴赏 | 古体诗/近体诗/词/曲，标注朝代和作者，附注释 |
| `04b-文言传记` | 文言人物传记 | 传记体文言文：有人物姓名字号、仕宦经历、事迹叙述，标题含"传""行状""墓志铭"等 |
| `04c-文言散文` | 文言散文 | 非传记体文言文：记/说/序/书/论/铭/赋等，侧重议论或抒情 |
| `05-写作` | 写作 | 出现"写一篇文章""不少于800字"或类似作文要求 |

### 边界情况处理

- **文言文只有一篇**：根据文体判断归入 04b 或 04c
- **社科文只有一则材料**：仍归入 02-社科文
- **积累应用中出现非选择题的语言运用**（如仿写、微写作）：归入 01b-语用
- **初中试卷**：板块结构可能不同（如无社科文、有名著阅读），按实际内容归类，缺的板块目录留空即可

## 三、每个板块切出的子文件

| 子文件后缀 | 内容 | 说明 |
|-----------|------|------|
| `-原文` | 阅读材料本体 | 含全部材料文本、注释、作者信息。保留原文分段和格式 |
| `-题目` | 题干 + 选项 | 不含答案。选择题保留选项，简答题保留分值和作答要求 |
| `-答案` | 参考答案 + 评分标准 + 阅卷反馈 + 注意事项 | 源文件中有什么就保留什么 |

### 特殊规则

- **01a-默写**：只切 `-题目` 和 `-答案`（题目本身就是"原文"）
- **01b-语用**：只切 `-题目` 和 `-答案`（选择题无独立原文）
- **05-写作**：只切 `-题目` 和 `-答案`
- **图片**：docx 内嵌图片会自动提取到板块目录下的 `images/` 子文件夹，MD 文件中用相对路径引用。详见第十节

---

## 四、文件命名规则

```
{年份}-{届}-{区名}-{考试}-{板块名}-{功能}.md
```

示例：
```
2026-26届-松江-二模-社科文-原文.md
2026-26届-浦东-二模-文言传记-题目.md
2026-26届-奉贤-二模-诗歌-答案.md
```

- 区名**包含在文件名**中，同时也在 frontmatter 标签中保留
- 考试类型：一模 / 二模 / 期中 / 期末 / 月考 等
- 附加材料子文件：`-样卷`（作文样卷）、`-阅卷反馈`（阅卷分析/反馈）

## 五、Frontmatter 规范

每个切出的 MD 文件必须包含以下 YAML frontmatter：

```yaml
---
title: "辛弃疾《玉楼春·隐湖戏作》"       # 原文标题或板块描述
board: 04a-诗歌                            # 板块代号
function: 原文                              # 原文 / 题目 / 答案
exam: 二模                                  # 考试类型
year: 2026                                  # 考试年份
class: 26届                                 # 届次
district: 松江                              # 区名
source: "2026年上海市松江区高三语文二模试卷及答案.docx"  # 源文件名
tags:
  - 试卷切片
  - 高三语文
  - 二模
  - 松江
  - 诗歌                                    # 板块标签
---
```

### 答案文件额外字段

```yaml
has_scoring_criteria: true    # 是否含评分标准
has_marking_feedback: false   # 是否含阅卷反馈
has_sample_essays: false      # 是否含作文样卷（写作板块）
has_images: false             # 源文件是否含未提取的图片
```

## 六、执行工作流

### Step 1：提取文本

从 docx 中提取全部文字内容。保持段落结构。

### Step 2：识别板块边界

用自然语义理解识别各板块边界。关键线索：
- 大题标号："一""二""三"等
- 小节标号："（一）""（二）"等
- 分值标注："（X分）"
- 内容特征：见第二节识别要点

**不依赖固定题号。** 同一板块在不同区的试卷中题号可能不同。

### Step 3：切分并归类

将识别出的每个板块拆分为原文/题目/答案子文件：
1. 先处理试题部分：按板块切出原文和题目
2. 再处理答案部分：逐一匹配到对应板块的答案文件
3. 如有阅卷反馈、注意事项等附加材料，追加到对应板块的答案文件末尾

### Step 4：写入文件

- 为每个子文件生成 frontmatter
- 写入对应板块目录
- 原文保留原始分段，不做内容改写
- 试卷上所有文字都要保留，包括：题目要求文字、注释、作者信息、分值标注等

### Step 5：校验

切分完成后检查：
- [ ] 每个板块的原文/题目/答案文件齐全（特殊板块除外）
- [ ] 所有题目都已归入某个板块，无遗漏
- [ ] 答案与题目一一对应
- [ ] frontmatter 字段完整且正确
- [ ] 试卷上的文字是否全部保留（包括注意事项、学生须知等，归入第一个文件或单独成文件）

---

## 七、批量处理规则

当一次性处理多套试卷时：
- 每套试卷独立执行完整 Step 1-5
- 同一板块目录下会积累多区的文件，靠 frontmatter 的 `district` 字段区分
- 处理完毕后输出汇总：各区 × 各板块的完成矩阵

---

## 八、与现有切片体系的关系

- **本库（试卷切片库）**：存放试卷原始切分结果，是**素材库**
- **教研切片库**（`教研计划/切片库/`）：存放教学方法论切片，是**教法库**
- 二者独立但可关联：试卷素材可作为教研切片的例题来源

## 九、图片处理

### 提取方式

docx 本质是 zip 包，图片存放在 `word/media/` 目录下。提取步骤：

1. 解压 docx，读取 `word/media/` 下所有图片文件
2. 解析 `word/document.xml`，定位每张图片在文档中的位置（通过 `<wp:inline>` 或 `<wp:anchor>` 关联的 `<a:blip r:embed="rId...">`，再经 `word/_rels/document.xml.rels` 映射到实际文件名）
3. 根据图片在文档中的位置，判断它属于哪个板块
4. 将图片复制到对应板块目录的 `images/` 子文件夹
5. 在 MD 文件中插入相对路径引用

### 目录结构示例

```
02-社科文/
├── images/
│   └── 2026-26届-二模-奉贤-社科文-fig1.png    ← 奉贤的条形统计图
├── 2026-26届-二模-社科文-原文.md               ← 内含 ![](images/...-fig1.png)
└── ...
```

### 图片命名规则

```
{年份}-{届}-{考试}-{区名}-{板块名}-fig{序号}.{ext}
```

图片文件名中**包含区名**（与 MD 文件不同），因为同一板块目录下会聚集多区图片，需要区分。

### MD 中的引用格式

```markdown
![称谓敏感调查数据](images/2026-26届-二模-奉贤-社科文-fig1.png)
```

### Frontmatter 补充

含图片的 MD 文件在 frontmatter 中标注：

```yaml
has_images: true
image_count: 1
```

### 实测发现

| 区 | 图片数 | 内容 | 归属板块 |
|---|---|---|---|
| 奉贤 | 1 | 条形统计图（称谓敏感调查） | 02-社科文 |
| 金山 | 1 | 对话漫画（母子关于专业选择） | 01b-语用 |
| 松江 | 0 | — | — |
| 浦东 | 0 | — | — |
| 闵行 | 0 | — | — |
| 宝山 | 0 | — | — |
| 嘉定 | 0 | — | — |

大部分语文试卷无图片。有图片的通常出现在社科文（图表）或语用（漫画）板块。
