```
### 执行要求

1. **文件格式处理**：
   - docx/doc → python3 zipfile 提取（doc 先用 textutil 转 docx）
   - pdf → 用 PyMuPDF 提取文本层；如无文本层则用已有的 MinerU 输出（静安有 .md）
   - 优先使用 docx 版本（如同时有 pdf 和 docx）

2. **区信息统一**：year=2026, class=26届, exam=一模

3. **命名规则**：`2026-26届-{区名}-一模-{板块名}-{功能}.md`

4. **附加材料处理**：
   - 阅卷反馈/阅卷分析 → `-阅卷反馈.md`（放入对应板块目录；如按题分拆则分别归入各板块）
   - 优秀范文/佳作 → `-样卷.md`（放入 05-写作/）
   - 解析版 → 内容合并到对应板块的 `-答案.md`

5. **并行处理**：每批次启动3个agent并行，按以下分批：
   - 批次1：普陀 + 嘉定 + 静安
   - 批次2：虹口 + 黄浦 + 松江
   - 批次3：徐汇 + 宝山 + 杨浦
   - 批次4：崇明 + 奉贤 + 闵行
   - 批次5：浦东 + 金山 + 长宁
   - 批次6：青浦 + 附加材料汇总
   每批完成后检查命名一致性，再启动下一批。

6. **完成后**：
   - 修正命名不一致（统一用短名：默写/语用/社科文/文学/诗歌/文言传记/文言散文/写作）
   - 输出 16区×8板块 完成矩阵
   - frontmatter 一致性检查
```

## 使用说明

1. 先启动一个新会话
2. 粘贴上面的提示词（选择一模或二模版本）
3. Claude 会自动读取工作流文档，按批次启动 agent 并行切分
4. 每批完成后自动检查，然后启动下一批
5. 全部完成后输出矩阵汇总

建议先跑 **26届一模**（全部是区际分享的规范文件，质量高），再跑 **25届二模**（格式更杂，附加材料更多）。
